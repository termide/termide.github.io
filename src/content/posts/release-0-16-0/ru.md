## Добавлено
- **Windows**: нативная поддержка Windows 11/10 через ConPTY (WSL не нужен)
- **Windows**: нативные API Win32 для определения места на диске и процессов
- **Windows**: Git Bash как оболочка по умолчанию в Windows
- **Windows**: цель сборки Windows MSVC в процессе релиза CI
- **Тема**: новая тема `terminal` — классический чёрный фон, наследующий цвета терминала
- **Сеть**: монитор пропускной способности сети в реальном времени (приём/передача) в верхней строке
- **Безопасность**: проверка символических ссылок в загрузчике скриптов — защита от выхода за пределы каталога
- **Безопасность**: 30-секундный тайм-аут для фоновых git-операций (push/pull/fetch)
- **i18n**: перевод `git_operation_timed_out` во всех 15 локалях

## Исправлено
- **SSH**: призрачная линия-разделитель и объединение событий перетаскивания для плавного изменения размера по SSH
- **Файловый менеджер**: исходные файлы открываются в редакторе, даже если у них установлен бит исполнения
- **Документация**: синхронизировано число тем (24→25) и языков (15+→21), удалена дублирующаяся ссылка
- **Документация**: исправлено число языков в описании deb-пакета (19→21)
- **Код**: чистка форматирования и мёртвого кода после PR #9, #10, #11
- **Сборка**: переменные прав на исполнение закрыты за `#[cfg(unix)]`

## Изменено
- **Производительность**: в Windows вызовы подпроцессов PowerShell заменены нативными API Win32
- **Документация**: раздел о нативной установке в Windows добавлен в документацию на всех 3 языках
- **Документация**: в список платформ добавлена нативная поддержка Windows
