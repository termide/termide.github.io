## Добавлено
- **Универсальный скрипт установки**: новый `install.sh` для простой установки на разных платформах

## Исправлено
- **Горячая перезагрузка конфигурации**: редактор теперь применяет настройки (theme, word_wrap, tab_size) при сохранении config.toml
- **Пути в UTF-8**: панель статуса Git корректно усекает пути к файлам с не-ASCII символами

## Изменено
- **Поиск git-репозиториев**: репозитории теперь находятся по путям панелей, а не по корню проекта
- **Производительность**: оптимизация O(n²) → O(n log n) в алгоритме удаления вложенных путей
- **Производительность**: меньше аллокаций при поиске с заменой за счёт `take()` вместо `clone()`
- **Качество кода**: в GitStatusPanel выделены вспомогательные методы (операции git, отрисовка, навигация, обработка мыши)
- **Качество кода**: из модуля buffer удалены неиспользуемые `SearchDirection` и `Action::Group`
