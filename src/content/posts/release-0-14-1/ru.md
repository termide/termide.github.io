## Добавлено
- **Файловый менеджер**: F3 открывает файлы только для чтения (режим просмотра)
- **Файловый менеджер**: выбор каталога по щелчку на заголовке для быстрого перехода
- **Файловый менеджер**: сочетания клавиш для переименования (R/F2), просмотра (V/F3), редактирования (E/F4) и нового файла (F/Ctrl+N)
- **Git статус**: сочетания клавиш для отката, просмотра и редактирования
- **Раскладка**: улучшено поведение при добавлении и удалении панелей в аккордеоне
- **Git статус**: автоматический fetch при инициализации, чтобы кнопка pull отображалась правильно

## Изменено
- **I18n**: `init()` и `init_with_language()` возвращают `Result`, а не вызывают panic
- **Кодовая база**: добавлены атрибуты `must_use`, исправлен небезопасный unwrap

## Исправлено
- **Терминал**: буфер альтернативного экрана меняет размер вместе с окном
- **Git**: для репозиториев через символические ссылки пути канонизируются перед strip_prefix
- **Файловый менеджер**: удалённые файлы появлялись не в тех каталогах
- **Клавиатура**: исправлены неверные и недостающие сочетания клавиш в документации
