## Добавлено
- **Горячая клавиша Alt+G**: быстро открывает панель статуса Git или переводит на неё фокус
- **Навигация в панели статуса Git**: пространственная навигация — Up/Down между разделами, Left/Right внутри строк
- **Закреплённые заголовки в панели статуса Git**: заголовки «Подготовлено» и «Не подготовлено» остаются видимыми при прокрутке
- **Улучшения CommitModal**: поддержка PageUp/PageDown, прокрутка мышью в текстовом поле
- **Shift+Enter в терминале**: вставляет перевод строки для многострочного ввода

## Исправлено
- Панель статуса Git: PageDown теперь прокручивает до конца и показывает все файлы
- Терминал: Shift+Enter отправляет перевод строки вместо escape-последовательности CSI u
- Редактор: прокрутка мышью больше не возвращает к позиции курсора
- CommitModal: рамка текстового поля теперь использует правильный акцентный цвет

## Документация
- В документацию терминала добавлено сочетание Shift+Enter (EN/RU)
- В документацию интерфейса добавлены пункт меню панели Git и сочетание Alt+G (EN/RU)
- Файлы справки на всех 9 языках дополнены сочетаниями клавиш панели Git
