## Добавлено
- **Система панелей-аккордеонов** — крупное архитектурное улучшение
  - Умная укладка панелей в зависимости от ширины терминала
  - Вертикальный аккордеон внутри горизонтальных групп
  - В каждой группе развёрнута одна панель, остальные свёрнуты до заголовка
  - Настраиваемый порог минимальной ширины панели (80 символов)
- Новые горячие клавиши навигации:
  - `Alt+Up/Down` — переход между панелями внутри группы
  - `Alt+PgUp/PgDn` — перенос панели в предыдущую/следующую группу
  - `Alt+Home/End` — перенос панели в первую/последнюю группу
  - `Alt+Plus/Minus` — увеличение/уменьшение ширины активной группы
  - `Alt+Backspace` — переключение укладки панелей (объединить/разъединить)
- Документация для разработчиков (`doc/en/architecture.md`, `doc/en/developer-guide.md`)

## Изменено
- Система раскладки панелей полностью переработана
  - Новый `LayoutManager` для централизованного управления группами панелей
  - Новый `PanelGroup` для вертикальной укладки панелей
  - Логика отрисовки панелей вынесена отдельно
- Улучшено управление шириной панелей
  - Исправлено перераспределение после удаления группы (8 мест)
  - Добавлена коррекция с нулевой суммой при изменении размеров
  - Расчёт автоукладки теперь использует среднюю ширину
  - Добавлено пропорциональное перераспределение ширины между всеми группами

## Удалено
- **НЕСОВМЕСТИМО**: удалён `LayoutMode` (SimplePanel/MultiPanel) в пользу динамических групп
- **НЕСОВМЕСТИМО**: модель навигации по панелям изменена с плоской на иерархическую (группы + панели)
