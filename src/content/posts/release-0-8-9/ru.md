## Добавлено
- **Распознавание URL в терминале**: при наведении с Ctrl ссылки подсвечиваются (голубым и подчёркиванием) и копируются в буфер обмена, Ctrl+щелчок открывает их в браузере
- **Повторное использование ImagePanel**: при просмотре изображений используется уже открытая панель, а не создаются новые
- **Асинхронные операции git**: отправка и получение выполняются в фоне с индикатором-спиннером и окном с результатом

## Исправлено
- **Удобство модальных окон**: InfoModal закрывается только по Enter, Escape или щелчку по кнопке (а не по любой клавише)
- **Отображение в модальных окнах**: результаты операций git показывают сам вывод без меток «Error:»/«Status:»
- **Определение щелчков по Unicode**: исправлено определение щелчка по кнопке с Unicode-текстом с учётом ширины графем
- **Порча TUI выводом git**: stdout/stderr перенаправлены в канал, чтобы вывод git не портил изображение в терминале

## Изменено
- **Расположение спиннера git**: перенесён из строки состояния в GitStatusPanel, чтобы его было лучше видно при переключении панелей
- **Чистка интерфейса**: объединён дублирующийся код и удалён мёртвый код
- **Структура меню**: меню перестроено, исправлено усечение в просмотрщике логов
