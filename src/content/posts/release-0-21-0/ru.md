## Добавлено
- **Меню**: процент заряда батареи и индикатор зарядки от сети рядом с часами
- **Модальные окна**: прокрутка колесом мыши в модальных окнах со списками
- **Редактор**: Shift+click расширяет выделение текста (с запасным вариантом Alt+click)
- **Редактор**: щелчок по индикатору табуляции в строке состояния позволяет переопределить `tab_size` для отдельного редактора
- **Файловый менеджер**: вычисление размера папок в широком виде с бюджетом времени на кадр
- **Файловый менеджер**: символические ссылки на папки учитываются при подсчёте размера в широком виде
- **Файловый менеджер**: кэш размеров папок общий для всех панелей файлового менеджера и сохраняется при навигации
- **Файловый менеджер**: цель символической ссылки показывается в модальном окне свойств; исправлена стрелка в строке состояния для вложенных элементов

## Изменено
- **Производительность (ввод)**: события отпускания и повтора клавиш вычерпываются без генерации холостых тиков; таблица горячих клавиш перестраивается реже, задержка опроса в простое ниже
- **Производительность (system-monitor)**: кэшируются запросы монтирований, процессов и сети; показания батареи кэшируются, а не перечитываются из `/sys` на каждом кадре; удалён дублирующийся модуль `disk_space`
- **Производительность (file-manager)**: асинхронная перезагрузка папки при обновлениях от наблюдателя
- **Производительность (editor)**: точки переноса вычисляются один раз на физическую строку; карта диагностик по строкам строится один раз за отрисовку
- **Производительность (highlight)**: запасной вариант подсветки синтаксиса возвращает сегменты `Cow<str>`, обходясь без выделений `String`
- **Производительность (core)**: `Panel::prepare_render` заимствует `Arc<Config>`, а не клонирует его
- **Производительность (app)**: рассылка диагностик LSP свёрнута в один цикл по панелям
- **Производительность (прочее)**: кэшируются поиск команды переднего плана, раскладка меню и регулярное выражение фрагментов; объединены покадровые проходы по панелям
- **Наблюдаемость**: проглоченные ошибки файловой системы и Git теперь пишутся в лог, а не молча отбрасываются
- **i18n**: тривиальные функции доступа к строкам генерируются макросом; `normalize_lang` сделан внутренним
- **Рабочее пространство**: `scripts` переименованы в `commands` по всей кодовой базе; удалено около 1,7 тыс. строк мёртвого кода, несколько публичных API сужены до `pub(crate)`

## Исправлено
- **Горячие клавиши**: буквенные привязки учитывают состояние Caps Lock через протокол клавиатуры Kitty
- **Терминал**: модификаторы Ctrl/Shift/Alt кодируются для стрелок, Home и End (#17)
- **Терминал**: экран PTY не пропадает при очень маленьких размерах терминала
- **Модальные окна**: объединённые события колеса мыши направляются в активное модальное окно
- **Модальные окна**: в окне размера табуляции больше нет лишней строки запроса
- **Настройки**: из заголовка модального окна убрана неработающая кнопка закрытия `[X]`
- **Редактор**: умные отступы срабатывают только при распознанном синтаксисе
- **Файловый менеджер**: отключённые каналы асинхронной перезагрузки обрабатываются корректно (больше никакой паники)
- **Системный монитор**: добавлен запасной вариант `get_disk_space_info_cached` для Windows, чтобы код индикаторов собирался под Windows

## Безопасность
- **Зависимости**: `openssl` обновлён с 0.10.76 до 0.10.78, чтобы закрыть GHSA-pqf5-4pqq-29f5 (CVE-2026-41676), GHSA-8c75-8mhr-p7r9 (CVE-2026-41678), GHSA-ghm9-cr32-g9qj (CVE-2026-41681), GHSA-hppc-g8h3-xhp3 и GHSA-xmgf-hq76-4vx2 — бюллетени о переполнении буфера и выходе за границы в `Deriver::derive`, `aes::unwrap_key`, `MdCtxRef::digest_final` и в обратных вызовах PSK/cookie/PEM. Зависимость подтягивается транзитивно через `suppaftp` → `native-tls`.
- **Зависимости**: `rand` обновлён с 0.8.5 до 0.8.6, чтобы закрыть GHSA-cq8v-f236-94qc (нарушение корректности по модели Stacked Borrows, возникающее, когда пользовательские логгеры вызывают `thread_rng()` при логировании уровня trace).
