## 新增
- **菜单**：在时钟旁显示电池电量百分比和交流电源充电指示
- **模态窗口**：列表模态窗口支持鼠标滚轮滚动
- **编辑器**：Shift+单击可扩展文本选区（Alt+单击作为备用）
- **编辑器**：点击状态栏中的 Tab 指示器，可为单个编辑器覆盖 `tab_size`
- **文件管理器**：宽视图中计算目录大小，并为每帧设定时间预算
- **文件管理器**：宽视图的目录大小统计会包含指向目录的符号链接
- **文件管理器**：目录大小缓存在所有文件管理器面板间共享，并在导航时保留
- **文件管理器**：属性模态窗口中显示符号链接的目标；修复了嵌套条目在状态栏中的箭头

## 变更
- **性能（输入）**：消化 Release/Repeat 按键事件时不再产生空闲 tick；减少快捷键表重建次数，降低空闲轮询延迟
- **性能（系统监视器）**：缓存挂载点/进程/网络查询；缓存电池读数，而不是每帧重新读取 `/sys`；移除重复的 `disk_space` 模块
- **性能（文件管理器）**：由监视器触发的更新改为异步重新加载目录
- **性能（编辑器）**：每个物理行的换行点只预先计算一次；每次渲染时按行构建的诊断映射只构建一次
- **性能（高亮）**：语法回退返回 `Cow<str>` 片段，以跳过 `String` 分配
- **性能（核心）**：`Panel::prepare_render` 借用 `Arc<Config>`，而不是克隆
- **性能（应用）**：LSP 诊断的分发合并到单个面板循环中
- **性能（其他）**：缓存前台命令查询、菜单布局和 hunk 正则表达式；合并每帧的面板遍历
- **可观测性**：此前被吞掉的文件系统和 Git 错误现在会记录到日志，而不是被悄悄丢弃
- **i18n**：简单的字符串访问器通过宏生成；`normalize_lang` 改为内部函数
- **工作区**：整个代码库中将 `scripts` 重命名为 `commands`；删除了约 1.7K 行死代码，并将若干公共 API 收紧为 `pub(crate)`

## 修复
- **快捷键**：字母键绑定通过 Kitty 键盘协议遵循 Caps Lock 状态
- **终端**：为方向键、Home 和 End 键编码 Ctrl/Shift/Alt 修饰键（#17）
- **终端**：在非常小的终端尺寸下保持 PTY 屏幕存活
- **模态窗口**：合并后的鼠标滚轮事件会传递给当前活动的模态窗口
- **模态窗口**：Tab 宽度模态窗口不再显示多余的提示行
- **设置**：移除了模态窗口标题中不起作用的 `[X]` 关闭按钮
- **编辑器**：智能缩进仅在识别出语法时触发
- **文件管理器**：妥善处理已断开的异步重新加载通道（不会再 panic）
- **系统监视器**：为 `get_disk_space_info_cached` 添加 Windows 回退实现，使指示器相关代码能在 Windows 目标上编译

## 安全
- **deps**：将 `openssl` 从 0.10.76 升级到 0.10.78，以修复 GHSA-pqf5-4pqq-29f5（CVE-2026-41676）、GHSA-8c75-8mhr-p7r9（CVE-2026-41678）、GHSA-ghm9-cr32-g9qj（CVE-2026-41681）、GHSA-hppc-g8h3-xhp3 和 GHSA-xmgf-hq76-4vx2——这些是 `Deriver::derive`、`aes::unwrap_key`、`MdCtxRef::digest_final` 以及 PSK/cookie/PEM 回调中的缓冲区溢出/越界安全公告。该依赖经由 `suppaftp` → `native-tls` 间接引入。
- **deps**：将 `rand` 从 0.8.5 升级到 0.8.6，以修复 GHSA-cq8v-f236-94qc（在 trace 级日志下，自定义日志记录器调用 `thread_rng()` 会触发的 Stacked Borrows 健全性问题）。
