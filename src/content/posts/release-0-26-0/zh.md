## 新增
- **Git 日志面板中的制表符提交图。** 提交历史现在用规范的伪图形字符（`● │ ├ ╮ ╯`）绘制，按每个提交的父提交布局，每条线道都有各自的颜色，因此可以凭颜色追踪一条分支。设置 `[git_log] unicode_graph = false` 可回退到 git 原生的 ASCII 图。
- **数据库连接恢复对话框。** 当数据库连接或查询发生致命错误时，查看器现在会提供 **重新连接** 或 **关闭面板**，而不是只在状态栏留下一条错误；`Esc` 可关闭对话框并保留最后的结果。
- **远程会话恢复对话框。** 当 SFTP/FTP/SMB 操作因会话断开（空闲超时、网络中断）而失败时，文件管理器会提供 **重新连接**、**打开主目录（本地）** 或 **关闭面板**，而不是一个走投无路的错误。
- **通过配置为自定义语言高亮关键字。** 直接在 `config.toml` 中（`[[highlight.custom_languages]]`）为没有 tree-sitter 语法的文件类型定义一个轻量的逐行高亮器 —— 关键字、类型和行注释，无需重新构建。
- **`Ctrl+R` 在内联查找栏中重新运行搜索**，用当前查询重新匹配最新内容（文件管理器目录、终端回滚缓冲区或编辑器缓冲区），无需重新输入。
- **查找栏用选区预填。** 在有单行选区时打开编辑器的查找/替换栏，会用选中的文本预先填入搜索字段。

## 修复
- 断开的 SFTP 会话不再引发源源不断的“连接错误”弹窗；文件管理器会停止重试已失效的会话。
- 切换界面语言现在也会更新顶层菜单栏，此前它会一直保持原来的语言，直到重启。
- 查找栏打开时，`Ctrl+C` 现在会复制缓冲区中的选区 —— 在缓冲区中点击或拖动会先把焦点移到那里。
