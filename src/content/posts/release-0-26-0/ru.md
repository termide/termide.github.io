## Добавлено
- **Граф коммитов из символов псевдографики в панели «Git история».** История коммитов теперь рисуется полноценной псевдографикой (`● │ ├ ╮ ╯`), выстроенной по родителям каждого коммита, и каждая дорожка окрашена своим цветом, так что ветку можно проследить по цвету. Задайте `[git_log] unicode_graph = false`, чтобы вернуться к родному ASCII-графу git.
- **Диалог восстановления подключения к базе данных.** Когда подключение к базе данных или запрос завершается фатальной ошибкой, просмотрщик теперь предлагает **Переподключиться** или **Закрыть**, а не оставляет лишь ошибку в строке состояния; `Esc` закрывает диалог, сохраняя последние результаты на экране.
- **Диалог восстановления удалённой сессии.** Когда операция SFTP/FTP/SMB завершается ошибкой из-за разрыва сессии (тайм-аут простоя, потеря сети), файловый менеджер предлагает **Переподключиться**, **Открыть домашний (локально)** или **Закрыть** вместо тупиковой ошибки.
- **Подсветка ключевых слов для пользовательских языков из конфигурации.** Для типов файлов без грамматики tree-sitter можно задать лёгкий построчный подсветчик прямо в `config.toml` (`[[highlight.custom_languages]]`) — ключевые слова, типы и строчные комментарии, без пересборки.
- **`Ctrl+R` повторяет поиск во встроенной панели поиска**, заново сопоставляя текущий запрос с актуальным содержимым (каталогом в файловом менеджере, прокруткой терминала или буфером редактора) без повторного ввода.
- **Панель поиска подставляет выделение.** Если открыть панель поиска и замены в редакторе при выделении в пределах одной строки, поле поиска заполняется выделенным текстом.

## Исправлено
- Разорванная SFTP-сессия больше не вызывает бесконечный поток всплывающих окон «ошибка подключения»; файловый менеджер перестаёт повторять попытки для мёртвой сессии.
- Смена языка интерфейса теперь обновляет и верхнюю строку меню, которая раньше оставалась на прежнем языке до перезапуска.
- `Ctrl+C` теперь копирует выделение в буфере, пока открыта панель поиска, — щелчок или перетаскивание в буфере сначала переводит туда фокус.
