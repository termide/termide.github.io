## Добавлено
- **Редактор**: автозакрытие скобок и кавычек с учётом контекста (апостроф посреди слова не закрывается)
- **Редактор**: переход по словам Ctrl+Left/Right и выделение по словам Ctrl+Shift+Left/Right
- **Редактор**: разнесение скобок с отступом по Enter между парными скобками (`{|}` → три строки с правильным отступом)
- **Редактор**: параметры конфигурации `auto_indent` и `auto_close_brackets`

## Изменено
- **VFS**: устранено дублирование операций SFTP с помощью помощников `spawn_op`/`spawn_op2` (−224 строки)
- **I18n**: небезопасное приведение указателя в `t()` заменено безопасным подходом через `Box::leak`
- **I18n**: при плюрализации используется запасное значение вместо `expect` с предварительной проверкой
- **Редактор**: логика границ слов вынесена из движений vim в общий модуль `word_boundary`
