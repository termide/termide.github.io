## Исправлено
- **Файловый менеджер**: `current_path` приводится к каноническому виду во всех местах записи (new, navigate, GoHomeDir), чтобы устранить расхождение наблюдателя на символических ссылках и bind-монтированиях — первопричину повторяющихся сбоев автообновления
- **Git**: для файлов из gitignore раскраска различий пропускается (добавлена проверка `git check-ignore`)
- **Git**: локальные коммиты считаются опережающими, когда удалённых ссылок нет (пустой удалённый репозиторий после клонирования)
- **Наблюдатель**: корень репозитория из событий git приводится к каноническому виду; распознаются MERGE_HEAD, FETCH_HEAD, REBASE_HEAD, CHERRY_PICK_HEAD
- **Терминал**: при копировании из строк с мягким переносом убираются лишние переводы строки (для каждой строки хранится флаг `wrapped`)
- **Модальные окна**: высококонтрастная инверсия fg/bg для кнопок во всех остальных модальных окнах (info, info_action, editable_select, tree_search)
- **Терминал**: добавлен debug_assert на согласованность длины буфера и флагов переноса
