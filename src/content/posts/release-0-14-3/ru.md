## Исправлено
- **Окна ресурсов**: CPU % нормализуется по числу ядер (0–100% от общей мощности, а не на одно ядро)
- **Окна ресурсов**: потоки (VfsLoader, GC-marker) и потоки ядра исключены из списков процессов
- **Окна ресурсов**: между колонками числа процессов и CPU добавлен отступ, чтобы они не наезжали друг на друга при больших значениях
- **Окна ресурсов**: число процессов показывается всегда (раньше скрывалось при count=1)
- **Окна ресурсов**: в строках окна Segments убран разделитель-двоеточие
- **Окна ресурсов**: содержимое окна CPU/RAM обновляется автоматически каждые 3 секунды
- **SSH**: проверяется диапазон порта (1–65535) вместо проверки только на цифры

## Изменено
- **Окно дисков**: переработано — колонки «свободно %», «свободно», «всего» и цветные значения свободного места
- **Окно дисков**: добавлены заголовки колонок с поддержкой i18n (15 языков)
- **Производительность**: сортировка без учёта регистра в файловом менеджере без аллокаций (раньше память выделялась при каждом сравнении)
- **Производительность**: сочетания клавиш терминала клонируются только при изменении конфигурации (раньше — на каждом кадре)
- **Качество кода**: варианты ConflictResolution синхронизированы между core, modal и file-ops
- **Качество кода**: к 11 чистым геттерам в BookmarksConfig добавлен `#[must_use]`
- **Безопасность**: пароль FTP обнуляется в памяти при уничтожении провайдера
