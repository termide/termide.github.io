## Добавлено
- Живой предпросмотр тем: тема меняется при перемещении курсора по меню выбора темы
- Отмена (Esc) возвращает прежнюю тему, подтверждение (Enter) сохраняет выбранную

## Исправлено
- Повторный щелчок по меню (выпадающее меню «Настройки» теперь закрывается по второму щелчку)
- Повторный щелчок по вложенному подменю (меню «Темы» закрывается по повторному щелчку)
- i18n: множественное число для функций time_*_ago (в списке сессий больше не появляется «{plural}»)

## Производительность
- Git-статус: число запусков процессов git на вызов сокращено с 6 до 2 (на 66%)
- RenamePattern::apply(): меньше аллокаций за счёт Vec<&str> вместо Vec<String>

## Рефакторинг
- Выделен трейт CursorNavigation для навигации курсором в модальных окнах (DRY, −70 строк)
- Выделены вспомогательные функции git_command для сокращения дублирования
- DRY-улучшения в system-monitor и status_bar
- Удалён мёртвый код в нескольких крейтах (~300 строк)
