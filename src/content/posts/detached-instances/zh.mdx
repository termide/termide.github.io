傍晚，你正在服务器上工作。termide 的一个面板里，构建已经跑了二十分钟；编辑器里开着三个文件，旁边的智能体正在逐个处理测试。这时 Wi-Fi 断了。SSH 连接随之中断，在那个终端里运行的一切也跟着没了：构建没能跑完，编辑器被关闭，智能体的回答停在半句。

通常的防范办法是 tmux。它能解决问题，却在你和 termide 之间又加了一个程序：它有自己的前缀键，会截走 termide 的快捷键，颜色和鼠标也要另外配置。termide 自己就能扛过断线，中间不需要任何东西。

## 启动时加一个参数

只需在启动 termide 时加上 `--detached` 参数，或者它的简写 `-d`：

```bash
cd ~/src/my-project
termide --detached
```

表面上什么都没变：打开的还是同一个 termide，用法也完全一样。不同之处在于，它不再依赖你的终端。termide 在服务器上独立运行，终端只是像一扇窗户那样把它显示出来。关上窗户，窗后的一切仍在原处。这样的 termide 称为实例，以项目文件夹命名，在这里就是 `my-project`。termide 从 0.35 版起就可以分离，但在 0.47 版之前，`--detached` 只负责启动实例，之后还要用 `termide --attach` 连接上去。

## 离开，再回来

需要离开时，按 <Keys k="Alt+D" />，或在菜单中选择 **选项 → 分离实例**。屏幕回到 shell，termide 会留下一条命令，用它就能回来。不过什么都不按也可以：连接断开，或者你直接关掉窗口，termide 会发现没人在看它了，然后继续工作。

什么时候回来、从哪里回来都行，哪怕是第二天、换一台电脑。连上服务器，进入项目，启动 termide，这次不加任何参数：

```bash
cd ~/src/my-project
termide
```

不会在第一个旁边再出现第二个。一个项目只能在一个 termide 中打开，所以 termide 发现 `my-project` 已被某个分离的实例占用时，就直接把你带进那个实例。这段时间里构建已经完成，文件还开在你离开时的位置，智能体也写完了它的回答。

没有任何东西被恢复，因为什么都没有中断过。termide 不会在你离开时保存工作、在你回来时再加载：它一直在运行，连同它的 shell、语言服务器和任务。

如果实例有好几个，或者记不清哪个是哪个，可以让 termide 列出清单，再按名称连接：

```bash
termide --list-instances
termide --attach my-project
```

清单会显示每个实例运行了多久，以及此刻是否有人连着它。装好 shell 补全后，`--attach` 之后按 <Keys k="Tab" /> 就能补出名称；不带名称的命令会选最近的那个实例。你回来时用的终端可能大不相同，尺寸和颜色都不一样：termide 会弄清它支持什么，然后重新绘制整个屏幕。

## 出了问题怎么办

同一时间只有一个终端能显示某个实例。如果 termide 还连在办公室的电脑上，而你已经回到家，普通的 `--attach` 会被拒绝。这时把实例接管过来：

```bash
termide --attach my-project --force
```

办公室那边的终端会收到实例已被接管的提示，termide 内部则一切照旧。

有时 termide 对按键没有反应。这时连按三次 <Keys k="Ctrl+\" />。这组按键不是由 termide 接收，而是由把你连到它的那个小程序接收，所以即使实例卡住了，也能分离。如果必须彻底结束 termide，就从外部结束它：

```bash
termide --kill my-project
```

未保存的修改不会丢失。termide 会把它们连同项目布局一起保存，下次打开项目时再交还给你；不过它的 shell 和任务会随它一起结束。

还有一个小细节：熟悉的 <Keys k="Ctrl+Z" /> 在这里不管用。termide 自己读取每一个按键，所以这个组合键根本到不了能让程序休眠的 shell。要做同样的事，用 <Keys k="Alt+D" />。

## 不必再记着这个参数

可分离有一个前提：必须事先安排好。没有用 `--detached` 启动的 termide 之后无法再分离，因为运行中的程序和它的终端紧紧绑在一起。tmux 也有同样的限制。如果你大部分时间都在服务器上工作，干脆让每次启动都可分离更省事。`config.toml` 里有对应的设置：

```toml
[general]
always_detachable = true
```

也可以在 **设置**（<Keys k="Alt+P" />）的 **常规** 中勾选 **始终可分离实例（Unix）** 来开启。

只是要记住，从此关闭窗口不再会关闭 termide，不仅在服务器上，在你的笔记本上也一样。它的 shell 和语言服务器也会继续运行，所以不时看一眼 `termide --list-instances`。有一个例外：termide 作为 `$EDITOR` 打开时，比如由 `git commit` 打开，这个设置不起作用：git 在等编辑器关闭，分离会让它以为编辑已经完成，而实际上并没有。

分离实例可在 Linux、macOS 和 BSD 上使用。所有命令和细节，直到 termide 把套接字放在哪里，都写在 [完整指南](https://github.com/termide/termide/blob/main/doc/zh/detached-instances.md) 中。
