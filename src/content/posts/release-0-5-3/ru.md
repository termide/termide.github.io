## Исправлено
- Мерцание цвета git-статуса при перезагрузке каталога (кэш сохраняется во время обновления)
- Дата каталога `.git` не обновлялась после коммита при просмотре корня репозитория
- Одиночный щелчок мышью в терминале копировал символ в буфер обмена (теперь копирует только выделение перетаскиванием)
- Время обновления git-статуса в файловом менеджере и формат отображения CPU в строке меню

## Изменено
- Наблюдатели git и файловой системы объединены в единый `UnifiedWatcher` с раздельными интервалами debounce (300 мс для файлов, 1000 мс для git)

## Производительность
- Оптимизирована отрисовка, сокращено число выделений памяти
