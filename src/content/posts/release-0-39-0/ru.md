## Несовместимые изменения
- **Агент задаётся одним файлом `agents/<name>/AGENT.md`.** Его настройки (`description`, `model`, `mode`, `tools` или `command` для внешнего агента) живут во front matter, а шаблон промпта — в теле, как в `SKILL.md`. `SOUL.md` и `agent.toml` больше не читаются: перенесите их содержимое в `AGENT.md`. Каталог в `agents/` без `AGENT.md` больше не задаёт агента; хватит и пустого файла.
- **Агент по умолчанию — `ai/agents/default/AGENT.md`.** Существующий `ai/AGENTS.md` переносится туда при запуске, так что ваши правки продолжают действовать; после этого `ai/AGENTS.md` не читается.

## Добавлено
- **Агент вспоминает, что проект уже знает.** Инструмент `recall` только для чтения ищет сразу по прошлым сессиям агента, истории git и файлам проекта и возвращает результаты со ссылками на источники — без хранилища памяти, за которым надо ухаживать. Он дотягивается и до каталога за пределами проекта, куда перешла панель, может отвечать по своим результатам моделью на ваш выбор и работает без интерфейса как `termide --recall`. Ограничения по времени — в `[ai.recall]`.
- **Режим плана прорабатывает задачу вместе с вами.** Агент исследует, затем решает открытые вопросы раундами карточек с вопросами, у каждой — рекомендуемый ответ, и только потом пишет план. Поиски он может поручать подагентам только для чтения. Карточка плана может выполнить план с чистого контекста: прочитанное по пути отбрасывается, а ваши сообщения и ответы сохраняются слово в слово. `←` и `→` переходят назад и вперёд между вопросами модели.
- **Claude Code, Codex и Gemini CLI получают инструменты MCP-серверов termide** в дополнение к своим, и каждый вызов проходит проверки termide. В Claude Code инструменты termide снова видны в чипе «Инструменты» и в чек-листе, и их можно отключить. Внешние агенты также получают карточку плана, а Claude Code узнаёт, когда режим плана переключается посреди сессии.
- **Сессия переходит между агентами.** Повторное открытие сессии или переключение её на внешний агент продолжает собственную сессию этого агента, где это возможно, а иначе начинает новую с кратким пересказом разговора. Вызовы инструментов внешнего агента теперь записываются в сессию, так что `recall` и вновь открытая сессия их видят.
- **Повторное открытие проектов прошлого запуска** из меню `Projects`. Набор сохраняется при каждом изменении, так что переживает и сбой; заново открытые проекты загружаются только при входе в них.
- **Ссылки открываются везде одинаково.** Markdown-ссылка в чате агента сохраняет свой адрес, а путь или URL в заголовке инструмента открывается по `Ctrl+click` на любой из строк, по которым он переносится; при зажатом `Ctrl` подсвечивается вся ссылка. Голые веб-адреса в Markdown становятся ссылками. Ссылка, по которой перешли, открывается по одним правилам во всех панелях: веб-адрес — по `[viewer] open_links`, каталог — в файловом менеджере, файл — там, где его открыл бы `Open…`, изображение — по `open_images`.
- **Редактирование каждой клавиши привязки в настройках.** `←`/`→` проходят по клавишам действия, `Enter` заменяет клавишу под курсором или добавляет новую на кнопке `[+]`, а `Delete` удаляет выбранную. Сочетание, на которое действие уже откликается, отклоняется.
- **Панель справки перечисляет клавиши панели агента.**
- **Агент сообщает об ошибках в своих определениях**: о ключах front matter, которые никто не читает, и о текстах инструментов с пустым телом или названных не по имени какого-либо инструмента.
- **То, что модели сообщается о каждом встроенном инструменте, лежит в `ai/tools/<name>.md`** и редактируется так же, как служебные промпты.

## Изменено
- **Ожидающие панели и проекты помечаются колокольчиком вместо цвета.** 🔔 встаёт на место значка панели (`!` без эмодзи-значков), а при входе в проект фокус переходит на ожидающую панель.
- **Чат агента читается спокойнее.** Правка показывает фрагменты диффа, а в заголовке — число добавленных и удалённых строк; префикс вызова инструмента по завершении окрашивается в цвет успеха или ошибки; длинные заголовки чтения, правки, поиска и загрузки переносятся, а не обрезаются; законченные рассуждения приглушаются; курсор и элементы управления запуском приглушаются в фоновой панели.
- **В поле ввода агента `↑`/`↓` сначала проходят по перенесённым строкам**, а уже потом вызывают историю, и вызванный запрос открывается с курсором в начале.
- **Больше команд только для чтения проходят в режиме плана**: печатающий `sed`, просмотр списков `git tag`, `git branch`, `git stash` и `git worktree`, другие читающие команды git, а также формы просмотра списков и содержимого у `gh`, `glab` и `tea`. Отклонённая команда называет часть, которая не только читает.
- **Компакция показывает ход работы** и новый размер контекста сразу по окончании.
- **Панель операций следует за вами при переключении проектов**, а команда, выполняющаяся в другом проекте, называет его.

## Исправлено
- **Закрытие отчёта о сборке по `Enter` могло завершить termide.** Выход, отклонённый по `Esc`, оставался взведённым до закрытия следующего модального окна. Теперь для выхода нужно принятое подтверждение.
- **Отчёт, завершившийся поверх открытого вопроса, заменял его**, и ответ терялся; теперь он ждёт, пока на вопрос ответят.
- **Долгие вызовы инструментов termide из Claude Code прерывались по тайм-ауту** через пять минут, и один долгий вызов задерживал все остальные; карточка с вопросом, от которого агент отказался, оставалась открытой.
- **Оформленный текст разрывал слова**: `**bold**ly` читалось как «bold ly», а `[docs](u).` — как «docs .».
- **Полоса контекста убегала на ячейку вперёд** от цифр рядом с ней.
- **Рецензент режима auto и решатель recall падали** на подключении, где не указана модель.
- **Claude Code не мог задать вопрос или предложить команду на карточке**: его вызовы `question` и `suggest_command` не находили, у кого спросить, и команды оказывались текстом в ответе.
- **Длинные строки в блоках кода обрезались** у края панели в чате агента и в просмотрщиках Markdown и HTML; теперь они переносятся.
- **Элементы управления приостановленного запуска переходили во вновь открытую сессию.**
