## 不兼容变更
- **代理由一个 `agents/<name>/AGENT.md` 定义。** 它的设置（`description`、`model`、`mode`、`tools`，外部代理则为 `command`）写在前置元数据中，提示词模板写在正文中，与 `SKILL.md` 相同。`SOUL.md` 和 `agent.toml` 不再被读取：请把其内容移到 `AGENT.md` 中。`agents/` 下没有 `AGENT.md` 的目录不再定义代理；一个空的 `AGENT.md` 即可。
- **默认代理是 `ai/agents/default/AGENT.md`。** 已有的 `ai/AGENTS.md` 会在启动时移到那里，因此你的修改仍然有效；此后不再读取 `ai/AGENTS.md`。

## 新增
- **代理能回忆项目已知的内容。** 只读的 `recall` 工具会同时搜索以往的代理会话、git 历史和项目文件，返回带引用的结果，无需维护任何记忆存储。它也能覆盖面板移到项目之外的目录，可以用你选择的模型根据结果作答，并能以 `termide --recall` 无界面运行。时间限制位于 `[ai.recall]` 下。
- **计划模式与你一起把任务理清。** 代理先进行探索，然后通过几轮问题卡片敲定悬而未决的决策，每张卡片都附有推荐答案，之后才撰写计划。它可以把搜索委派给只读的子代理。计划卡片可以在干净的上下文中执行计划，丢弃过程中读取的内容，同时逐字保留你的消息和回答。`←` 和 `→` 在模型的问题之间来回切换。
- **Claude Code、Codex 和 Gemini CLI 获得 termide MCP 服务器的工具**，与它们自己的工具并存，并且每次调用都经过 termide 的检查。在 Claude Code 上，termide 的工具重新显示在 **工具** 标签和清单中，并且可以关闭。外部代理也获得了计划卡片，Claude Code 能获知会话中途计划模式的切换。
- **会话可在代理之间延续。** 重新打开会话或将其切换到外部代理时，会尽可能恢复该代理自己的会话，否则以对话回顾开始新会话。外部代理的工具调用现在会记录到会话中，因此 `recall` 和重新打开的会话都能看到它们。
- **从 `项目` 菜单重新打开上次运行的项目。** 这组项目在每次变化时都会保存，因此即使崩溃也能保留；重新打开的项目只在你进入时才加载。
- **链接在各处以相同方式打开。** 代理聊天中的 Markdown 链接会保留其地址，工具标题行中的路径或 URL 可以在其换行所跨越的所有行上用 `Ctrl+click` 打开；按住 `Ctrl` 会高亮整个链接。Markdown 中的裸网址会变成链接。点击的链接在每个面板中都按相同规则打开：网址按 `[viewer] open_links`，目录在文件管理器中，文件在 `打开…` 会打开它的地方，图片按 `open_images`。
- **在设置中编辑绑定的每个按键。** `←`/`→` 在某个操作的按键之间移动，`Enter` 替换光标下的按键，或在 `[+]` 按钮上添加新按键，`Delete` 删除选中的按键。该操作已经响应的组合键会被拒绝。
- **帮助面板列出代理面板的快捷键。**
- **代理会报告其定义中的错误**：没有任何地方读取的前置元数据键，以及正文为空或名称不对应任何工具的工具说明文本。
- **模型收到的每个内置工具的说明位于 `ai/tools/<name>.md` 中**，可以像服务提示词一样编辑。

## 变更
- **等待中的面板和项目改用铃铛而不是颜色标记。** 🔔 取代面板图标（不使用 emoji 图标时为 `!`），进入项目时焦点会移到正在等待的面板。
- **代理聊天读起来更安静。** 编辑会显示其 diff 片段，并在标题行中显示增删行数；工具调用的前缀在完成后变为成功或错误颜色；较长的读取、编辑、搜索和抓取标题行会换行而不是截断；已结束的推理变暗；后台面板中的光标和运行控件变暗。
- **在代理提示框中，`↑`/`↓` 先在换行后的各行之间移动**，然后才调出历史记录，调出的请求打开时光标位于开头。
- **更多只读命令可通过计划模式**：输出用的 `sed`，列出 `git tag`、`git branch`、`git stash` 和 `git worktree`，其他 git 读取命令，以及 `gh`、`glab` 和 `tea` 的列表和查看形式。被拒绝的命令会指出不属于只读的部分。
- **压缩上下文会显示进度**，并在结束后立即显示新的上下文大小。
- **操作面板会跟随你切换项目**，在另一个项目中运行的命令会注明该项目。

## 修复
- **用 `Enter` 关闭构建报告可能会退出 termide。** 用 `Esc` 拒绝的退出会一直处于待触发状态，直到下一个模态窗口关闭。现在退出必须经过已接受的确认。
- **在打开的问题上完成的报告会替换该问题**并丢失答案；现在它会等到问题被回答之后。
- **Claude Code 对 termide 工具的长时间调用在五分钟后超时**，并且一个长调用会阻塞其他所有调用；代理已放弃的问题卡片仍保持打开。
- **带样式的文本会把单词拆开**：`**bold**ly` 显示为「bold ly」，`[docs](u).` 显示为「docs .」。
- **上下文条比旁边的数字最多超前一个单元格。**
- **auto 模式审查模型和 recall 求解器失败**，发生在未指定模型的连接上。
- **Claude Code 无法在卡片上提问或提供命令**：它的 `question` 和 `suggest_command` 调用找不到询问对象，因此命令最终作为文本出现在它的回复中。
- **代码块中的长行在面板边缘被截断**，发生在代理聊天以及 Markdown 和 HTML 查看器中；现在会自动换行。
- **暂停的运行的控件会带到新打开的会话中。**
