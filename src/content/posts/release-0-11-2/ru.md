## Исправлено
- **Panic из-за UTF-8**: исправлен panic по байтовому индексу при изменении размера панелей с кириллицей или другим Unicode-текстом — обрезка теперь идёт по ширине отображения, а не по смещению в байтах
- **Мышь в редакторе при переносе строк**: исправлено неверное положение курсора при щелчке мышью в режиме переноса, когда есть git-маркеры удалённых строк
- **Прокрутка редактора при переносе строк**: исправлена ситуация, когда в режиме переноса область просмотра не прокручивалась дальше строк с маркерами удаления или диагностикой
- **Визуальный курсор редактора**: исправлено: при постраничной навигации в режиме переноса курсор не мог дойти до конца последней визуальной строки
- **Щелчок по встроенному diff**: исправлено смещение щелчка мышью в режиме без переноса, когда удалённый текст встроенного diff сдвигает визуальные позиции
- **Устаревание панели git-статуса**: свёрнутая панель git-статуса теперь помечает себя устаревшей и обновляется при разворачивании (MarkStale/RefreshIfStale)
- **Заголовок git-статуса**: заголовок свёрнутой панели git-статуса теперь обновляет ветку и число файлов при событиях git и файловой системы
- **Переключатель git diff**: щелчок мышью по заголовку файла в панели git diff теперь правильно сворачивает и разворачивает его
- **Фокус панели операций**: открытие панели операций больше не забирает фокус у активного редактора
- **Безопасность CodeQL**: разорвана цепочка заражённых данных для предупреждений о логировании открытым текстом в типах VFS
