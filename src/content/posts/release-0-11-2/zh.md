## 修复
- **UTF-8 panic**：修复面板含西里尔字母/Unicode 文本时调整大小引发的字节索引 panic——现在按显示宽度截断，而不是按字节偏移
- **编辑器自动换行下的鼠标**：修复存在 git 删除标记时，自动换行模式下鼠标点击后光标位置错误
- **编辑器自动换行下的滚动**：修复自动换行模式下视口无法滚过带删除标记或诊断信息的行
- **编辑器可视光标**：修复自动换行模式下翻页时光标无法到达最后一个可视行的末尾
- **编辑器行内 diff 点击**：修复不换行模式下行内 diff 的已删除文本使可视位置偏移时的鼠标点击偏差
- **Git 状态面板过期**：折叠的 Git 状态面板现在会把自己标记为过期，并在展开时刷新（MarkStale/RefreshIfStale）
- **Git 状态标题**：折叠的 Git 状态面板标题现在会在 git/文件系统事件发生时更新分支和文件计数
- **Git diff 折叠切换**：在 Git diff 面板中鼠标点击文件头现在能正确切换折叠
- **操作面板焦点**：打开操作面板不再抢走活动编辑器的焦点
- **CodeQL 安全**：切断 VFS 类型中触发明文日志告警的污点链
