## Добавлено
- **Терминал**: поиск текста по `Ctrl+F` — по буферу прокрутки и видимому экрану с подсветкой совпадений, переходами и автопрокруткой
- **Ядро**: трейт `Searchable` для единого поиска в панелях редактора, журнала и терминала
- **Окно поиска**: область фокуса кнопок с навигацией с клавиатуры (Down/Up для переключения, Left/Right между кнопками)

## Исправлено
- **Терминал**: клавиша поиска по умолчанию изменена с `Ctrl+Shift+F` на `Ctrl+F` — внешние терминалы (GNOME Terminal и др.) перехватывают `Ctrl+Shift+F`
- **Журнал**: во время активного поиска автопрокрутка отключается, чтобы область просмотра оставалась на текущем совпадении
