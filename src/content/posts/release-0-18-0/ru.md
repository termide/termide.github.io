## Добавлено
- **Панель Git Stash**: отдельная панель для управления стэшами (извлечь, применить, удалить, различия — через контекстное меню); открывается из меню «Инструменты» и кнопкой «Стэш» в git-status; сохраняется в сессии
- **Git Blame**: встроенная аннотация blame в редакторе (Alt+B) с автором, возрастом, хешем коммита и описанием; включена по умолчанию для git-репозиториев; загружается асинхронно
- **Палитра команд**: быстрый доступ ко всем командам по Ctrl+Shift+P
- **LSP: поиск ссылок**: Shift+F12 открывает панель ссылок со всеми использованиями символа по проекту
- **LSP: переименование символа**: F2 переименовывает символ под курсором через LSP WorkspaceEdit
- **Темы**: 4 новые темы — blue-sky (светлая), pinky-pie (светлая), green-backs (светлая), billiard (тёмная)
- **Git Diff**: адаптивные цвета различий и навигация стрелками

## Изменено
- **Git Stash**: вынесен из встроенного ViewMode в GitStatusPanel в отдельный крейт `panel-git-stash` с контекстным меню на SelectModal
- **Панели**: панели Git Log, Git Stash и Git Diff теперь существуют в единственном экземпляре (используется уже открытая, а не создаётся дубликат)
- **Редактор**: открытие уже открытого файла переводит фокус на его вкладку, а не создаёт дубликат
- **Кнопки модальных окон**: используют высококонтрастную инверсию fg/bg, чтобы надёжно читаться во всех темах
- **Терминал**: escape-последовательности F-клавиш заменены таблицей соответствий
- **SFTP**: магические числа интервалов опроса заменены именованной константой

## Исправлено
- **InputModal**: стрелки влево и вправо теперь переключают кнопки OK/«Отмена» (раньше их перехватывал обработчик ввода текста)
- **Git**: строки вне git-репозитория больше не подсвечиваются по ошибке
- **Git Blame**: аннотация отрисовывается на правильной строке (раньше смещалась на одну)
- **Git Blame**: форматирование возраста учитывает диапазон месяцев (больше никаких «0 лет назад»)
- **Горячие клавиши**: устранены конфликты с терминалом и tmux, добавлены недостающие привязки
- **Конфиг**: горячая клавиша `switch_directory` теперь настраивается в file_manager.keybindings

## Рефакторинг
- **PanelExt**: меньше устаревших приведений типов (downcast), устранено дублирование кода
- **Документация**: обновлены справочники горячих клавиш, добавлена документация по Git Blame, поиску ссылок и переименованию символа на всех 3 языках
