## Добавлено
- **Удалённые файловые системы** — SFTP / FTP / FTPS на чистом Rust через russh + russh-sftp + rustls. Удалённые файлы можно просматривать, открывать, копировать, переименовывать и перемещать в том же файловом менеджере, что и локальные. Закладки принимают адреса `sftp://user@host:port/path`, `ftp://`, `ftps://`; аутентификация `Auto` перебирает по цепочке SSH-агент → `~/.ssh/config` (псевдонимы `IdentityFile`, `User`, `Port`, `Hostname`) → ключи по умолчанию → пароль. Пути не в ASCII без потерь проходят через URL-кодирование туда и обратно. Подробнее — в [`doc/en/vfs.md`](https://github.com/termide/termide/blob/main/doc/ru/vfs.md).
- **Статический бинарник Linux на musl** — `termide-0.23.0-x86_64-unknown-linux-musl.tar.gz` публикуется с каждым выпуском. Работает на Alpine, в distroless-контейнерах и на любом Linux без glibc. Nix flake тоже предоставляет этот рецепт как `#termide-static`.
- **Панель операций** —
  - Всплывающее меню для каждой карточки («Пауза» / «Продолжить» / «Отмена») на значке типа в скобках `[↑]`/`[↓]`/`[⧉]` (мышью), а с клавиатуры — `Space` / `Esc` / `Delete`.
  - Модальное окно очистки при отмене прерванных загрузок на удалённый сервер — «Удалить частично загруженный 'filename'?» по умолчанию предлагает удалить и безопасно для пакетных операций (затрагивает только файл, который передавался в этот момент).
  - Индикатор `⏸` рядом со значком, пока операция на паузе.
  - Панель справки теперь указывает Esc наряду с Delete/Backspace.
  - Подробнее — в [`doc/en/operations.md`](https://github.com/termide/termide/blob/main/doc/ru/operations.md).
- **CLI `--diagnostics`** — предварительная проверка (разбор конфига, каталоги XDG, наличие git), которая выполняется до инициализации терминала и завершается с кодом 0/1 для скриптов.
- **Панель журнала: кнопки уровней** — кликабельные `[TRACE] [DEBUG] [INFO] [WARN] [ERROR]` в строке заголовка, переключаются также по `Alt+1..5`.
- **Восстановление несохранённых буферов** — осиротевшие буферы из упавшей сессии и раньше восстанавливались как панели редактора; теперь о каждом сообщается в журнале, чтобы было понятно, откуда взялись лишние вкладки.
- **Файловый менеджер — действия на уровне курсора** — `Ctrl+N`, `D`/`F7` и `Ctrl+V` теперь срабатывают на том уровне дерева, где стоит курсор (в той же подпапке, внутри которой он находится), а не всегда в корне панели. Описано в `doc/{en,ru,zh}/file-manager.md`.
- **Редактор** — `F8` вне режима vim удаляет текущую строку (или все строки, затронутые активным выделением); в буферах только для чтения игнорируется.
- **Конфиг** — послойная загрузка глобального конфига и переопределений для проекта; `<project>/.termide/config.toml` накладывается на `~/.config/termide/config.toml`. Оба файла сохраняют только отличия от своей базы.
- **Документация по архитектуре** — в `doc/en/architecture.md` появились таблица «Async Pipelines» и отдельный раздел о VFS.

## Изменено
- **Большая работа над скоростью запуска и отклика.** Открытие сессии, у которой корни файловых менеджеров лежат в отслеживаемой домашней папке, раньше замораживало интерфейс на секунды. Всё перечисленное ниже вынесено из главного потока, и всё опрашивается через существующий механизм `tick()`:
  - Первоначальное чтение папки.
  - Раскрытие поддерева (локально: запускается рабочий поток, строка-заглушка `…`; так же, как уже было для удалённых панелей).
  - Обновление панелей git-статуса и истории git (5–6 вызовов `git` на одно обновление).
  - Поиск подмодулей git (`RepoManager` — синхронно находится только репозиторий верхнего уровня; подмодули добавляются через `poll`).
  - Обход git-статуса для поиска файлов.
  - Восстановление сессии — каждая панель группы создаётся в собственном рабочем потоке, а потом они собираются в сохранённом порядке.
  - Регистрация репозиториев в наблюдателе — обход `WalkBuilder` перенесён в рабочий поток; вызовы `inotify_add_watch` разбиты на порции по тикам (`INSTALL_CHUNK = 256`), чтобы репозиторий на 5000 папок не создавал пик в одном тике.
- **Передачи по SFTP корректно встают на паузу.** Актор теперь обслуживает только атомарные команды открытия / чтения порции / записи порции / закрытия; цикл по порциям работает в синхронном рабочем потоке и проверяет паузу и отмену между отправками. Приостановленная загрузка действительно останавливает поток байтов, а запросы `list_dir` от других панелей при этом проходят без блокировки.
- **Переименование в пределах одного хоста SFTP / FTP выполняется на сервере** — `mv` внутри одного соединения больше не скачивает и не загружает файл заново.
- **Размер папок в широком виде** — бюджет одного обхода по умолчанию снижен с 1000 мс до 100 мс; `Space` на папке также записывает её точный размер в общий кэш, так что колонка подхватывает его при следующей перерисовке.
- **Ошибки загрузки конфига и сессии отправляются в журнал**, а не в stderr до перехода в raw-режим, где сообщение уезжало за экран.
- **Редактор** — курсор и подсветка текущей строки скрываются, когда панель не в фокусе; визуально теперь так же, как в файловом менеджере.
- **Рамка модального окна** — пустой заголовок больше не пробивает в верхней рамке дыру в одну ячейку.
- **Асинхронное раскрытие дерева в удалённых панелях файлового менеджера** со строками-заглушками `…`; заодно исправлено дублирование при повторном раскрытии.
- **Встроенная аннотация blame** в строках редактора с переносом привязывается к последней визуальной строке, а не к строке курсора.

## Исправлено
- Несколько пограничных случаев отмены SFTP: зависание актора при отмене, незакрытые дескрипторы файлов, устаревшие получатели, клинившие пространство идентификаторов запросов russh-sftp, — пауза, отмена и переподключение теперь работают чисто (кэшированные `ConnectOptions` позволяют незаметно переподключиться после отменённой передачи).
- Переименование в удалённой панели шло через локальные `fs::*` (создавалась локальная папка и оставался лишний файл); теперь оно идёт через VFS.
- Положение курсора на только что созданном файле или папке: сопоставление идёт по полному пути, так что элемент, вложенный в раскрытую подпапку, находится правильно.
- Повторное раскрытие удалённой папки дублировало её содержимое.
- Вставка из буфера обмена всегда попадала в корень панели, где бы ни стоял курсор.
- Редактор → Команды: редактирование горячей клавиши команды проекта теперь сбрасывает таблицу горячих клавиш в памяти, так что новая привязка действует сразу.
- Панель терминала: живой вывод больше не тянет позицию прокрутки истории к концу.

## Удалено
- **Флаг сборки `--features vendored-openssl`** — рабочее пространство написано на чистом Rust (rustls + russh + russh-sftp) и OpenSSL не использует. Флаг и так ничего не делал; он убран из `release.yml`.

## CI и удобство разработки
- Новый `.github/workflows/ci.yml` запускает fmt / check / clippy / test на каждый PR и push в main (release.yml по-прежнему только для выпусков).
- `deny.toml` и шаг `cargo-deny check` проверяют бюллетени безопасности, лицензии, запреты и источники.
- Хук pre-commit описан в `CONTRIBUTING.md`.
