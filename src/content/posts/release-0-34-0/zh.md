## 新增
- **分离会话。** `termide --detached` 会启动一个比启动它的终端活得更久的会话：关掉 SSH 连接，几小时后回来执行 `termide --attach`，编辑器、shell、LSP 服务器和长时间运行的任务都还在你离开时的位置。`--list-sessions` 显示正在运行的会话，而 `Alt+D`——或 选项 → 分离会话——会在不停止任何东西的情况下断开客户端。这正是 `tmux` 和 `screen` 所提供的，只是在你和 termide 之间不再隔着第二个多路复用器：没有与 termide 自身快捷键争抢的前缀键，也不用为颜色或鼠标报告再配置一层。仅限 Unix；Windows 没有 `fork`/`setsid`，其 ConPTY 模型需要不同的宿主。
- **`general.always_detachable`** 让每个会话都可以分离，无需在启动时记得加 `--detached`。默认关闭，因为它改变了关闭终端的含义：会话会在关闭后继续存在，其语言服务器和 shell 也是如此。对 `$EDITOR` 方式的启动会忽略此设置——`git commit` 会等待编辑器退出，而一次分离会让它以为编辑已经结束，实际上并没有。
- **枚举类设置会打开下拉列表**，而不只是在各个取值之间循环。以前 Enter 和 Left/Right 只会跳到下一个值，既看不到还有哪些选项，也无法直接到达较远的条目——对三种图标模式还行，对二十五个主题就不行了。该列表支持键盘、滚轮和点击选择。

## 变更
- **`Alt+D` 现在用于分离，`Alt+W` 用于关闭面板。** 这两个字母原本被 WASD 导航替代键占用（`Alt+W/S/A/D` 对应方向键），这些替代键默认不再绑定；方向键继续负责导航，`Alt+X`/`F10` 仍可关闭面板。这些替代键也照顾了会吞掉 `Alt+<arrow>` 的终端——Ghostty 默认把 `Option+Left`/`Right` 重新绑定为 `ESC b`/`ESC f`——而这现在应在终端自身的配置中处理，`doc/*/keybindings.md` 中有说明。仍原样保留旧默认值的配置会被自动迁移；你自己选择的绑定永远不会被改写，即使它使用的是相同的按键。
- **菜单会显示每个有快捷键的操作的快捷键**——窗口、会话、书签、选项、命令以及面板上下文菜单——显示在右侧一列暗色文字中。以前只能通过帮助面板或设置发现键盘操作方式。命令的快捷键以前以 ` [Ctrl+K]` 的形式粘在标签后面，现在也使用同一列。
- **恢复默认 移到了按钮行的右侧**，挨着 取消，而按项目的按钮现在显示为 **应用到项目** / **从项目中移除**。以前 恢复默认 位于两个“应用”按钮之间，想点项目按钮时一旦点偏就会清空配置；而“创建项目覆盖”说的是要写入的文件，而不是按下它会做什么。
- **设置中的 快捷键 分组默认展开。** 它包含九个分区，默认折叠会把所有快捷键都藏在一个用户根本想不到的步骤后面。

## 修复
- **设置不响应鼠标。** 点击控件只会移动光标而不会切换开关，在本地化版本中按钮甚至完全无法点击：渲染器按字符逐个绘制 `[ label ]`，而点击检测却按字节计算宽度，因此第一个按钮之后的每个按钮都与点击落点错开了若干列。
- **“恢复默认”恰恰在最需要它的时候是灰色的**，而真正执行时又会让 快捷键 标签页变成空的。它依据的是窗口是否有未保存的编辑——这是它打开时的状态——而不是配置是否与默认值不同，并且它装入的是一个空白的 `Config::default()`，其中所有快捷键都未设置。
- **保存时会把整张快捷键表固化到 `config.toml` 中。** 你从未动过的设置在第一次保存时就被写了出来，因为比较的基准中所有快捷键都未设置。以这种方式固化的快捷键不再跟随默认值，因此之后的版本若新增或移动某个快捷键，就会与这份副本冲突，而不是生效。
- **设置只显示多键绑定中的第一个按键。** `Close panel` 响应 `Alt+W`、`Alt+X` 和 `F10`，但列表中只显示 `Alt+W`——而 `Delete` 随后会一次性删除全部三个，其中两个根本看不到。现在每个备选按键都会列出，`Delete` 一次删除一个（`Shift+Delete` 直接清空该操作），这也让多键绑定终于可以编辑：捕获对话框只能添加按键。
- **在全新安装中无法从设置更改主题。** 循环切换时按位置在主题列表中查找当前值，而默认配置自带 `theme = "default"`——这是一个回退名称而非主题——因此什么也找不到，并悄无声息地保持不变。
- **过长的字段标签会撞上自己的值。** 标签列固定为 32 个字符，最长的英文标签已经占满，翻译后的标签则会超出。
