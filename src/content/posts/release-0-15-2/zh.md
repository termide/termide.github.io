## 新增
- **文件管理器**：树形视图，目录可展开/折叠（`→`/`←`，vim 模式下为 `l`/`h`）
- **文件管理器**：树内增量搜索（`/`）——边输入边过滤文件，匹配项自动展开
- **文件管理器**：级联选择——用 `Insert` 选中目录时会选中其中的所有文件
- **文件管理器**：嵌套 git 状态——目录显示其子项的汇总状态
- **搜索对话框**：统一的搜索对话框，从文件管理器打开，提供文件 glob 和内容搜索两种模式（`Ctrl+F` / `Ctrl+Shift+F`）
- **搜索对话框**：内容搜索结果以树形显示，按文件分组并可展开

## 修复
- **搜索对话框**：在非 Text 模式下，Tab/Shift+Tab 现在会触发首次搜索（与 F3/Shift+F3 的行为一致）
- **Git**：在 diff 缓存中处理新文件/未跟踪文件为空的原始内容

## 变更
- **重构**：消除菜单操作中嵌套子菜单导航的重复代码
- **重构**：统一 Git 状态的文件选择和树构建辅助函数
- **重构**：在批处理器中提取 VFS URL 解析和来源名称辅助函数
- **性能**：在 Git 状态面板的循环中缓存行边界计算
