## Добавлено
- **Файловый менеджер**: дерево с разворачиваемыми и сворачиваемыми каталогами (`→`/`←` или `l`/`h` в режиме vim)
- **Файловый менеджер**: инкрементальный поиск по дереву (`/`) — файлы фильтруются по мере ввода, каталоги с совпадениями разворачиваются автоматически
- **Файловый менеджер**: каскадное выделение — выделение каталога клавишей `Insert` выделяет все файлы внутри него
- **Файловый менеджер**: вложенный git-статус — каталоги показывают сводный статус своего содержимого
- **Окно поиска**: единое окно поиска из файлового менеджера с режимами поиска по маске файлов и по содержимому (`Ctrl+F` / `Ctrl+Shift+F`)
- **Окно поиска**: при поиске по содержимому результаты показываются деревом с разворачиваемыми группами по файлам

## Исправлено
- **Окно поиска**: Tab/Shift+Tab теперь запускают первичный поиск в режимах, отличных от Text (так же, как F3/Shift+F3)
- **Git**: в кэше diff обрабатывается пустое исходное содержимое новых и неотслеживаемых файлов

## Изменено
- **Рефакторинг**: устранено дублирование навигации по вложенным подменю в действиях меню
- **Рефакторинг**: объединены помощники выбора файлов и построения дерева в git-статусе
- **Рефакторинг**: в обработчике пакетных операций вынесены разбор URL VFS и помощники имени источника
- **Производительность**: вычисления границ строк в циклах панели git-статуса кэшируются
