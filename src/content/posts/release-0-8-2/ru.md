## Добавлено
- **Встроенная визуализация диффа**: посимвольная подсветка изменений в изменённых строках редактора (удалённый текст красным, вставленный зелёным)
- **Git-метки на полях**: визуальные индикаторы в номерах строк редактора (`+` для добавленных строк, `~` для изменённых)
- **Кнопка «Откатить»**: быстрый откат отдельных файлов в панели статуса Git

## Исправлено
- Git-команды теперь правильно находят репозиторий при редактировании файлов в подкаталогах
- Сопоставление строк встроенного диффа корректно отслеживает изменённые строки, когда выше добавлены или удалены другие строки
- Пакет Debian (.deb) теперь содержит исполняемый файл в `/usr/bin/`
- Исправлены ссылки на скачивание пакетов .deb и .rpm в README.md
