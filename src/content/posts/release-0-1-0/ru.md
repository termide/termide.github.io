## Добавлено
- Первый релиз Termide с полным набором возможностей
- IDE в терминале с подсветкой синтаксиса для более чем 15 языков программирования
  - Rust, Python, JavaScript, TypeScript, Go, C/C++, Java, Ruby, PHP
  - Haskell, Nix, HTML, CSS, JSON, TOML, YAML, Bash, Markdown
- Умный файловый менеджер с понятным TUI-интерфейсом
  - Иконки типов файлов и колонка атрибутов
  - Распознавание символических ссылок и исполняемых файлов
  - Продвинутое выделение с клавиатуры и мышью
  - Рекурсивный git-статус для каталогов
- Встроенный виртуальный терминал с полной поддержкой PTY
  - Вставка по Ctrl+Shift+V в режиме bracketed paste
  - Отрисовка с частотой 24 FPS
  - Буфер прокрутки и поддержка цветов ANSI
- Система раскладки из нескольких панелей
- Интеграция с Git
  - Фоновое отслеживание git-статуса с наблюдением за файлами
  - Автоматическое обновление при изменениях в репозитории
  - Цветовые индикаторы статуса
  - Приглушённое отображение файлов из gitignore
  - Поддержка подкаталогов репозитория
- 12 встроенных тем
  - Тёмные: Default, Midnight, Dracula, OneDark, Monokai, Nord, Solarized Dark
  - Светлые: Atom One Light, Ayu Light, GitHub Light, Material Lighter, Solarized Light
  - Поддержка собственных тем из каталога конфигурации
- Мониторинг системных ресурсов
  - Загрузка CPU и RAM в реальном времени
  - Цветовые предупреждения
- Поддержка нескольких языков (английский, русский)
  - Полная поддержка кириллической раскладки клавиатуры
  - Перевод горячих клавиш с сохранением регистра
- Поддержка мыши во всех панелях и элементах интерфейса
- Буфер обмена для вырезания, копирования и вставки
- Пакетные операции с файлами (копирование, перемещение, удаление)
- Подтверждение выхода при несохранённых изменениях и запущенных процессах
- Надёжная обработка ошибок и ограничения на размер файлов
- Автоматическое обновление каталога при изменениях в файловой системе
- Кроссплатформенность (Linux, macOS, Windows через WSL)
- Сборки для нескольких архитектур (x86_64, ARM64)

## Техническое
- Написан на Rust с TUI-фреймворком ratatui
- Crossterm для кроссплатформенной работы с терминалом
- Portable-pty для реализации PTY
- Tree-sitter для подсветки синтаксиса
- Ropey для управления текстовым буфером
- Sysinfo для мониторинга системных ресурсов
- Pre-commit-хуки для контроля качества кода
- Обширный набор тестов
