## 变更
- **终端搜索现在是内联查找栏。** 在终端中按 `Ctrl+F` 会打开停靠在面板顶部的查找栏 —— 与编辑器和文件管理器一致 —— 带有 `[Aa]` 大小写和 `[.*]` 正则开关、`◄ Prev` / `Next ►` 导航以及内联匹配计数。终端搜索现在支持正则（此前只能按字面匹配），`Tab` 可在查找栏与终端网格之间移动焦点。
- 减少了终端、文件管理器和文本渲染路径上的每帧内存分配，降低了重绘时的 CPU 占用。

## 修复
- 当相对于 HEAD 有行被删除时，编辑器的内联 git blame 注释现在会保持在光标所在行；此前删除标记会把它推到光标上方。
