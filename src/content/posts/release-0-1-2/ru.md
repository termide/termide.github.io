## Добавлено
- Дублирование строки или выделения (`Ctrl+D`)
- Сообщение о результате замены («Заменено N вхождений»)
- Проверка размера файла перед открытием в редакторе (лимит 100 МБ)
- Настраиваемый размер табуляции (читается из `config.toml`)
- Публикация на crates.io в процессе релиза

## Изменено
- Переход на теги семантического версионирования без префикса «v» (например, `0.1.2` вместо `v0.1.2`)
- Лицензия в Cargo.toml изменена с двойной (MIT OR Apache-2.0) только на MIT
- Улучшена обработка ошибок во всём приложении
  - Panic при разборе темы заменён мягкой обработкой ошибок
  - При ошибке разбора используется встроенная тема по умолчанию
  - Улучшена обработка ошибок мьютексов в терминале (22 вызова `.lock().unwrap()` заменены на `.expect()`)
- Добавлены понятные сообщения об ошибке для слишком больших файлов

## Исправлено
- Падения приложения из-за некорректных файлов тем
- Размер табуляции в редакторе теперь учитывает настройки пользователя
