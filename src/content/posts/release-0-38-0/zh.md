## 新增
- **项目在后台保持打开。** 切换到另一个项目不再关闭你离开的那个：其终端中的程序继续运行，其代理继续工作，未保存的编辑保持原样。项目会一直保持打开，直到你关闭它或退出。`项目` 菜单和 `Alt+\` 切换器以同一个扁平列表列出相同的项目——先是已打开的项目，按路径排序，然后是其他项目，最近使用的在前，并附上你最后一次在其中工作的时间。● 标记当前项目，○ 标记在后台打开的项目，🔔 标记有面板在等你的项目（代理的提问或已完成的工作、终端响铃）；只要存在这样的项目，`项目` 标题就会高亮。`Alt+\` 后按 `Enter` 回到你最后离开的项目。`Delete`/`F8` 在确认后关闭后台项目，或删除未打开项目的已保存布局；退出时会列出仍在运行某些内容的后台项目。`prev_project`、`next_project` 和 `goto_project_1`…`goto_project_9` 可用键盘切换；它们默认未绑定，参见 [`doc/en/keybindings.md`](https://github.com/termide/termide/blob/main/doc/zh/keybindings.md)。应 [#61](https://github.com/termide/termide/issues/61) 的请求而添加。
- **文件可通过系统剪贴板传递。** 在文件管理器中按 `Ctrl+C` 会把选中项作为文件放到剪贴板上，这样 Finder、资源管理器或其他文件管理器会将它们作为文件粘贴；`Ctrl+V`（也可用 `Cmd+V`）会把在那里复制的文件粘贴到面板中。`Ctrl+X` 将选中项标记为剪切，下次粘贴时会移动它们，确认框会在删除任何内容之前注明「移动」；在远程面板或压缩包内部，剪切会被拒绝，而不是变成复制。以文本形式复制的路径也能粘贴。Linux 上剪贴板仍只支持文本。参见 [`doc/en/file-manager.md`](https://github.com/termide/termide/blob/main/doc/zh/file-manager.md)。
- **带审查模型的 `auto` 权限模式。** 原本会弹出权限卡片的情况，改由一次单独的模型调用来决定；它能看到你的消息和代理的调用，但永远看不到工具结果，因此文件和网页中的内容无法说服它做任何事。规则、计划模式和钩子仍然优先，拦截会连同原因一起传给代理。每次调用都会记录是谁做出的决定。`[ai] auto_reviewer` 选择所用的连接。
- **回退到选定的消息。** 在空提示框中按 `Esc`（或 `F4`）会在提示框上方列出你发送过的消息；选中其中一条会把对话回退到它之前，并把这条消息放回输入框。如果此后文件有变动，会有卡片询问是恢复文件、对话，还是两者都恢复。
- **分叉会话。** `F5`、`/fork` 或 `[≡]` 菜单会把会话复制到新的代理面板中，新面板从同一点继续，而原会话照常进行；副本命名为 `Refactor (2)`、`(3)` 等。
- **从代理提示框运行 shell 命令。** 在空提示框中输入 `$` 会将其变为 shell 命令行，立即运行而不询问模型；代理会在你的下一条消息时读取该命令及其输出。新的 `suggest_command` 工具让代理把命令交给你而不是自己运行，在卡片上提供 运行、先编辑、复制 和 不运行。
- **通过 HTTP 连接的 MCP 服务器。** `.mcp.json` 中的 `url` 服务器通过可流式 HTTP 连接，支持服务器推送、OAuth 登录（授权保存在 `mcp-auth.json` 中）以及 `/mcp reload`、`login` 和 `logout`。`.mcp.json` 会从面板所在目录及其上方的每一级目录读取。每个服务器保持一行实时状态，打开的工具集清单会随着服务器连接逐步填充。
- **用 `Ctrl+S` 将代理聊天保存为 Markdown。**
- **更生动的欢迎横幅。** 它绘制项目徽标，以代理及其描述作为标题，在下方列出提前到达的通知，会话日期精确到分钟，并且新会话可以单击选择其目录。
- **代理聊天中的 URL 可用 `Ctrl+click` 打开**，已抓取的 URL 显示为暗色。
- **内置 PHP、Terraform 和 Docker 语言服务器**（`phpantom_lsp`、`terraform-ls`、`docker-language-server`，后者的遥测已关闭），当二进制文件在 `PATH` 中时自动使用。Dockerfile 和 Compose 文件按名称识别。`.tsx` 和 `.jsx` 文件现在会启动 TypeScript 服务器。
- **Lua** 语法高亮和大纲。
- **制表符延伸到下一个制表位。** 以前无论制表符宽度设为多少，制表符都只画一列宽；现在在编辑器度量文本的所有地方——绘制、光标、单击、换行和滚动——它都延伸到下一个制表位。
- **在目录选择器中按 `.` 切换隐藏目录。**
- **终端响铃会提醒你注意**：未获得焦点的终端面板标题会变成警告色，直到你聚焦它。

## 变更
- **新的代理会话以 `auto` 模式启动。** 可在设置中选择其他起始模式。
- **服务提示词和根提示词模板只从配置目录读取。** 仓库不能再自带 `.termide/ai/system/` 或 `.termide/ai/AGENTS.md` 来改变代理总结、规划或评判的方式，或去掉其基本准则。项目的约定仍可通过其 `AGENTS.md` 指令进入提示词。
- **你自己的 `[lsp.servers.*]` 条目会添加到内置服务器中，而不是全部替换它们**；针对内置语言的条目只修改它所设置的字段。
- **项目菜单是一个扁平列表，而不是目录树**，因此一次性删除某个目录下所有项目已保存布局的功能也随之移除。`Alt+\` 切换器每个项目显示一行，光标为反色。
- **上下方向键让光标保持在其屏幕列上**，在未开启自动换行时跨越短行也是如此。
- **自动推理可用于本地服务器。** 设为 `auto` 的连接现在会向本机或局域网上的服务器（llama.cpp、vLLM、omlx、LM Studio）发送聊天模板的 `enable_thinking` 开关，于是它们的 **推理** 标签会出现。

## 修复
- **把文件粘贴到其所在目录可能会清空它。** 在冲突时选择 **覆盖** 会在把源文件复制到自身之前先将其截断。现在复制到自身会使用下一个可用名称（`notes (1).txt`），移动到自身不做任何事，将目录复制或移动到其自身内部会被拒绝。
- **一个分离实例中的 panic 可能拖垮由同一守护进程服务的所有其他实例**；网页工具同样可能在一次出错后永久失效。
- **在 Windows 上，路径带有 `\\?\` 前缀**，出现在面板标题、书签、git 和终端中。
- **在含有制表符的行上，诊断下划线、补全和代码操作的列位置错误**，重复的诊断被计数两次，git diff 丢失了以制表符缩进的行的缩进。
- **在已滚动的长文本字段中单击会落到错误的字符上**，并且字段会跳回开头；编辑器的查找栏现在可以接收鼠标单击。
- **状态栏在有宽字符时文本位置错乱。**
- **语言服务器可能在初始化之前就收到请求。**
- **工具集清单在未按 `Enter` 就关闭时会丢失更改**，代理横幅的标签也没有翻译。
- **重命名对话框显示了「Move … to:」提示。**
- **当适应高度的面板获得焦点时，全屏列会被展开。**
- **russh 更新到 0.63**，以修复 SSH 连接中未解决的安全公告。
