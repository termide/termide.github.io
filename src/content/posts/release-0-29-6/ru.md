## Исправлено
- Таблицы Markdown и HTML теперь отображают строчное форматирование (встроенный код, `**bold**`, `*italic*`) и кликабельные ссылки внутри ячеек. Раньше форматированная ячейка оставалась пустой, а её содержимое вытекало простым текстом под таблицу.
- Панель диагностики больше не вызывает панику, когда в терминале всего несколько строк.
- Панели git status и git log больше не накапливают лишние фоновые обработчики обновления при бурной активности в `.git` (rebase, gc, fetch, большой checkout), что избавляет от всплесков нагрузки на процессор и числа git-подпроцессов.
- Встроенный git diff в редакторе больше не рискует вывести запрос учётных данных git/SSH поверх интерфейса и теперь правильно строит diff для файлов, открытых через путь с символической ссылкой.

## Изменено
- Возраст в git blame и относительное время в списке сессий теперь следуют языку интерфейса (blame раньше всегда был на английском) и получили градацию «годы»; новая строка переведена на все встроенные локали.
- Быстрее отрисовка редактора при поиске в больших файлах и меньше работы на кадр в панели git status.
