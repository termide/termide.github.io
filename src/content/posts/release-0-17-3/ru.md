## Добавлено
- **Переключатель сессий**: поле фильтра в модальном окне переключения сессий — ввод фильтрует сессии по пути (поиск подстроки без учёта регистра); Backspace удаляет последний символ; навигация (↑↓/Enter/Esc) работает по отфильтрованным результатам
- **История Git**: выпадающие списки выбора репозитория и ветки — щелчок по виджету `[repo ▼]` или `[branch ▼]` открывает встроенный выпадающий список, чтобы переключать репозитории и ветки прямо из панели истории git

## Исправлено
- **История Git**: щелчок по открытому селектору теперь закрывает его (а не открывает заново); щелчок по одному селектору, пока открыт другой, переключает на него сразу, одним щелчком
- **История Git**: выпадающий список веток выровнен по позиции своего селектора; селектор ветки размещён сразу после селектора репозитория
- **Файловый менеджер**: одиночные горячие клавиши на кириллице теперь переводятся в латиницу (например, `щ` в раскладке ЙЦУКЕН работает как `o`)
- **Файловый менеджер**: клавиша `o` добавлена как запасной вариант для открытия во внешней программе (вдобавок к `Ctrl+Enter`)
- **Статус Git**: при отрисовке пунктов выпадающего списка модификаторы сбрасываются, чтобы зачёркивание не просачивалось из предыдущей отрисовки
- **Git**: пути репозиториев приводятся к каноническому виду, чтобы не дублировать репозитории, доступные по символическим ссылкам (один и тот же репозиторий больше не появляется в селекторе дважды)
- **Редактор**: кэш отрисовки сбрасывается после перезагрузки файла с диска — обновлённое содержимое показывается сразу

## Изменено
- **Ресурсы**: обновлены скриншоты тем, добавлено 15 новых превью тем
- **Рефакторинг**: магические номера подменю заменены именованными константами (`SESSIONS_SUBMENU_SWITCH`, `TOOLS_SUBMENU_GIT_LOG` и др.) во всех обработчиках действий меню
