## Добавлено
- **4 новые темы**: Matrix (цифровой дождь), Terminator (HUD Скайнета), Pip-Boy (ЭЛТ-экран из Fallout), Manuscript (средневековый пергамент)
- **Адаптивная раскладка по умолчанию**: раскладка сессии зависит от ширины — широкие терминалы (>= 160 колонок) получают раскладку из 3 групп, обычные — из 2 групп с боковой панелью-аккордеоном
- **GitStatus в боковой панели по умолчанию**: если найден git-репозиторий, новые сессии автоматически добавляют панель GitStatus в боковой аккордеон
- **Кэширование строк диагностики**: редактор кэширует число строк диагностики, чтобы быстрее прокручивать область просмотра с диагностикой LSP

## Изменено
- **Разделение модуля состояния**: монолитный `crates/state/src/lib.rs` разбит на подмодули `batch`, `layout`, `operations`, `pending_action`, `ui`
- **Удаление мёртвого кода**: удалены неиспользуемые функции в 7 крейтах (`clipboard::has_text`, `git::check_git_available`, `logger::get_entries`, `editor::cleanup_temp_file`, `theme::all_themes`, `theme::builtin_theme_names`, `system_monitor::cpu_usage_float`)
- **Удалён крейт text-search**: неиспользуемый крейт `termide-text-search` удалён из рабочего пространства
- **Обновление документации**: README, документация по архитектуре и руководства для разработчиков (EN+RU) обновлены под текущую структуру рабочего пространства, 24 темы, 15 языков и все типы панелей

## Исправлено
- **Безопасность**: крейт `time` обновлён с 0.3.45 до 0.3.47 — устранена DoS-уязвимость с исчерпанием стека (GHSA)
- **Диагностика в редакторе**: отменена дедупликация строк диагностики в методах прокрутки, из-за которой курсор вставал не туда
- **Регистрация наблюдателей**: исправлено: наблюдатели не регистрировались при переключении сессии; оптимизировано исключение `.git/objects` из наблюдения
- **Подсветка ссылок в терминале**: исправлено смещение подсветки ссылки по Ctrl+щелчку для не-ASCII содержимого в панели терминала
- **Корень git в файловом менеджере**: `git_root` сохраняется при внутренних переходах; исправлена потеря git-контекста при обновлении после коммита
- **Перерисовка файлового менеджера**: исправлено отсутствие перерисовки после завершения асинхронного обновления git-статуса
