## 新增
- 版本字符串（`termide --version` 和帮助面板标题）现在包含构建所用的 git 提交，例如 `0.23.1 (50b81b1)`，这样版本号相同的构建也能区分开来。

## 修复
- **PHP 语法高亮** —— `.php` 文件现在会被高亮，而不再以纯文本显示，包括混合 HTML/PHP 的模板（HTML、`<?php … ?>` 代码以及标签都会着色）。此前发布的二进制文件中 PHP 语法被悄无声息地禁用了：不同的 crate 引入了互不兼容的 tree-sitter-php 版本，它们冲突的 `tree_sitter_php` 符号在链接时合并到了一个运行时会拒绝的 ABI 上。现在所有 crate 都固定使用同一语法版本。
- **JSX 语法高亮** —— `.jsx` 文件现在会被高亮；该语言此前虽被列为支持，却从未真正加载。
- **多行结构** —— 跨越多行的块注释和字符串现在在所有语言中都会一直着色到结尾，而不会在第一行之后失去高亮。

## 变更
- 编辑器现在以一次上下文感知的遍历高亮整个缓冲区（文件不超过 1 MB），而不是逐行高亮，这正是模板语言和多行记号能正确着色的原因。更大的文件回退到原先的逐行高亮。
- 加载失败的语法现在会被记录到日志，而不是被悄悄丢弃，因此高亮缺失的问题可以诊断。

## 安全
- 将 `russh` 升级到 0.61.1（CVE-2026-46702）：SFTP 客户端现在会限制解压后的 SSH 数据包大小，堵住了在协商启用压缩时恶意服务器可触发的远程资源耗尽漏洞。
- 刷新依赖锁文件，将已撤回的 `aes` 0.9.0 换成 0.9.1（无 API 变化）。
