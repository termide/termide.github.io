## Добавлено
- **Конфиг**: послойная загрузка глобального конфига и переопределений для проекта. `<project>/.termide/config.toml` накладывается на глобальный `~/.config/termide/config.toml` пользователя, а тот, в свою очередь, на встроенные значения по умолчанию. Оба файла теперь сохраняют **только** те поля, которые отличаются от их базы (значений по умолчанию для глобального файла, значений по умолчанию и глобального конфига для файла проекта), так что файлы конфига остаются маленькими, а значение по умолчанию, изменённое в будущем выпуске, больше не будет молча перекрыто значением, которое пользователь сохранил как стандартное.
- **Настройки**: новая кнопка в нижней части окна «Создать / удалить переопределение проекта» — единый элемент, чтобы начать записывать отличия для проекта или удалить их (с подтверждением). Состояние определяется по наличию файла проекта; отдельного флага нет.
- **Редактор**: `F8` вне режима vim удаляет текущую строку (или все строки, затронутые активным выделением). В буферах только для чтения привязка игнорируется; буфер обмена намеренно не трогается.

## Изменено
- **VFS**: устранено дублирование диспетчеризации провайдеров через вспомогательную функцию `dispatch_remote` на замыканиях (поведение не меняется; из `crates/vfs/src/lib.rs` убрано около 70 строк).
- **Чистка**: удалены три неиспользуемые публичные вспомогательные функции (`is_supported`, `is_language_supported`, `count_files_under`); тестовый код `panel-terminal` переформатирован, чтобы убрать два предупреждения `clippy --all-targets`.

## Исправлено
- **Редактор**: в режиме переноса строк встроенная аннотация blame теперь привязана к последней визуальной строке логической строки курсора. Раньше она пыталась следовать за той визуальной строкой, где стоит курсор, а на длинных строках это строка, плотнее всего заполненная кодом, — аннотацию выталкивало за правый край, и её фактически не было видно.
- **Панель терминала**: пока фоновая программа выводит новые данные, позиция прокрутки истории у пользователя больше не сползает к живому концу. `scroll_up` теперь увеличивает `scroll_offset` (не больше длины истории прокрутки), когда строка уходит в историю, так что видимое окно остаётся на том же содержимом. Те, кто следит за концом вывода (offset == 0), по-прежнему видят самый свежий вывод.
- **Редактор → Команды**: редактирование горячей клавиши команды проекта через модальное окно теперь сбрасывает таблицу горячих клавиш в памяти, так что новая привязка действует сразу и сохраняется после перезапуска.

## Безопасность
- **openssl** обновлён до `0.10.79` (транзитивно через `native-tls → suppaftp → termide-vfs`), что закрывает GHSA-xv59-967r-8726 / CVE-2026-44662 (переполнение кучи в AES key-wrap-with-padding) и GHSA-xp3w-r5p5-63rr / CVE-2026-42327 (неопределённое поведение в `X509Ref::ocsp_responders` на OCSP-адресах не в UTF-8). Termide напрямую не задействует ни один из этих путей кода.
