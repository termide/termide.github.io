## 新增
- **配置**：分层加载全局配置 + 项目级覆盖。`<project>/.termide/config.toml` 叠加在用户的全局 `~/.config/termide/config.toml` 之上，而全局配置又叠加在内置默认值之上。两个文件现在都**只**保存与其基准不同的字段（全局文件以默认值为基准，项目文件以默认值+全局配置为基准），因此配置文件保持精简，今后某个版本更改的默认值也不会再被用户保存下来的旧默认值悄悄掩盖。
- **设置**：底部新增“创建 / 移除项目覆盖”按钮——用一个可视控件即可开始写入项目级差异配置，或将其删除（需确认）。状态由项目文件是否存在推导而来，没有单独的标志。
- **编辑器**：在非 vim 模式下，`F8` 删除当前行（或当前选区涉及的每一行）。只读缓冲区会忽略此绑定；剪贴板有意保持不变。

## 变更
- **VFS**：通过基于闭包的 `dispatch_remote` 辅助函数消除了提供程序分发中的重复代码（行为不变；从 `crates/vfs/src/lib.rs` 中删除了约 70 行代码）。
- **清理**：移除了三个未使用的公共辅助函数（`is_supported`、`is_language_supported`、`count_files_under`）；重新格式化了 `panel-terminal` 的测试代码，以消除两条 `clippy --all-targets` lint。

## 修复
- **编辑器**：在自动换行模式下，内联 blame 注释现在固定在光标所在逻辑行的最后一个换行行上。此前它试图跟随光标所在的确切换行行，而在长行上这一行往往塞满了代码，会把注释挤出右边缘——实际上根本看不见。
- **终端面板**：后台程序输出新内容时，用户在回滚缓冲区中的位置不再向实时末尾漂移。现在每当有一行进入回滚缓冲区，`scroll_up` 就会增加 `scroll_offset`（上限为回滚缓冲区长度），使可见窗口停留在相同的内容上。跟随末尾的用户（offset == 0）仍会像以前一样看到最新输出。
- **编辑器 → 命令**：通过模态窗口编辑项目命令的快捷键后，现在会使内存中的快捷键表失效，因此重新绑定立即生效，并在重启后保留。

## 安全
- **openssl** 升级到 `0.10.79`（经由 `native-tls → suppaftp → termide-vfs` 间接引入），修复了 GHSA-xv59-967r-8726 / CVE-2026-44662（带填充的 AES 密钥包装中的堆溢出）和 GHSA-xp3w-r5p5-63rr / CVE-2026-42327（`X509Ref::ocsp_responders` 在非 UTF-8 OCSP URL 上的未定义行为）。Termide 不会直接执行这两条代码路径。
