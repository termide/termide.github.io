## 新增
- **文件管理器**：在复制对话框中创建符号链接，并可沿符号链接导航
- **界面**：标题栏中按面板类型显示 emoji 图标
- **文件管理器**：字体样式区分——符号链接用斜体（ITALIC），可执行文件用粗体（BOLD）
- **文件管理器**：分组排序——目录 → 可执行文件 → 普通文件

## 变更
- **编辑器**：Git 边栏改为用背景色标示行号并自动调整对比度，而不是改变前景色
- **重构**：降低耦合，收紧可见性（`pub(crate)`），提取面板工厂
- **性能**：缓存 SFTP 文件名的内存分配，减少每帧的配置克隆
- **文档**：更新 README 和文档——CLI 选项、Ctrl+/ 切换注释、软件包管理器

## 修复
- **Git**：连续修改行的行内 diff 检测（Del…Del Ins…Ins 块现在能正确配对）
- **Git**：符号链接路径解析——加载 diff 时先 `canonicalize()` 再 `strip_prefix()`
- **Git 状态**：树形视图中目录标签的格式
- **界面**：复制/移动/符号链接/另存为对话框中路径的波浪号展开
- **文件操作**：防止删除符号链接时破坏其目标数据
- **文件管理器**：“..” 不再可被选中
- **界面**：折叠的面板标题中出现双重间距
