## Добавлено
- **Файловый менеджер**: создание символических ссылок из окна копирования и переход по символическим ссылкам
- **Интерфейс**: эмодзи-иконки типов панелей в заголовках
- **Файловый менеджер**: оформление начертанием шрифта — КУРСИВ для символических ссылок, ЖИРНЫЙ для исполняемых файлов
- **Файловый менеджер**: сортировка по группам — каталоги → исполняемые файлы → обычные файлы

## Изменено
- **Редактор**: git-полоса окрашивает фон номеров строк с автоматическим контрастом вместо цвета текста
- **Рефакторинг**: снижена связанность, сужена видимость (`pub(crate)`), вынесена фабрика панелей
- **Производительность**: кэшируются аллокации имён файлов SFTP, меньше клонирования конфигурации на каждом кадре
- **Документация**: обновлены README и документация — параметры CLI, комментирование по Ctrl+/, менеджеры пакетов

## Исправлено
- **Git**: определение встроенного diff для идущих подряд изменённых строк (блоки Del…Del Ins…Ins теперь правильно сопоставляются)
- **Git**: разрешение путей символических ссылок — `canonicalize()` перед `strip_prefix()` при загрузке diff
- **Git статус**: формат подписи каталогов в дереве
- **Интерфейс**: раскрытие тильды в путях в окнах копирования, перемещения, создания символической ссылки и «Сохранить как»
- **Файловые операции**: удаление символической ссылки больше не уничтожает данные цели
- **Файловый менеджер**: «..» больше нельзя выделить
- **Интерфейс**: двойные пробелы в заголовках свёрнутых панелей
