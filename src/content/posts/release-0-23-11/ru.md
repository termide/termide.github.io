## Добавлено
- **Несколько панелей «Git статус».** Открытие Git статуса (`Alt+G` / меню «Инструменты») теперь всегда создаёт новую панель, а не переводит фокус на существующую, так что за несколькими репозиториями можно следить одновременно — каждая панель отслеживает свой репозиторий, выбранный в выпадающем списке.

## Безопасность
- Вспомогательная программа SSH askpass теперь передаёт парольную фразу ssh прямой записью в stdout, а не макросом `print!`. Поведение не изменилось (ssh читает её из принадлежащего ему канала — никогда не из терминала и не из лога); это лишь не даёт статическому анализу принять контракт askpass за запись открытого текста в лог.
