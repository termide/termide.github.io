## 不兼容变更
- **`Alt+1`…`Alt+9` 切换已打开的项目，而不再切换面板组。** 已打开的项目现在像标签页一样保持你给定的顺序，因此它们的编号固定不变。按编号跳转到面板组（`goto_panel_N`）默认不再绑定；如果你用过它，请在 **设置 → 快捷键** 中绑定。旧版本保存到 `config.toml` 中的 `goto_panel_N = "Alt+N"` 会让位给项目；若要把数字键留给面板，还需在同一文件中把 `goto_project_N` 改到其他按键。
- **`[ai.auto_reviewer]` 是一个表**，包含 `connection` 和 `model`；只指定模型时，在会话的连接上进行审查。`[ai]` 下旧的 `auto_reviewer = "<connection>"` 会被丢弃并给出警告：请把它以 `connection = "<connection>"` 的形式移到该表中。

## 新增
- **用于远程登录的密码库。** SFTP、FTP/FTPS、PostgreSQL、MySQL 以及通过 HTTPS 或 SSH 的 git 在密码被拒绝时会询问密码，并可将其保存在以主密码加密的密码库中（`~/.config/termide/vault.toml`）。密码只有在服务器接受后才会保存，保存时从不需要主密码；密码库在空闲 `[vault] lock_after_mins` 后自动锁定，也可从命令面板锁定。保存 URL 中含有密码的书签时，会提议把密码移入密码库。参见 [密码库](https://github.com/termide/termide/blob/main/doc/zh/passwords.md)。
- **已打开的项目在菜单栏中显示为按钮**，当前项目高亮，等待中的项目带 🔔。单击即可切换；拖动按钮，或在 `项目` 菜单、切换器或菜单栏上使用 `Alt+PgUp`/`Alt+PgDn`/`Alt+Home`/`Alt+End` 来重新排列项目，`Delete`/`F8` 关闭项目。顺序会随项目集合一起保存和恢复。在 `项目` 菜单中对当前项目按 `Delete`/`F8` 现在会关闭它并回到最后离开的项目。
- **`termide -r` / `--restore`** 在启动时重新打开上次运行的项目，并进入上次运行时所在的项目。没有已保存的集合时它就是普通启动，因此可以放心地用在 shell 别名中。
- **代理运行失败时提供后续选择。** 订阅额度限制、速率限制或网络中断会被识别出来，连同其重置时间，面板会提议等到重置、重试、持续重试、压缩上下文、重启已退出的外部代理、切换代理或停止。重试不会发送新消息。`[ai] on_limit = "ask" | "wait" | "stop"` 让无人值守的 `/goal` 或 `/loop` 可以等待限制解除。
- **子代理并行工作，并可使用任意连接。** 一次回复中的只读调用（读取、搜索、抓取、`recall`、仅查看的命令）和委派任务现在会同时运行。连接可在 `subagents` 中指定其受托代理在何处运行；在 Claude Code 上，受托代理可以是一个全新的 Claude Code 会话。子代理获得 MCP 服务器的工具，在任务块中显示其工具调用，遵守代理的子代理轮次限制，并且它们的 token 与 `auto` 审查模型的一样计入会话总数。
- **用 `max_concurrent_requests` 限制连接同时处理的请求数**，这样多个面板、子代理和审查模型就不会挤占本地服务器；等待中的请求显示 ⏳ 及其在队列中的位置。
- **每个连接都可以指定其 `auto` 模式审查模型**，Claude Code 或 Codex 订阅也可以充当审查模型。外部代理现在也会在 `auto` 模式下接受审查。
- **外部代理与内置循环看齐。** 在代理支持的情况下，回合进行中输入的消息会引导该回合；模型、推理级别以及代理的其他选项（在新的 **选项** 标签上）可随时切换，并在重新打开后保留；代理自己的斜杠命令会加入 `/` 列表；`/goal` 和 `/handoff` 可用；Codex 和 Gemini CLI 获得 `recall`、`skill`、`question` 和 `suggest_command`。**模型** 标签显示模型自己的名称，代理启动时显示加载动画。
- **代理 `AGENT.md` 中的 `icon`** 会替换其面板标题、代理选择器和 AI 菜单中的 🤖。
- **六款夜路主题**：`black-earth`、`moonlit-dew` 和 `fireflies`，以及与之配对的日间浅色主题 `dry-path`、`morning-mist` 和 `summer-meadow`。

## 变更
- **在聊天块上打字会输入到提示框**，而不是被吞掉。
- **第一次单击未获得焦点的代理面板只会聚焦它。**
- **代理的欢迎横幅作为一整页滚动**，因此在较矮的面板上，各字段会为最近会话腾出空间。
- **`suggest_command` 在聊天中显示为 shell 调用**，并有自己的「建议」动作。
- **项目菜单中不再有「切换项目」项**；其下方的列表和 `Alt+\` 起到相同作用。
- **权限指南说明代理工具在无沙箱的情况下运行**：权限是一种控制手段，而不是隔离。

## 修复
- **复制代理回答时会复制其绘制的行**：`›` 标记、代码块竖线以及面板换行处的断行，导致复制的命令无法运行。
- **未使用的代理面板在项目重新打开时会忘记其连接、模型和选项**，并且切换连接或代理会清空提示框。
- **`termide -r` 会把启动时所在的目录**加入已保存的项目集合。
- **日志的级别标签无法通过键盘切换**；现在直接按 `1`…`5` 即可。
- **发送给外部代理的消息在其回合已取走后仍留在队列条上。**
- **Claude Code 在回复中把命令写成 `! cmd`**，而不是在卡片上提供它们。
- **子代理在停止后仍继续运行**，直到它的下一个事件，并且在等待空位时什么也不显示。
- **连接密码可能出现在调试日志中。**
