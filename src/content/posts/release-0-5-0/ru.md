## Добавлено
- Вставка символа табуляции по Tab в редакторе и сдвиг блока вправо/влево (Tab/Shift+Tab)
- Отслеживание внешних изменений файла с диалогом «перезагрузить/закрыть»
- Панель просмотра логов с отрисовкой на основе редактора (курсор, поддержка выделения)
- Прокрутка мышью по положению курсора, а не по панели в фокусе
- Рекурсивное отслеживание файлов в git-репозиториях

## Изменено
- **Крупный рефакторинг архитектуры**: из монолитного src/ выделено 31 крейт рабочего пространства
  - Модульная структура крейтов: app, app-core, app-event, app-modal, app-panel и другие
  - Сборка стала быстрее благодаря инкрементальной компиляции
  - Код лучше организован, ответственность чётче разделена
- Типобезопасная архитектура взаимодействия панелей
  - Перечисление `PanelCommand` вместо небезопасного приведения через `dyn Any`
  - Перечисление `CommandResult` для типобезопасных ответов на команды
  - Метод `handle_command()` в трейте Panel
- Объединён код модальных диалогов
  - Общая отрисовка рамки с кнопкой закрытия [X]
  - Общая отрисовка поля ввода с курсором
  - Меньше дублирования кода в диалогах поиска и замены
- Конфигурация переведена на вложенные секции TOML
- Асинхронное вычисление git diff, чтобы интерфейс не зависал
- Обновления файловой системы учитывают .gitignore

## Исправлено
- Файловый менеджер сохраняет позицию курсора после удаления файла
- Копирование и вставка больше не вызывают нежелательную прокрутку
- Время изменения файлов показывается в местном часовом поясе
- Размеры файлов округляются до целых единиц и выравниваются по правому краю
- Устранено дублирование git diff, из-за которого зависал интерфейс
- Петли обратной связи наблюдателя ФС и отображение удалённых файлов

## Производительность
- Асинхронный git diff и обновления ФС с учётом .gitignore
- Кэширование `find_repo_root()` и ограничение частоты обновления индикатора загрузки
- Условная перерисовка снижает нагрузку на CPU в простое
- Оптимизация памяти: убраны лишние клонирования

## Тесты
- Модульные тесты PanelCommand и CommandResult (7 тестов в core)
- Интеграционные тесты handle_command редактора (9 тестов)
- Интеграционные тесты handle_command файлового менеджера (8 тестов)
- Тесты базового модуля модальных окон (4 теста)
- Тесты работы с большими файлами (7 тестов)
  - Загрузка и навигация по файлам от 10 тыс. строк
  - Бенчмарк прокрутки (50 тыс. строк менее чем за 100 мс)

## Качество кода
- Ни одного комментария TODO/FIXME в рабочем коде
- Все 5 блоков unsafe снабжены комментариями SAFETY
- Более 21 критичного вызова `unwrap()` заменены на `expect()` с поясняющими сообщениями
- Исправлено проглатывание ошибок в `handle_key()` редактора — теперь ошибки показываются пользователю
- Удалён мёртвый код: неиспользуемое событие `RequestDirSize` и методы трейта `PanelProvider`
- Оптимизирован `get_selected_text()` — при больших выделениях он больше не копирует весь буфер
