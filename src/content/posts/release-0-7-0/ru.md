## Добавлено
- **ImagePanel**: встроенный просмотр изображений через графические протоколы терминала (Kitty, Sixel, iTerm2)
- **Изменение размеров панелей**: границу панели можно перетаскивать мышью
- **Клавиша F3**: просмотр файла без запуска (исполняемые файлы открываются в редакторе)
- **Shift+Enter**: принудительно открыть файл системным приложением (xdg-open)
- **Запуск по Enter**: исполняемые файлы запускаются прямо в терминале
- Умное определение типа файла: растровые изображения → ImagePanel, векторные, видео и двоичные → xdg-open

## Исправлено
- Список сессий: курсор теперь встаёт на текущую сессию
- Редактор: ошибка на единицу в умном переносе по словам
- Диалог «Сохранить как»: теперь использует рабочий каталог файлового менеджера

## Изменено
- Параметр конфигурации `min_panel_width` разделён на отдельные параметры для более тонкой настройки
- Определение двоичных файлов вынесено в общую утилиту (`core::util::is_binary_file`)

## Документация
- Документация файлового менеджера дополнена новыми сочетаниями клавиш (F3, Shift+Enter)
- Обновлены экраны справки на всех 9 языках
