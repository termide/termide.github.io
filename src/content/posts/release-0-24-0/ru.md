## Добавлено
- **Просмотрщик баз данных (только чтение).** Просматривайте таблицы **SQLite**, **PostgreSQL** и **MySQL/MariaDB** из закладки, путь которой — URL базы данных (`sqlite:///…`, `postgres://…`, `mysql://…`). Панель подключается в фоне и показывает строки в двумерной сетке с курсором по ячейкам, постраничной загрузкой скользящим окном, сортировкой на стороне сервера по одному столбцу (по возрастанию → по убыванию → без сортировки), фильтрацией по столбцам с учётом типа (условия объединяются через `AND`), диалогом со всей строкой (копирование как TSV / JSON / INSERT) и копированием ячейки или строки. Если в URL не указана база данных (PostgreSQL/MySQL), её можно выбрать в списке (первая выбирается автоматически); панель восстанавливается между сессиями. Запросы выполняются в фоновой среде, так что интерфейс никогда не блокируется; всё строго только для чтения (только запросы `SELECT` и запросы к каталогу). Клавиши действий настраиваются в `[database.keybindings]` и показаны в справке; мышью можно открывать списки выбора, сортировать щелчком по заголовку столбца и перемещать курсор щелчком по ячейке. См. [Просмотрщик баз данных](https://github.com/termide/termide/blob/main/doc/ru/database.md).
- **Поддержка Android / Termux.** В релизы теперь входит статически скомпонованный бинарник `aarch64-unknown-linux-musl`, который работает в Termux; см. документацию по установке.

## Исправлено
- Панель «Операции» больше не предлагает **Паузу** для операций со скриптами и командами (реализовать её для них было невозможно); **Отмена** по-прежнему останавливает их, завершая процесс. Пауза и продолжение остаются для передачи файлов.
