## Добавлено
- **Встроенные панели поиска и замены.** Поиск и замена в редакторе, а также поиск по имени и по содержимому в файловом менеджере теперь встроены в свои панели, а не открываются плавающими модальными окнами: результаты обновляются на лету, элементы управления работают с мышью, `Esc` закрывает панель, а `Tab`/`Shift+Tab` переводят фокус между формой и результатами.
- **Переключатели регулярных выражений и регистра в поиске и замене.** Поиск (`Ctrl+F`) и замена (`Ctrl+H`) в редакторе, поиск по имени и поиск по содержимому в файловом менеджере получили переключатели `[.*] Regex` и `[Aa] Case`. При включённых регулярных выражениях в замене поддерживаются группы захвата `$1` / `${name}`.
- **Поиск и замена по всему проекту** в поиске по содержимому файлового менеджера. Введите замену в новом поле `Repl:`, просмотрите изменения в виде `-old/+new`, выберите затрагиваемые файлы флажками у каждого файла или кнопкой **Выделить всё** и примените замену после подтверждения.

## Изменено
- **Результаты поиска проще просматривать и перемещаться по ним.** Результаты поиска по содержимому в файловом менеджере сгруппированы по файлам со сворачиваемыми заголовками, счётчиками совпадений, ограниченной строкой `+ N more` для остатка, переходами по папкам и файлам и областями щелчка для сворачивания и выбора.
- **НЕСОВМЕСТИМОЕ ИЗМЕНЕНИЕ (поведение поиска):** поиск по содержимому в файловом менеджере теперь **по умолчанию буквальный** — запрос сопоставляется дословно. Для поиска по шаблону включите `[.*] Regex`. Раньше запрос всегда был регулярным выражением.
- Установка из исходников в документированном установщике теперь использует `cargo install --git`, минуя устаревший пакет на crates.io.

## Исправлено
- Переключение панелей из стопки в положение рядом больше не открывает отделённую панель с минимальной шириной; при повторных разделениях и объединениях ширины остаются стабильными.
- Ошибки замены текущего совпадения в редакторе теперь показываются в строке состояния, а не отбрасываются молча.
- Сопоставление имён в файловом менеджере теперь единообразно учитывает переключатель регистра и в поиске по имени, и в масках поиска по содержимому.
