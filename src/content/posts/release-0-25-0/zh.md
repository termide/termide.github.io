## 新增
- **内联搜索与替换栏。** 编辑器的查找/替换以及文件管理器的名称/内容搜索现在停靠在各自的面板内，而不是打开浮动的模态框；它们提供实时结果、可用鼠标操作的控件、`Esc` 关闭行为，以及用 `Tab`/`Shift+Tab` 在表单与结果之间移动焦点。
- **搜索与替换中的正则和大小写开关。** 编辑器的搜索（`Ctrl+F`）和替换（`Ctrl+H`）、文件管理器的名称搜索以及文件管理器的内容搜索现在都有 `[.*] Regex` 和 `[Aa] Case` 开关。开启正则时，替换支持 `$1` / `${name}` 捕获组。
- **全项目查找与替换**，位于文件管理器的内容搜索中。在新的 `Repl:` 字段中编写替换内容，以 `-old/+new` 形式预览更改，用逐文件的复选框或 **全选** 选择受影响的文件，确认后应用替换。

## 变更
- **搜索结果更易浏览和导航。** 文件管理器的内容搜索结果按文件分组，带可折叠的标题、匹配计数、有上限的 `+ N more` 溢出行、文件夹/文件导航，以及用于折叠和选择的点击区域。
- **不兼容（搜索行为）：** 文件管理器的内容搜索现在**默认按字面匹配** —— 查询原样匹配。需要模式搜索时请开启 `[.*] Regex`。此前查询总是被当作正则表达式。
- 从源码安装现在在文档所述的安装路径中使用 `cargo install --git`，避免使用已过时的 crates.io 包。

## 修复
- 将面板从堆叠切换为并排时，分离出的面板不再以最小宽度打开；反复拆分/合并切换现在会保持稳定的宽度。
- 编辑器“替换当前项”失败时现在会显示在状态栏中，而不是被悄悄丢弃。
- 文件管理器的名称匹配现在在名称搜索和内容搜索的掩码中一致地应用大小写开关。
