## Добавлено
- **Интерфейс**: окно календаря по щелчку на часах — сетка месяца с переходом по дням (стрелки, PgUp/PgDn для месяцев, Home для перехода к сегодняшнему дню)
- **Интерфейс**: цветные заголовки панелей и улучшенное оформление строки состояния
- **Git лог**: открытие коммита в браузере по `o` / `Shift+Enter`
- **VFS**: подключение по FTP/FTPS и SMB через ввод в адресной строке

## Изменено
- **Рефакторинг**: устранено дублирование утилит для графем — они перенесены в общий крейт `termide-ui`
- **Рефакторинг**: почищена отрисовка строки меню, удалена переменная окружения `TERMIDE_LANG`
- **Производительность**: исправлены аллокации при отрисовке и обработка ошибок SMB
- **Документация**: документация синхронизирована с последними изменениями возможностей
