## Добавлено
- **Открытие баз данных без закладки.** `Enter` или `F3` на файле `.db` / `.sqlite` / `.sqlite3` / `.db3` в файловом менеджере теперь открывает его в просмотрщике баз данных (а не в hex-просмотрщике).
- **`Окна ▸ Открыть…`** — универсальное окно открытия (заменяет прежний пункт `Web` и теперь стоит первым в меню), которое направляет введённое по типу: файл (по расширению), каталог (файловый менеджер), URL базы данных (`sqlite://` / `postgres://` / `mysql://`) или адрес `http(s)://`. `Ctrl+G` в любом просмотрщике работает так же.

## Исправлено
- Выпадающие списки таблиц и баз данных в просмотрщике баз данных теперь рисуются с рамкой, как списки выбора ветки и репозитория в git-панели (раньше они выводились списком без рамки).
- Сетка данных в просмотрщике баз данных теперь показывает полосы прокрутки на рамке панели: вертикальную на правой границе (положение во всей таблице, с учётом страниц) и горизонтальную на нижней границе, когда столбцы шире панели. Раньше не было видно ни сколько осталось страниц, ни что столбцы уходят за край экрана.
- **Файловые и git-панели теперь отслеживают внешние изменения на лету.** Из-за ошибки в наблюдателе слежение за каталогами git-репозитория на деле никогда не устанавливалось, поэтому файловый менеджер и git-панели обновлялись только при получении фокуса или навигации — изменения из терминала (или от агента) будто бы игнорировались. Исправлено, а также: каталоги, созданные после открытия панели, теперь тоже отслеживаются; файловый менеджер пересчитывает git-статус по событиям наблюдателя, а не берёт устаревший кэш; панели git log и git diff обновляются по событиям наблюдателя (и при получении фокуса), а не только при ручной перезагрузке; перезагрузка каталога, поглощённая во время всплеска изменений, повторяется, так что итоговое состояние всегда отображается; задержка наблюдателя уменьшена (debounce для файлов 1000→300 мс, для git теперь фиксированное окно 250 мс, которое не сбрасывается при каждом изменении).
