## 新增
- **无需书签即可打开数据库。** 在文件管理器中对 `.db` / `.sqlite` / `.sqlite3` / `.db3` 文件按 `Enter` 或 `F3`，现在会在数据库查看器中打开它（而不是十六进制查看器）。
- **`Windows ▸ Open…`** —— 一个通用的打开提示框（取代旧的 `Web` 项，现在是菜单中的第一项），按类型分派你输入的内容：文件（按扩展名）、目录（文件管理器）、数据库 URL（`sqlite://` / `postgres://` / `mysql://`）或 `http(s)://` 地址。在任何查看器中按 `Ctrl+G` 都有相同的行为。

## 修复
- 数据库查看器的表和数据库下拉列表现在会绘制边框，与 git 面板的分支/仓库选择器一致（此前它们显示为没有边框的列表）。
- 数据库查看器的数据网格现在会在面板边框上显示滚动条：右边框上的垂直滚动条（表示在整张表中、跨页的位置），以及列宽超出面板时底边框上的水平滚动条。此前既看不出还剩多少页，也看不出有列延伸到了屏幕之外。
- **文件和 git 面板现在会实时跟踪外部更改。** 由于一个监视器缺陷，git 仓库的逐目录监视实际上从未被安装，因此文件管理器和 git 面板只在获得焦点或导航时刷新 —— 在终端（或代理）中做出的更改看起来像是被忽略了。现已修复，此外：面板打开之后创建的目录现在也会被监视；文件管理器在监视器事件发生时重新计算 git 状态，而不再复用过时的缓存；git 日志和 git diff 面板会根据监视器事件（以及获得焦点时）刷新，而不只是在手动重新加载时；在一连串更改中被合并掉的目录重新加载会重试，确保最终状态总能呈现；监视器延迟也更低了（文件防抖 1000→300 ms，git 防抖现在是固定的 250 ms 窗口，而不是每次更改都重新计时）。
