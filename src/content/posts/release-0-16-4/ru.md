## Исправлено
- **Статус Git**: кнопка «Получить» молча обрезалась в узких панелях — теперь кнопки переносятся на следующую строку, а не обрезаются
- **Статус Git**: порядок кнопок изменён на «Получить» → «Отправить» → «Различия» → «Коммит», чтобы самые важные действия синхронизации шли первыми и всегда были видны
- **Git**: файлы внутри неотслеживаемых папок теперь правильно отображаются как добавленные в git-статусе файлового менеджера
- **Приложение**: ошибки `git fetch` теперь показываются в строке состояния, а не молча проглатываются
- **CI**: PKGBUILD для AUR теперь синхронизируется из репозитория перед подстановкой версии

## Изменено
- **Статус Git / Приложение**: панели Git (git-status, git-log) теперь обновляют список репозиториев, когда пользователь переходит в другую папку, так что панель показывает текущий репозиторий без ручного обновления
- **Рефакторинг**: `ThemeColors` теперь выводит `Copy` — это убирает выделения памяти в куче на каждом кадре отрисовки
- **Рефакторинг**: параллельные поля деревьев `unstaged_*` / `staged_*` в `GitStatusPanel` объединены в одну структуру `FileTree`, что убрало 8 лишних полей
- **Рефакторинг**: повторяющийся код отрисовки заголовков в панели git-status вынесен в переиспользуемые вспомогательные функции (вместо 4 мест вызова — 2)
