## Исправлено
- **Запросы SSH и учётных данных больше не портят интерфейс.** При открытии репозитория выполняется автоматический fetch, а push/pull/fetch запускались с подключённым терминалом, поэтому, когда ssh требовалась парольная фраза ключа, он рисовал запрос прямо поверх TUI. Теперь сетевые операции git выполняются неинтерактивно (отключённый stdin, `GIT_TERMINAL_PROMPT=0`, `BatchMode` для ssh): ключ, уже загруженный в ssh-agent, просто работает, а при его отсутствии операция аккуратно завершается ошибкой. О неудачном автоматическом fetch сообщается в строке состояния, а не во всплывающем модальном окне.

## Добавлено
- **Ввод парольной фразы SSH-ключа в модальном окне для git push/pull/fetch.** Когда операции нужна парольная фраза, которой нет в ssh-agent, termide теперь запрашивает её в модальном окне со скрытым вводом и повторяет попытку (через закрытую кратковременную передачу askpass), а не завершается ошибкой. Парольная фраза кэшируется в памяти на время сессии, чтобы повторные операции не спрашивали её снова; она никогда не записывается в конфигурацию и нигде не сохраняется.
