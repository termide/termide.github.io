## Исправлено
- Панели git status и git log больше не сбрасывают выбранный репозиторий при работе в каталоге со множеством git-проектов. Навигация (которая заново строит список репозиториев) отбрасывала асинхронно найденные вложенные репозитории и подмодули, и выбор сбрасывался на первый репозиторий; теперь список репозиториев объединяется, а не заменяется, так что выбор сохраняется.
- Просмотрщик диаграмм теперь показывает горизонтальную полосу прокрутки на нижней границе для диаграмм шире панели, так что видно, где по оси X находится область просмотра (и что справа есть ещё). Раньше рисовалась только вертикальная полоса прокрутки.
- Раскладка диаграмм стала сбалансированнее: узлы одного ранга теперь центрируются относительно связанных с ними соседей, а не смещаются в одну сторону, так что узел-концентратор со множеством связей (например, сущность, на которую ссылаются многие другие в ER-диаграмме) располагается симметрично над своими соседями. Это убирает широкие пустые промежутки и длинные соединительные линии, из-за которых первые блоки оказывались далеко слева, и делает широкие диаграммы заметно уже.
