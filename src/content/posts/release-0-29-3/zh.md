## 修复
- 在包含许多 git 项目的目录中工作时，git 状态/日志面板不再重置所选仓库。导航（会重新推导仓库列表）此前会丢掉异步发现的嵌套仓库和子模块，把选择重置为第一个仓库；现在仓库列表是合并而非替换，因此选择得以保留。
- 对于比面板更宽的图表，图表查看器现在会在底边框上显示水平滚动条，让你知道视图在 X 轴上的位置（以及右侧还有更多内容）。此前只绘制垂直滚动条。
- 图表布局更加均衡：同一层级的节点现在以与其相连的邻居为中心排列，而不是偏向一侧，因此连接众多的枢纽节点（例如 ER 图中被许多实体引用的实体）会对称地跨在其邻居之间。这消除了把最前面的方框远远甩到左侧的宽阔空白通道和长连线，并让宽图表明显变窄。
