## 新增
- **压缩包在文件管理器中像目录一样打开。** 在 zip、tar（普通、`.gz`、`.bz2`、`.xz`、`.zst`）或 ISO 9660 镜像上按 `Enter`，会以只读方式列出其内容；在其根目录按 `..` 或 `Backspace` 则返回到存放它的目录。其中的文件可以查看、复制和解压，并带有进度、暂停和取消；会修改压缩包的命令则一开始就被拒绝。压缩包无论放在哪里都能打开：本地磁盘、已连接的服务器，或是另一个压缩包内部。加密的 zip（ZipCrypto 或 AES）会询问密码，输错后会再次询问。俄文版 Windows 写入的 zip 文件名（CP866）现在显示为西里尔字母，而不是制表符；ISO 镜像如果带有 Rock Ridge 或 Joliet 名称，则显示这些名称。条目名称被视为不可信：任何内容都不会被解压到目标目录之外。参见 [`doc/en/vfs.md`](https://github.com/termide/termide/blob/main/doc/zh/vfs.md)。
- **用 `P` 将选中项打包为压缩包。** 文件管理器会询问写入位置，默认是选中项旁边的 `<name>.zip`，后缀决定格式：zip 或 tar（普通、`.gz`、`.bz2`、`.xz`、`.zst`）。权限、修改时间和符号链接都会保留；压缩包只在完成后才出现；已有文件绝不会被覆盖；打包过程显示在操作面板中。快捷键为 `file_manager.keybindings.pack`。
- **按模型设置推理级别。** **推理** 标签现在会打开级别选择器（off、minimal、low、medium、high、xhigh、max），只提供模型接受的级别；模型无法被要求推理时，该标签会隐藏。此前开/关开关根本没有传到服务器，所以实际上没有任何模型被要求推理。Anthropic 模型使用自适应思考或思考预算；OpenAI 兼容连接通过 `reasoning_param` 选择请求方式（`reasoning_effort`、聊天模板的 `enable_thinking`，或不请求）。`[ai] reasoning` 取代了 `prefer_reasoning`，后者仍会被读取为 `high` 或 `off`。
- **实时显示预填充。** 在第一个 token 到达之前，底栏会显示模型已读取提示词多长时间，以及提示词的大致大小。在连接上开启 `prefill_progress`（设置模态窗口中也可开启）后，llama.cpp 服务器会报告进度，这一行会显示进度条、已读取的 token 数与总数，以及速度。
- **代理欢迎横幅上的最近会话。** 新会话的横幅会列出该目录的其他会话，最新的在前。单击或按 `Enter` 打开其中一个，`Tab` 进入列表，`Delete`/`F8` 删除光标下的会话。已在其他面板中打开的会话不会列出。横幅现在位于面板顶部，把下方的空间留给列表。
- **将网页保存为 Markdown。** `Ctrl+S`，或 HTML 查看器 `[≡]` 菜单中的 **将页面另存为 Markdown…**，会保存页面的标题、列表、代码、表格和链接，相对链接转换为绝对链接。与阅读模式一样，它保留页面的主体内容，略去导航、侧边栏和页脚。应 [#56](https://github.com/termide/termide/issues/56) 的请求而添加。
- **网页会显示正在加载。** 对 URL 按 `Ctrl+G` 会立即打开查看器，标题中显示加载动画和 URL，页面到达后填充内容，或显示错误。点击链接后，当前页面保留在屏幕上，标题转动加载动画，直到下一个页面到达。多个页面可以同时加载，关闭查看器会取消其请求。
- **HTML 和 Markdown 查看器中的 `Ctrl+A`** 会选中整个文档，这样 `Ctrl+C` 就能复制整页。
- **提示词模板中的条件段落。** `{{if name}} … {{else}} … {{/if}}` 在值为空时去掉该段落。内置系统提示词用它来略去空段落，例如没有技能的会话中的技能段落。
- **代理的 `tools` 列表可以不包含 `task`**，这样该代理就无法委派任务。
- **清单分组可从标题切换。** 在 **工具** 选择器中，分组标题上的复选框会切换整个分组，分组部分开启时显示 `[-]`。
- **AI 菜单列出代理、技能和提示词及其描述。**

## 变更
- **「始终允许」和「本次会话内允许」只在规则能为其允许的调用担保时才提供。** 在权限卡片上点一下就可能授予 `rm *`、`git push *` 或 `env *`，而后者还会为 `env` 运行的任何程序担保。现在持久授权要求单条命令且其程序已知；对于会破坏所操作对象的命令，或运行的程序无法从名称看出的命令，两种持久授权都不再提供。本次会话内拒绝仍然可用。
- **内置系统提示词更短了。** 它不再列出工具，模型本来就会连同描述一起收到这些工具。它也不再包含日期——日期在长会话中会过时，而且是 UTC 时间；取而代之的是，它告诉模型用工具去查看日期、文件或历史，而不是猜测，并在没有查看时说明。
- **空的 `SOUL.md` 表示没有系统提示词。** 此前它会回退到内置提示词。
- **在模态窗口外单击即可关闭它**，与按 `Esc` 相同：选择列表、清单、输入提示、确认框和信息窗口。代理面板打开的选择器以前只能用 `Esc` 退出。
- **文件管理器在包含巨大被忽略目录的仓库中不再卡顿。** Git 状态以前会遍历每个被忽略的目录，在 `target/` 很大时每次加载目录最多耗时 19 秒。对于没有被任何忽略规则匹配、但只包含被忽略文件的目录，现在将其中的文件显示为暗色，而不是目录本身。
- **文件管理器的状态和项目计数已翻译**为全部十五种语言。

## 修复
- **带缩进的文件会把屏幕弄乱。** 自 0.35.0 起，编辑器中的 TAB 被原样写到终端，导致该行剩余部分落到下一个制表位，屏幕逐渐填满先前帧的碎片，在所有终端上都是如此。现在控制字符在编辑器、状态栏和其他文本单元格中显示为空白。由 [#55](https://github.com/termide/termide/issues/55) 报告。
- **西里尔键盘布局下的 `Ctrl` 快捷键。** `Ctrl+С` 无法中断终端中的程序；现在在其他布局的字母上按 `Ctrl` 组合键，会作为同一手指位置下的拉丁字母键发出。文本字段（全选、复制、剪切、粘贴、撤销）、查找栏的 `Ctrl+R`，以及模态窗口和面板的字母快捷键（`y`/`n`、`j`/`k`、`q` 等）现在也在任何布局下都能使用。
- **从服务器复制时可能复制成本地文件。** 批量复制或移动一个在本地也存在的远程路径（服务器上的 `/etc`）时，会从本地磁盘读取。现在源文件来自选中它们的那个面板。
- **命令中的 `$(…)` 会让整行的每个部分都要求确认**，而回答卡片可能会把 `cd *` 或 `ls *` 之类的规则写入配置，从而让对这些命令危险参数的内置检查失效。现在命令替换只对包含它的那一部分生效。
- **多行提示词在对话记录中显示为一行。**
- **代理提问中较长的选项和回答会被截断**；现在会自动换行。
- **另存为字段无法用鼠标选择**，在长路径上单击会落到错误的字符上。现在单击会放置光标，拖动会选择，粘贴会进入该字段。
- **在远程面板中返回上级目录时，光标停留在原来的行上**；现在会落在刚离开的目录上，与本地面板一致。
