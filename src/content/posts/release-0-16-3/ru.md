## Исправлено
- **Приложение**: свободное место на диске в строке состояния теперь кэшируется на каждый тик, а не запрашивается через `statvfs` при каждой отрисовке — это устраняет возможные блокировки на NFS-монтированиях при интенсивном вводе
- **Приложение**: интервал автообновления модальных окон ресурсов унифицирован — модальные окна CPU, RAM и диска используют параметр `resource_monitor_interval` (у окон процессов было жёстко задано 3 с); интервал по умолчанию изменён с 1 с на 2 с

## Изменено
- **Приложение**: модальное окно диска теперь обновляется по тику, как окна CPU и RAM
- **Рефакторинг**: в путях VFS и файловых операций сохраняются исходные типы ошибок; удалён мёртвый код; оптимизирован горячий путь отрисовки
