## Изменено
- Оптимизирована производительность панели терминала
  - `has_pending_output()` в цикле событий для эффективного запуска перерисовки
  - Заранее выделяемый Vec для span'ов, чтобы сократить число аллокаций
  - Методы VecDeque со сложностью O(1) для операций с нулевой строкой
- Прекращена публикация на crates.io (распространение через GitHub Releases, только deb/rpm)

## Исправлено
- Git-статус в окне сведений о файле теперь показывает реальное число изменений
- Курсор файлового менеджера сбрасывается на позицию 0 при входе в подкаталог
- Согласованы версии крейтов modal, panel-editor и ui-render
