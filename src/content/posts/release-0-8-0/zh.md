## 新增
- **Git 状态面板**：完整的 git 状态面板，显示已暂存/未暂存的文件，并提供提交/推送/拉取操作
- **Git 日志面板**：查看提交历史并在其中导航
- **会话菜单**：通过 Ctrl+S 菜单新建会话、切换会话、更改会话根目录
- **CommitModal**：多行文本框，用于输入提交信息，带有“提交”/“取消”按钮
- **TextArea 组件**：多行文本输入，支持二维光标、选区、撤销/重做和剪贴板
- **输入框改进**：模态框输入框支持文本选择、撤销/重做（Ctrl+Z/Y）和剪贴板

## 修复
- 模态框输入框：UTF-8 处理、剪贴板操作、文本选择
- 折叠面板的标题：现在显示截断后的标题，而不是空字符串
- Git 状态面板标题：正确显示仓库名、分支和状态标记

## 变更
- Git 状态面板：刷新时显示旋转图标，状态数字移到面板标题中
- InlineSelector 组件：改进样式与交互
