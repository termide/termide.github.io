## 新增
- **LSP 集成**：完整支持语言服务器协议（Language Server Protocol），包括补全、诊断、悬停提示和跳转到定义
- **Git 差异面板**：GitHub 风格的 diff 查看器，可从 Git 日志面板查看某次提交的 diff
- **另存为模态框**：新对话框带有“可执行”复选框，用于设置文件权限（Ctrl+Shift+S）
- **报告脚本**：文件名带 `.report.` 后缀的脚本在后台运行，并在模态对话框中显示输出
- **运行时切换语言**：随时切换界面语言，支持 15 种语言
- **动态帮助面板**：用随上下文变化的帮助取代静态的 WelcomePanel
- **Git 状态增强**：没有仓库时显示“初始化”按钮，路径从左侧以省略号截断，文件属性信息更丰富
- **终端功能**：识别文件路径、跨行链接高亮、支持 bracketed paste（括号粘贴模式）
- **编辑器功能**：状态栏显示磁盘空间信息，改进 PageUp/PageDown 行为
- **界面改进**：使用 Unicode 省略号智能截断标题，统一的旋转加载动画

## 变更
- **菜单更名**：“工具”→“窗口”，“操作”→“脚本”，更易理解
- **快捷键**：Ctrl+Shift+S 现在打开“另存为”（原为强制保存）
- **子菜单更名**：“管理操作”→“管理脚本”
- **Git diff 样式**：文件标题与 termide 设计体系统一
- **重构**：大规模代码清理，采用命令模式（Command Pattern）、提取状态并合并辅助函数

## 修复
- **i18n**：格式化键移到正确的分节，警告改为输出到日志
- **Git**：通过解析 .gitmodules 识别子模块
- **复制/移动模态框**：移除重复的文本

## 文档
- **LSP 文档**：新增完整的 LSP 文档，附配置示例
- **脚本文档**：针对新的菜单名称和 .report. 后缀功能进行更新
- **编辑器文档**：加入 Ctrl+Shift+S 另存为快捷键
