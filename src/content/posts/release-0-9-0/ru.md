## Добавлено
- **Интеграция LSP**: полная поддержка Language Server Protocol с автодополнением, диагностикой, подсказками при наведении и переходом к определению
- **Панель диффа Git**: просмотр диффов в стиле GitHub, в том числе диффов коммитов из панели истории Git
- **Окно «Сохранить как»**: новый диалог с флажком «Исполняемый» для установки прав доступа к файлу (Ctrl+Shift+S)
- **Скрипты-отчёты**: скрипты с суффиксом `.report.` выполняются в фоне и показывают вывод в модальном окне
- **Смена языка на лету**: язык интерфейса меняется без перезапуска, поддерживается 15 языков
- **Динамическая панель справки**: статичная WelcomePanel заменена контекстной справкой
- **Улучшения статуса Git**: кнопка «Создать», когда репозитория нет, усечение путей с многоточием слева, расширенные свойства файлов
- **Возможности терминала**: распознавание путей к файлам, подсветка многострочных ссылок, поддержка bracketed paste
- **Возможности редактора**: сведения о свободном месте на диске в строке состояния, улучшенное поведение PageUp/PageDown
- **Улучшения интерфейса**: умное усечение заголовков с Unicode-многоточием, единые анимированные спиннеры

## Изменено
- **Переименование меню**: «Инструменты» → «Окна», «Действия» → «Скрипты» для большего удобства
- **Сочетания клавиш**: Ctrl+Shift+S теперь открывает «Сохранить как» (раньше — принудительное сохранение)
- **Переименование подменю**: «Управление действиями» → «Управление скриптами»
- **Стиль диффа Git**: заголовки файлов приведены к единой системе оформления termide
- **Рефакторинг**: масштабная чистка кода с паттерном Command, выделением состояния и объединением вспомогательных функций

## Исправлено
- **i18n**: ключи форматирования перенесены в правильный раздел, предупреждения перенаправлены в журнал
- **Git**: подмодули определяются разбором .gitmodules
- **Окна копирования и перемещения**: удалён дублирующийся текст

## Документация
- **Документация по LSP**: добавлено подробное описание LSP с примерами настройки
- **Документация по скриптам**: обновлена с учётом новых названий меню и суффикса .report.
- **Документация редактора**: добавлено сочетание Ctrl+Shift+S для «Сохранить как»
