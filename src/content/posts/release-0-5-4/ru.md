## Добавлено
- Окно переключения сессий (Alt+M → Сессии) для перехода между открытыми сессиями termide
- Статичный индикатор загрузки при инициализации наблюдателя файлов (вместо анимированного спиннера из символов Брайля)

## Исправлено
- Единый расчёт позиции курсора при переносе строк
- Смещение выделения мышью при включённом переносе строк
- Формат индикатора свободного места на диске (убран пробел перед единицей: «411/467GB»)

## Производительность
- Наблюдатель файлов теперь использует крейт `ignore`, чтобы пропускать каталоги из .gitignore

## Документация
- Структура проекта в README и документации по архитектуре обновлена с учётом крейтов рабочего пространства
- Раздел i18n обновлён: перечислены все 9 поддерживаемых языков
- В справку редактора добавлено Ctrl+D (дублирование строки)
