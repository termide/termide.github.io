## Исправлено
- Панель терминала: завершённое выделение текста больше не «залипает» после того, как приложение с отслеживанием мыши (например, агент) включает передачу событий мыши. Раньше любой следующий щелчок растягивал устаревшее выделение до точки щелчка, и убрать его было нельзя. Теперь выделение захватывает мышь, только пока действительно идёт перетаскивание, а щелчок в приложении с отслеживанием мыши убирает оставшуюся локальную подсветку.

## Изменено
- Копирование, вырезание и вставка теперь — единый набор **глобальных** сочетаний клавиш (`Ctrl+C` / `Ctrl+X` / `Ctrl+V`), которые передаются панели в фокусе, а не настраиваются отдельно для каждой панели. Каждая панель обрабатывает их по своим возможностям — редактор копирует, вырезает и вставляет выделенный текст, файловый менеджер — выбранные пути, база данных — текущую ячейку, git-панели — путь к файлу или хеш коммита. В **терминале** `Ctrl+C` копирует выделение, если оно есть, а иначе отправляет оболочке `SIGINT`, а `Ctrl+V` вставляет (раньше `Ctrl+Shift+C` / `Ctrl+Shift+V`). Привязки `copy` / `cut` / `paste` / `clipboard_copy` для отдельных панелей удалены из настроек; переназначьте их один раз в разделе **Глобальные**.

## Добавлено
- Строка состояния файлового менеджера теперь показывает поле **Размер:** с подписью (справа от **Владелец:**) для элемента под курсором — просто размер в байтах для файлов и `<size> (N items)` для каталогов, где `N` — число непосредственных (без рекурсии) дочерних элементов. Это соответствует окну свойств (`Space` / `F12`), где строка **Размер** так же дополняется числом элементов в скобках (например, `1.2 MB (42 items)`); число появляется сразу, пока рекурсивный размер ещё вычисляется.
