## Добавлено
- **Панель предпросмотра HTML.** Файлы `.html` / `.htm` открываются в отрисованном виде только для чтения (`F3`) со всеми возможностями просмотрщика — подвижным курсором, выделением текста, копированием в буфер обмена, инкрементальным поиском (`Ctrl+F`), перезагрузкой с диска (`Ctrl+R`) и переключением на редактируемый исходник по `Ctrl+E`. Поддерживаемое подмножество тегов оформляется (заголовки, списки, таблицы, `<pre>`/`<code>`, `<kbd>`/`<b>`/`<i>`/`<sub>`, ссылки, пиктограммы изображений); неизвестные теги остаются прозрачными, а авторские CSS и скрипты игнорируются.
- **HTML внутри Markdown теперь отрисовывается.** Сырой HTML в файлах `.md` — центрированные значки `<img>`, `<details>`/`<summary>`, HTML-таблицы `<table>` и строчные теги вроде `<kbd>`/`<sub>` — отрисовывается тем же движком, а не показывается буквальным текстом с угловыми скобками.
- **Просмотрщики Markdown и HTML стали текстовым браузером.** `Ctrl+G` — или новый пункт меню `Окна ▸ Web` — открывает путь или URL `http(s)://`; страницы загружаются и отрисовываются, ссылки открываются на месте с историей назад/вперёд (`[` / `]` или `Backspace`), относительные ссылки и якоря `#section` разрешаются, а ссылки на изображения открываются в предпросмотре изображений. Загруженная страница показывает URL в заголовке со значком 🌐. Загрузка ограничена из соображений безопасности: только http/https, проверка TLS, тайм-аут 15 секунд, не более 5 перенаправлений без понижения `https→http`, предел тела ответа 8 МиБ, а встроенные ресурсы (например, `<img>`) никогда не загружаются. Настройки `[viewer] open_links` и `[viewer] open_images` выбирают между панелью и внешней программой (по умолчанию `panel`); `O` всегда открывает ссылку во внешнем браузере.
- **Закладки открываются в просмотрщике.** HTML-, Markdown-, Mermaid-файлы, изображения и веб-ссылки `http(s)` открываются во встроенном просмотрщике в зависимости от типа (с учётом `[viewer] open_links`), а не всегда во внешней программе. Каталоги, удалённые пути, SSH и базы данных работают как прежде.
- **Прозрачный фон через цвет темы `"Reset"`.** Задайте любому цвету темы значение `"Reset"`, чтобы использовать родной цвет терминала (например, `bg = "Reset"` показывает фон терминала насквозь). Именованные цвета темы теперь сопоставляются без учёта регистра. (#37, спасибо @shepelpavel)
- **Сочетания клавиш просмотрщиков в панели справки** (`Alt+H` / `F1`) — новый раздел «Просмотрщики» с горячими клавишами Markdown, HTML и диаграмм.

## Исправлено
- Просмотрщики Markdown и диаграмм: получают фокус при открытии, открывают отдельный просмотрщик для каждого файла, рисуют полосу прокрутки на рамке панели, перезагружаются с диска по `Ctrl+R`, скрывают курсор без фокуса и оставляют заголовок, идущий после HTML-блока, на отдельной строке.
- Панель «Git история»: курсор выделения теперь на всю ширину (без неокрашенных краёв и пустой нижней строки), а лишнее сообщение «Refreshed» в строке состояния убрано.
