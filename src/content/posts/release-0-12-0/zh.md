## 新增
- **大纲面板**：基于 tree-sitter 查询的代码结构导航，markdown/HTML 回退到正则表达式；树形前缀、光标同步以及键盘/鼠标导航
- **全局快捷键**：大纲、诊断和 Git 日志面板的快捷键
- **文件管理器编辑按钮**：文件信息对话框中用“编辑”按钮取代“Git 状态”按钮

## 变更
- **代码质量**：消除 app 和 git crate 中不安全的 unwrap，对批量操作去重
- **对话框处理器**：对对话框处理器去重，添加路径穿越防护和 RwLock 恢复
- **清理面板索引**：移除过时的 panel_index 字段，修复相关的 clippy 警告

## 修复
- **大纲同步**：大纲面板现在在面板导航时同步，并对实时编辑做防抖处理
- **关闭后重新同步大纲**：所跟踪的编辑器关闭后，大纲面板改为绑定另一个编辑器（或清空）
