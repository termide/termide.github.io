## 新增
- **`{file}`、`{line}` 和参数直接写在命令行里。** 命令以前只能通过环境变量 `TERMIDE_PARAM_*` 拿到参数，所以要对手头的文件运行 `p4 edit`，就得填表单、输入路径，再写 `"$TERMIDE_PARAM_FILE"`，而 PowerShell 和 cmd 根本不认这种写法。现在 `command` 或 `build` 中的 `{name}` 会在命令运行前被替换：替换为同名参数，或替换为焦点面板所拥有的内容——编辑器光标处的 `{file}` 和 `{line}`/`{col}`、文件管理器光标下的 `{file}` 及其选中的 `{files}`、`{dir}`，以及项目根目录 `{project}`。`command = "p4 edit {file}"` 就是完整的命令。无论占位符写在哪里——单独出现、在单引号中还是在双引号字符串内——值始终按字面取用，并按读取这一行的程序的规则加引号：后台命令和报告命令用 sh 的规则，终端模式下用终端自身的 shell（sh、fish、PowerShell、cmd）的规则，调试器的程序则每个值作为一个单词；名为 `$(rm -rf ~).c` 的文件只是一个名字。没有值可给时——焦点在终端上、文件是远程的、在编辑器之外使用 `{line}`——命令不会运行，并提示应当聚焦什么。只有这些名字会被替换：`awk '{print $1}'`、`{{.Name}}` 模板、花括号展开、`${VAR}` 以及为 shell 转义过的占位符都保持原样，环境变量也照旧保留。
- **被限额拦下的委托会等待限额解除。** 委托任务遇到配额、速率或临时限制时，过去会用限额的文本回复调用，委托它的智能体便失去了这部分工作。现在它会暂停：输入框上方的那一行显示 `⏸`、委托及其何时继续，它会在限额重置时、在你要求时或在面板的连接变更后自行恢复——因此订阅用完后换成本地模型，工作也能从它自己的日志中接着进行。委托方智能体会被告知任务已暂停并将稍后汇报，因此不会再次委托。若 `on_limit` 设为询问，会出现一张卡片，提供立即重试或放弃；放弃会告诉智能体任务未完成。重试六次后，限额会传达给智能体，并注明连接和重置时间。等待无法解决的失败——认证、错误的请求、上下文溢出——仍像以前一样立即返回。

## 修复
- **从菜单选择的主题或语言在所有项目中保持。** 在拥有自己设置文件的项目中，选择会写入该文件，于是其他项目打开时仍是旧的设置，切换项目时选择仿佛丢失了。现在菜单会将其全局保存；单个项目的主题仍可在设置中通过“存储：项目”设置。
- **Git 选择器显示当前所在的仓库和分支。** 长的仓库路径和分支名开头相同（`github.com/team/`、`feature/`），区别在结尾，却偏偏从结尾截断。现在它们在开头的 `…` 之后保留结尾。仓库选择器还会占用短分支留下的空间，而不是止步于标题的一半；每个 git 下拉列表的宽度与其最宽的选项一致，以面板为限。
- **比行更宽的单词会换行，而不是被截断。** 智能体提示中的长 URL，或回答、Markdown 文件中的路径，过去会超出边缘。现在它会断成单独的几行；复制时这些行会无空格地重新拼接，链接在其跨越的每一行上都保持可点击。

## 变更
- **名称统一写作 Termide**：文档、README 和程序自身的文本中，原来写作 TermIDE 的地方都已更改。
