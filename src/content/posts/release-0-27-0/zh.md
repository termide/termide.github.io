## 新增
- **Mermaid 图表查看器。** `.mmd` / `.mermaid` 文件以只读图表的形式打开，用文本伪图形绘制 —— 流程图、时序图、状态图、类图、ER 图、甘特图、饼图、用户旅程图、思维导图、时间线、gitGraph 和象限图 —— 支持二维滚动、复制到剪贴板（`y` / `Ctrl+C` 或 `[≡]` 菜单），并可用 `Ctrl+E` 切换到可编辑的源码。Markdown 预览中的 ```` ```mermaid ```` 围栏代码块也会渲染为图表。（#34）
- **Markdown 预览面板。** `.md` / `.markdown` 文件以渲染后的只读视图打开 —— 标题、列表、表格、引用块、语法高亮的代码块、可点击的链接和图片图标 —— 带有可移动的光标、文本选择、剪贴板复制，并可用 `Ctrl+E` 切换到可编辑的源码。（#32）
- **十六进制/二进制查看器和编辑器。** 二进制文件以自适应的十六进制/ASCII 视图打开，带双区字节光标、拖动 / Shift 选择和剪贴板复制、ASCII 与十六进制字节搜索，以及十六进制↔文本切换（`Ctrl+L`）；`F4` 以原地覆盖编辑的方式打开同一文件，保存时写入 `.bak` 备份，关闭时若有未保存的更改会请求确认。（#31、#33）
- **编辑器中的语法高亮语言选择器。** 从编辑器状态栏选择高亮语言，即可重新高亮被误判类型的文件，而无需重命名。
- **可点击的面板状态栏分段。** 面板可以提供自己的状态栏标签和 `[≡]` 操作菜单项；编辑器和新的查看器用它们实现查看/编辑切换、复制和类型指示。（#36）

## 变更
- 编辑器状态栏改用可点击的分段重建，与十六进制查看器保持一致，并支持随模式变化的查看/编辑切换。

## 修复
- 选择下拉列表和菜单现在可以用鼠标滚轮滚动，并在列表溢出时显示滚动条 —— 包括 Git 分支/仓库选择器、编辑器的语法高亮选择器，以及菜单栏和 `[≡]` 下拉菜单。此前滚轮滚动的是下方的面板，长列表也没有滚动条。
