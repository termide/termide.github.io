## Добавлено
- Просмотрщик баз данных: значения теперь можно редактировать. `Enter` на ячейке открывает её для правки на месте с курсором — повторный `Enter` сохраняет, `Escape` отменяет, — а `Space` открывает диалог строки, где каждое поле можно редактировать рядом с уже имевшимися действиями копирования. У столбца, допускающего NULL, появляется флажок `NULL`; очистка текстового поля записывает пустое значение, а не NULL. Для редактирования нужна таблица с первичным ключом, поскольку без него нельзя однозначно указать одну строку; остальные таблицы остаются доступными для чтения и объясняют причину. Файл SQLite по-прежнему открыт только для чтения во время просмотра и переоткрывается на запись лишь при первой правке.
- Полосы прокрутки панелей можно перетаскивать мышью. Если захватить ползунок на правой границе панели (или на нижней, где рисуется горизонтальная полоса), панель прокручивается в это положение и следует за курсором при перетаскивании; дорожка полосы и границы без полосы по-прежнему меняют размеры раскладки. Работает во всех панелях с полосой прокрутки, а перетаскивание ползунка панели без фокуса прокручивает её на месте, не забирая фокус.

## Изменено
- Панели терминала теперь отслеживают рабочий каталог оболочки. Заголовок показывает каталог, в котором вы действительно находитесь, и следует за `cd`; панель сообщает этот каталог переключателю каталогов, команде «открыть панель здесь» и поиску репозиториев в git-панелях, а восстановленная сессия открывает терминал там, где вы остановились, а не там, где панель была создана.
- Массовые операции с файлами больше не обходят дерево без необходимости. Перемещение в пределах одной файловой системы — это переименование, поэтому всё поддерево больше не сканируется заранее: для дерева из 35 тыс. элементов такое сканирование стоило дороже самого перемещения. Удаление берёт тип файла из листинга каталога вместо отдельного stat для каждого элемента и сообщает о прогрессе по таймеру, а не после каждого файла. Всплеск событий файловой системы после крупного удаления схлопывается по каталогам, что убирает заметную паузу после завершения операции.
- Подтверждение удаления теперь начинается с «Нет», так что случайный `Enter` не удалит файлы. Остальные подтверждения по-прежнему по умолчанию на «Да».

## Исправлено
- Git-панели больше не теряют репозитории. Репозиторий, открытый в одной панели, пропадал из выпадающего списка, если другая панель находилась в родительском каталоге; репозитория собственного каталога сессии не было в списке, если ни одна панель не находилась внутри него; а репозиторий, для которого открыли панель, мог исчезнуть через мгновение после того, как приходили пути других, не связанных с ним панелей.
- Счётчик прошедшего времени в панели операций теперь использует единицы текущего языка, а не всегда `h`/`m`/`s`.
