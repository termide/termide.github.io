## 新增
- 数据库查看器：现在可以编辑值了。在单元格上按 `Enter` 会就地打开它并显示光标——再按 `Enter` 保存，按 `Escape` 放弃——按 `Space` 打开行对话框，其中每个字段都可编辑，原有的复制操作仍在旁边。允许 NULL 的列会多出一个 `NULL` 复选框；清空文本字段写入的是空值，而不是 NULL。编辑要求表有主键，因为没有主键就无法准确指定唯一一行；其他表仍可浏览，并会说明原因。浏览时 SQLite 文件仍以只读方式打开，只有在第一次编辑时才会以可写方式重新打开。
- 面板滚动条可以用鼠标拖动。抓住面板右边框（或绘有水平滚动条的下边框）上的滑块，面板就会滚动到相应位置，并在拖动时跟随光标；滚动条的轨道以及没有滚动条的边框仍像以前一样用于调整布局大小。所有绘制滚动条的面板都支持此功能，拖动未聚焦面板的滑块会就地滚动它，而不会抢走焦点。

## 变更
- 终端面板现在会跟踪 shell 的工作目录。标题显示你实际所在的目录并跟随 `cd` 变化，面板会把这个目录提供给目录切换器、“在此处打开面板”以及 git 面板的仓库搜索，恢复的会话也会让终端在你离开时的位置重新打开，而不是面板最初创建时的位置。
- 批量文件操作不再在不必要时遍历目录树。在同一文件系统内移动就是一次重命名，因此不再先扫描整个子树——对于一个有 3.5 万个条目的目录树，这次扫描比移动本身还耗时。删除时从目录列表中读取文件类型，而不是对每个条目单独执行一次 stat，并按定时器而不是每个文件报告一次进度。大规模删除之后涌来的一批文件系统事件会按目录合并，从而消除了操作完成后明显的停顿。
- 删除确认现在默认选中“否”，因此误按一下 `Enter` 不会删除文件。其他确认仍默认选中“是”。

## 修复
- git 面板不再丢失仓库。以前，只要另一个面板位于父目录中，在某个面板中打开的仓库就不会出现在下拉列表里；会话自身目录所在的仓库，除非恰好有面板位于其中，否则也会缺失；而面板打开时所针对的仓库，可能会在无关的面板路径到达后不久消失。
- 操作面板中的已用时间计数器现在使用当前语言的单位，而不是总显示 `h`/`m`/`s`。
