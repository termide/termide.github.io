## Добавлено
- **Диаграммы классов из исходного кода.** Пункт меню редактора `Показать как диаграмму` строит диаграмму классов Mermaid из объявлений открытого файла и открывает её в просмотрщике диаграмм. Заголовок каждого блока — само объявление (`pub struct Cli`, `enum Mode`, `public interface Draw`, …), у членов есть маркеры видимости UML (`+`/`-`/`#`/`~`), а наследование, реализация трейтов и интерфейсов и композиция через поля рисуются связями. Для Rust, Python, TypeScript/TSX/JSX, Go, Java, C, C++, Ruby и PHP есть подробные извлекатели (типы, сигнатуры, связи); для остальных языков tree-sitter строятся блоки типов с именами методов и блок функций верхнего уровня, названный по имени файла.
- **Сохранение сгенерированной диаграммы** в постоянный файл `.mmd` по `Ctrl+S` или через пункт `Сохранить диаграмму как…` в меню просмотрщика диаграмм.
- **Фильтрация при вводе** в выпадающих списках репозиториев и веток git-панели — начните печатать, чтобы сузить список.
- **Удаление слов в редакторе:** `Ctrl+Backspace` (или `Alt+Backspace`) удаляет предыдущее слово, `Ctrl+Delete` — следующее.
- **Выделение слова и строки мышью:** двойной щелчок выделяет слово под курсором, тройной — всю строку, и в редакторе, и в терминале.

## Изменено
- Панели git status и git diff теперь обновляются автоматически при получении фокуса, так что изменения, сделанные вне панели, появляются без ручного `Ctrl+R`.
- Копирование в буфер обмена теперь определяет доступный дисплейный сервер (X11/Wayland), а не гадает по наличию SSH, поэтому запасной вариант OSC 52 правильно используется в сессиях без графики, в Docker и на последовательной консоли.
- Панель справки теперь полностью локализована на все 15 языков; раньше многие описания выводились по-английски даже в переведённых локалях.

## Исправлено
- Нажатие Enter в фильтре репозиториев и веток git, когда совпадений нет, больше не переключает на первый репозиторий или ветку.
- Действия, специфичные для панели (например, `Показать как диаграмму`), теперь появляются в выпадающем меню `[≡]` панели.
