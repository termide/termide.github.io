## Добавлено
- **109 новых тестов**: тесты в 8 крейтах закрывают критичные пробелы (layout, config, buffer, clipboard, core, git, i18n, session)

## Изменено
- **Оптимизация «устаревания при сворачивании»**: свёрнутые панели пропускают фоновую работу тиков, наблюдателей, git и LSP и обновляются один раз при повторном разворачивании
- **Итераторы с учётом развёрнутости**: в LayoutManager добавлены `iter_all_panels_with_expanded_state_mut()` и `iter_expanded_panels_mut()`
- **Опрос LSP только для развёрнутых редакторов**: статус загрузки обновляется только для видимых панелей редактора

## Исправлено
- **CI и безопасность**: OpenSSL встроен в сборку для кроссплатформенности, исправлены типы statvfs на macOS, учётные данные вычищаются из логов
- **Ошибка устаревания SFTP**: удалённые панели больше не помечаются устаревшими из-за локальных событий файловой системы и git (это ломало переподключения)
- **Зависание спиннера VFS**: тик FileManager всегда разбирает приёмники VFS и git-статуса, даже в свёрнутом виде, и спиннеры больше не зависают
- **Разбор ошибок VFS**: исправлен ранний выход из тика FileManager, из-за которого результаты с ошибками VFS не обрабатывались
