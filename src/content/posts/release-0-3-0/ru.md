## Добавлено
- Навык Claude Code для управления релизами, автоматизирующий процесс выпуска
  - Проверки качества перед релизом (fmt, clippy, test, build)
  - Анализ изменений из нескольких источников (незакоммиченные изменения, коммиты, состояние файлов)
  - Интерактивный выбор версии с проверкой
  - Автоматическое обновление версии в 12+ файлах
  - Записи CHANGELOG, генерируемые из истории git
  - Проверка качества после обновления
  - Создание коммита в формате conventional commits и git-тега
- Поддержка спецификации XDG Base Directory
  - Конфигурация: `~/.config/termide/` (или `$XDG_CONFIG_HOME/termide/`)
  - Данные: `~/.local/share/termide/` (или `$XDG_DATA_HOME/termide/`)
  - Кэш: `~/.cache/termide/` (или `$XDG_CACHE_HOME/termide/`)
  - Правильные пути на всех платформах (Linux, macOS, Windows)
- Автоматическое сохранение сессий с настраиваемым сроком хранения
  - Сессии сохраняются автоматически при потере фокуса (с задержкой)
  - Автоматическая очистка сессий старше заданного срока хранения (по умолчанию 30 дней)
  - Отдельное хранение сессий для каждого проекта
  - Несохранённые буферы переживают смену сессий
- Подробная документация проекта
  - CHANGELOG.md с полной историей версий (от 0.1.0 до 0.2.0)
  - CONTRIBUTING.md с правилами разработки
  - Обновлённые шаблоны issue
  - Пересмотренная политика безопасности
  - Кодекс поведения Contributor Covenant

## Изменено
- **НЕСОВМЕСТИМОЕ ИЗМЕНЕНИЕ**: файловый менеджер теперь обычная закрываемая панель
  - Убрана особая обработка фиксированной левой панели
  - Файловый менеджер можно закрывать, менять его размер и перемещать между группами
  - По умолчанию открываются 2 панели файлового менеджера (раскладка 50/50)
  - Упрощённая архитектура (−350 строк кода)
  - Все панели теперь равноправны и обладают одинаковыми возможностями
  - Существующие сессии загрузятся с раскладкой по умолчанию
