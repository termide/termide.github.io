## Добавлено
- Окно поиска файлов (Ctrl+Shift+P) с асинхронным сопоставлением по glob-шаблонам
- Окно поиска по содержимому (Ctrl+Shift+F) с поддержкой регулярных выражений для поиска текста в файлах
- Выбор темы через вложенное выпадающее меню в разделе «Настройки»
  - Цветовое превью каждой темы: фон, текст и акцентные цвета
  - Тема применяется сразу и сохраняется в конфигурации
- Рефакторинг тем: API `all_theme_names()` и `get_by_name()` для системы тем

## Исправлено
- Подсветка синтаксиса в светлых темах откатывается к основному цвету текста темы
- Окно сессий: текущая сессия теперь выделена акцентным цветом, и её можно выбрать
- Улучшено удобство окна сессий и поиска файлов

## Документация
- Добавлены сочетания клавиш поиска файлов (Ctrl+Shift+P) и поиска по содержимому (Ctrl+Shift+F)
- Документация по темам обновлена: описан новый способ выбора через меню
