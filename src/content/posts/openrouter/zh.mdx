[OpenRouter](https://openrouter.ai) 把数百个模型放在同一个 API 之后：Anthropic、OpenAI、Google、DeepSeek、Qwen、Moonshot 等等。你只需要一个密钥和一份预付的额度余额，按所调用模型的 token 计费。它的 API 就是 OpenAI 的 chat API，因此 termide 的代理面板把它当作普通的 OpenAI 兼容连接来使用。

和本地服务器一样，代理是 termide 自己的：它的系统提示、工具、权限检查和上下文压缩都来自 termide，OpenRouter 只负责回答模型调用。OpenRouter 带来的是选择：可以在会话中途切换模型，也可以把附带工作交给更便宜的模型。本指南介绍如何配置，以及 termide 专门为 OpenRouter 做了什么。

## 准备工作

- **一个有额度的 OpenRouter 账户。** id 以 `:free` 结尾的模型免费，但每分钟和每天只允许少量请求，而代理很快就会用完：任务的每一步都是一次请求。
- **一个 API 密钥**，在账户的 [Keys](https://openrouter.ai/settings/keys) 页面创建（`sk-or-v1-…`）。密钥可以设置自己的额度上限，从而限制 termide 用它能花多少钱。

## 添加连接

按 <Keys k="Alt+P" /> 打开设置，进入 **AI**。最前面是 **Connections**。**+ Add connection** 会添加一个 OpenAI 兼容连接；在它的页面上：

- **Name**：例如 `openrouter`。之后靠这个名称切换到该连接。
- **Base URL**：`https://openrouter.ai/api/v1`。
- **API key**：**Enter a key…** 把密钥存入 termide 的加密保险库，而不是 `config.toml`。也可以把密钥放进环境变量，并在 **API key variable** 中填写变量名，例如 `OPENROUTER_API_KEY`。
- **Identify as Termide**：只要 base URL 指向 OpenRouter 就会出现（见[下文](#identify-as-termide)）。
- **Model**：选择一个模型（见[模型](#模型)）。
- **Context window (fallback)**：留空。OpenRouter 会报告每个模型的窗口，termide 直接采用。
- **Use by default**：勾选后，新的代理面板会以 OpenRouter 启动。

在 `config.toml` 中同样如此：

```toml
[ai]
connection = "openrouter"            # 新会话使用的连接

[ai.connections.openrouter]
provider = "openai_compatible"
base_url = "https://openrouter.ai/api/v1"
model = "anthropic/claude-sonnet-5"
api_key_env = "OPENROUTER_API_KEY"   # 或省略，把密钥保存在保险库中
# app_attribution = false            # 不在请求中向 OpenRouter 标明 termide
```

## 模型

**Model** 下拉列表按 OpenRouter 给出的名称列出模型，例如 `anthropic/claude-sonnet-5` 显示为 `Anthropic: Claude Sonnet 5`，保存的则是 id。列表很长：末尾的 **Enter a model id…** 可以手动输入 id，从 [openrouter.ai/models](https://openrouter.ai/models) 上模型的页面复制，包括 `:free` 变体或 `~anthropic/claude-sonnet-latest` 这样的别名。

<Shot src={models} alt="在 Model 字段下方打开的 Model 下拉列表：Auto — the provider's choice，然后是 Anthropic: Claude Haiku 5、Anthropic: Claude Opus 5.5、标记为已保存的 Anthropic: Claude Sonnet 5、DeepSeek: DeepSeek V4、Google: Gemini 3.5 Flash、Google: Gemini 4 Pro Preview、MoonshotAI: Kimi K3、OpenAI: GPT-6 Luna、OpenAI: GPT-6.1 Sol、Qwen: Qwen3.6 35B A3B、Qwen: Qwen3.8 Coder Plus" caption="按名称列出的 OpenRouter 模型；写入配置的是 id。" />

请选定一个模型，而不是保留 **Auto**。Auto 使用服务器列出的第一个模型：在本地服务器上那是已加载的模型，而在 OpenRouter 上只是按字母排序的第一个 id。

模型必须能调用工具：代理只能通过工具调用来读取、编辑和运行命令。OpenRouter 的目录可以按模型支持的参数筛选，其中包括 `tools`，而当前大多数模型都支持。

每个模型的窗口随列表一起提供：会话开始或切换模型时，termide 采用 OpenRouter 为该模型报告的窗口（某个模型一百万 token，另一个二十万），并把上下文控制在其中。状态栏显示上下文相对于该窗口的占用（`11k/1M`）。

## 第一个请求

按 <Keys k="Alt+A" /> 打开代理面板并给它一个任务。状态栏显示连接和模型，**Reasoning** 芯片设置模型思考的力度：termide 以 `reasoning_effort` 发送级别，OpenRouter 再以模型提供方接受的形式转发。OpenAI 的模型有自己的一组级别，其他模型为 `low`、`medium` 和 `high`。

状态栏的 **Model** 芯片可以切换会话的模型：对话继续进行，下一个请求发给新模型并使用新模型的窗口。困难的一步可以交给更强的模型，之后再切回来。

## 提示缓存

代理每一步都会发送整个对话：系统提示、工具 schema，以及到目前为止说过和读过的一切。会缓存提示的提供方以输入价格的一小部分从缓存读取这些内容；不缓存的提供方则每一步都重新全额计费。

OpenAI、DeepSeek、Gemini、Moonshot 和大多数其他提供方会自动缓存。Anthropic 的模型只在被要求时才缓存，而 termide 会提出要求：在 OpenRouter 连接上，发往 `anthropic/…` 模型的请求带有 `cache_control`，它把对话缓存到最后一条消息，并随对话增长向后移动。状态栏中的 `↻` 数字就是来自缓存的部分：上面的录屏中是 `↻30k`，对比重新读取的 `↑11k`。

## 花费

termide 统计的是 token 而不是金额：**Session info**（<Keys k="F3" /> 或 `/usage`）按花费者——对话、子代理、`auto` 审查器、摘要——以及按模型细分。它们的价格可以在 OpenRouter 的 [Activity](https://openrouter.ai/activity) 页面逐个请求查看。

有两件事可以压低账单。上下文压缩让上下文保持在窗口之内，而在那之前很久，你就可以对较长的会话自己执行 `/compact`。另外，附带工作可以交给更便宜的模型：再建一个使用小模型的 OpenRouter 连接，把它指定为本连接 `auto` 模式的审查器，以及委派任务所用的连接：

```toml
[ai.connections.openrouter]
# …
reviewer = "openrouter-small"        # auto 审查器；默认：[ai.auto_reviewer]
subagents = "openrouter-small"       # 委派任务；默认：本连接

[ai.connections.openrouter-small]
provider = "openai_compatible"
base_url = "https://openrouter.ai/api/v1"
model = "anthropic/claude-haiku-5"
api_key_env = "OPENROUTER_API_KEY"
```

审查器评判 `auto` 模式下规则未决定的每个操作；读取、项目内的编辑和只读命令不会交给它。**Permissions**（或 <Keys k="Shift+Tab" />）在 `ask`、`configured`、`plan`、`edit`、`all` 和 `auto` 之间切换，与任何连接相同。

## Identify as Termide

OpenRouter 会按发出请求的应用统计用量，未标明应用的请求归入 `Unknown`。**Identify as Termide**（`app_attribution`）默认开启，会在请求头中标明 termide，OpenRouter 便把这些请求记在 termide 名下。OpenRouter 上的应用页面由所有 termide 用户共享，其用量在那里是公开的。关闭此开关即可不被标明。termide 只为 OpenRouter 显示这个开关——这是它所知道的唯一做此类统计的服务。

## 出错时

- **额度用完**：OpenRouter 拒绝请求（402），任务停止并显示卡片：**Try again now**、**Keep trying until it goes through** 或 **Stop**。充值后重试；或者在卡片显示时用状态栏的 **Connection** 芯片把会话切换到另一个连接，再以 **Try again now** 回答卡片。
- **速率限制**：`:free` 模型的每分钟上限，或提供方容量已满（429）。一分钟内解除的限制，termide 会自己等待并重试；更长的限制，卡片会提供等待或持续重试的选项。对于无人值守的 `/goal` 或 `/loop`，把 **On a limit or outage**（`[ai]` 下的 `on_limit`）设为 `wait`。
- **上下文已满**：termide 会压缩会话并自动再试一次；如果仍然失败，卡片会提供 **Compact the context and try again**。

## 须知

- **OpenRouter 只是一个例子。** 同样的 OpenAI 兼容连接也适用于 OpenAI 本身（`https://api.openai.com/v1`）、Gemini API 和其他网关，以及你自己的服务器，例如 [llama.cpp](/zh/blog/llama-cpp/) 和 [omlx](/zh/blog/omlx/)；`provider = "anthropic_compatible"` 则用于 Anthropic API。
- **订阅是另一种方式。** [Claude Code](/zh/blog/claude-code/)、[Codex](/zh/blog/codex/) 和 [Gemini CLI](/zh/blog/gemini-cli/) 自带代理，按订阅计划而非额度运行；OpenRouter 连接很适合作为备用连接，在计划额度用完时把会话切换过去。
- **termide 不是沙箱。** 它的权限是一种控制而不是隔离：你允许的操作以你的权限运行。
- **详细说明** 见 [代理指南](https://github.com/termide/termide/blob/main/doc/zh/agent.md#配置模型)。
