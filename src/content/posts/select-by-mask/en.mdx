Copying every Rust source out of a directory, or deleting the build output of a dozen packages, means selecting a group of files. Clicking them one by one is slow. Since version 0.41, termide's file manager selects by pattern, with the keys Far Manager and Total Commander users already know.

## Three keys

| Key | What it does |
|---|---|
| <Keys k="+" /> | Select what matches a mask |
| <Keys k="-" /> | Unselect what matches a mask |
| <Keys k="*" /> | Invert the selection |

<Keys k="+" /> and <Keys k="-" /> open a small dialog asking for the mask, with `*` filled in, so <Keys k="+" /> <Keys k="Enter" /> selects everything. The selection then works with every file operation: copy with <Keys k="F5" />, move with <Keys k="F6" />, pack with <Keys k="Alt+F5" />, delete with <Keys k="F8" />. <Keys k="Esc" /> clears it.

## Writing a mask

- A mask is one or more glob patterns: `*.rs *.md` matches Rust and Markdown files.
- Separate patterns with spaces, commas or semicolons, whichever you type faster.
- Matching ignores case: `*.jpg` also finds `PHOTO.JPG`.
- A pattern matches files. End it with `/` to match directories instead: `target/` for one, `*/` for all of them.

Combining the keys covers most cases. To select everything except the tests, press <Keys k="+" /> <Keys k="Enter" /> to take it all, then <Keys k="-" /> with `test_*`. To clean up build output, <Keys k="+" /> with `target/ node_modules/`, then <Keys k="F8" />.

## With the mouse

<Keys k="Ctrl+Click" /> toggles a row, and <Keys k="Shift+Click" /> selects from the cursor to the clicked row. macOS terminals turn <Keys k="Ctrl+Click" /> into a right click, so <Keys k="Alt+Click" /> does the same there and works everywhere.

## Other keys

The keys live in the `[file_manager.keybindings]` section of `config.toml`:

```toml
[file_manager.keybindings]
select_group = "+"
unselect_group = "-"
invert_selection = "*"
```

The [file manager guide](https://github.com/termide/termide/blob/main/doc/en/file-manager.md#file-selection) lists every selection key.
