## Исправлено
- Проблемы сборки пакетов .deb и .rpm для архитектуры ARM64
  - aarch64 убран из матриц сборки пакетов, чтобы избежать проблем с кросс-компиляцией
  - Архивы с бинарниками по-прежнему поддерживают все платформы, включая ARM64

## Добавлено
- Скрипт для локальной проверки сборки пакетов (`scripts/test-packages.sh`)
