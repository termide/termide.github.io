## Добавлено
- **Автоматизация CI/CD**: при выпуске релиза пакеты в AUR и Homebrew обновляются автоматически через GitHub Actions
- **Пакеты в AUR**: `termide` (из исходников) и `termide-bin` (двоичный) теперь доступны в AUR

## Исправлено
- **Выделение текста в терминале**: выделение теперь использует абсолютные координаты буфера
- **Сохранение выделения**: выделение следует за текстом при прокрутке истории
- **Ctrl+Shift+C**: сочетание клавиш для копирования выделения в терминале
- **Сброс выделения**: выделение снимается при вводе с клавиатуры
- **Пробелы в конце строк**: сохраняются при копировании выделенного текста
