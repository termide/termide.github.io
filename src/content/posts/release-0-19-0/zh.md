## 新增
- **脚本**：基于表单创建脚本（ScriptCreateModal），可设置名称、分组、类型（终端/后台/报告）和项目范围
- **脚本**：菜单中的脚本和书签支持按 F2 重命名，以及带确认的 Delete 删除
- **脚本**：菜单和操作卡片中显示类型图标（终端、后台、报告）
- **快捷键**：基于配置的 `HotkeyTable` 系统取代了硬编码的按键匹配——所有快捷键现在都可通过 TOML 配置
- **快捷键**：对所有按键进行西里尔字母键盘归一化（ЙЦУКЕН → QWERTY 映射，包括标点符号）
- **面板**：按 Escape 会请求关闭面板，并弹出确认对话框
- **错误**：所有错误现在都以 InfoModal 对话框显示，而不是短暂的状态栏消息
- **文件管理器**：文件信息模态窗口中提供交互式权限编辑器
- **菜单**：磁盘使用指示器，以及菜单导航中的日历网格
- **菜单**：书签和脚本支持项目本地的 `.termide/` 目录
- **会话**：在会话模态窗口中按 Delete 键删除会话

## 变更
- **快捷键**：文件管理器和 Git 日志面板统一使用 `open_external`——默认值改为 `O / Alt+Enter`，以兼容 VTE 终端
- **快捷键**：从帮助面板和配置中移除了无用的“Universal”快捷键部分（-435 行代码）
- **操作**：重新设计了操作卡片，带有边框标题、图标和已用时间计时器
- **操作**：卡片边框标题中显示脚本名称，而不是笼统的“Script”
- **布局**：宽度分配采用最大余数算法（修复了舍入误差）
- **重构**：移除了旧的 HotkeyKind/Hotkey/HotkeyProcessor 语义层
- **重构**：编辑器 blame 从快捷键开关改为配置项
- **日志**：静默的 `let _ = fs::*` 操作改为正确记录错误日志

## 修复
- **SSH**：防止通过 SSH 使用时出现空白屏幕——跳过 `supports_keyboard_enhancement()` 检测，添加用于恢复终端状态的 panic 处理程序，并防范 0×0 的终端尺寸
- **SSH/终端**：添加边界检查，防止终端调整大小时缓冲区索引越界导致 panic
- **SFTP**：修复本地到远程复制时的覆盖冲突——改用上传请求而非远程到远程复制，并通过 VFS stat 判断目标是文件还是目录
- **脚本**：在创建/重命名脚本时清理文件名（将非法字符替换为 `-`）
- **脚本**：修复在项目与全局来源混合时子菜单执行错误脚本的问题
- **脚本**：取消时正确终止脚本，支持并行运行报告脚本
- **键盘**：恢复 0.18.2 中丢失的按键（大纲、诊断、Git 面板中的 PageUp/PageDown/Enter）
- **键盘**：修复编辑器 F2/F4 绑定与全局快捷键的冲突
- **文件操作**：复制时保留权限，同一文件系统内移动时使用 `fs::rename`
- **i18n**：移除重复的键，修复帮助面板中未本地化的字符串
