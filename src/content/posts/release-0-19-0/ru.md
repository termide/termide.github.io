## Добавлено
- **Скрипты**: создание скрипта через форму (ScriptCreateModal) с именем, группой, типом (терминал/фоновый/отчёт) и областью действия «проект»
- **Скрипты**: в меню скрипты и закладки можно переименовать по F2 и удалить по Delete с подтверждением
- **Скрипты**: значки типов в меню и карточках операций (терминал, фоновый, отчёт)
- **Горячие клавиши**: система `HotkeyTable` на основе конфига заменила жёстко заданное сопоставление клавиш — все горячие клавиши теперь настраиваются через TOML
- **Горячие клавиши**: нормализация кириллической раскладки для всех клавиш (соответствие ЙЦУКЕН → QWERTY, включая знаки препинания)
- **Панели**: Escape запрашивает закрытие панели с диалогом подтверждения
- **Ошибки**: все ошибки теперь показываются диалогами InfoModal, а не временными сообщениями в строке состояния
- **Файловый менеджер**: интерактивный редактор прав доступа в модальном окне свойств файла
- **Меню**: индикатор занятого места на диске и сетка календаря в навигации по меню
- **Меню**: поддержка локальной для проекта папки `.termide/` для закладок и скриптов
- **Сессии**: удаление сессии клавишей Delete в модальном окне сессий

## Изменено
- **Горячие клавиши**: `open_external` унифицирован для панелей файлового менеджера и истории git — по умолчанию теперь `O / Alt+Enter` для совместимости с терминалами на VTE
- **Горячие клавиши**: из панели справки и конфига убран неработающий раздел «Universal» (−435 строк)
- **Операции**: переработаны карточки операций — заголовки в рамке, значки и таймер прошедшего времени
- **Операции**: в заголовке рамки карточки показывается имя скрипта вместо общего «Script»
- **Раскладка**: распределение ширины использует метод наибольшего остатка (исправляет ошибки округления)
- **Рефакторинг**: удалён устаревший семантический слой HotkeyKind/Hotkey/HotkeyProcessor
- **Рефакторинг**: blame в редакторе переключается настройкой в конфиге, а не горячей клавишей
- **Логирование**: молчаливые операции `let _ = fs::*` заменены полноценной записью ошибок в лог

## Исправлено
- **SSH**: устранён пустой экран при работе по SSH — пропускается определение `supports_keyboard_enhancement()`, добавлен обработчик паники для восстановления состояния терминала, добавлена защита от размера терминала 0×0
- **SSH/Терминал**: добавлены проверки границ, чтобы при изменении размера терминала не возникала паника из-за индекса буфера
- **SFTP**: исправлен конфликт перезаписи при копировании с локального диска на удалённый — используется запрос загрузки вместо копирования между удалёнными путями, а назначение определяется как файл или папка через VFS stat
- **Скрипты**: при создании и переименовании скрипта имена файлов очищаются (недопустимые символы заменяются на `-`)
- **Скрипты**: исправлен запуск не того скрипта из подменю при смешанных источниках (проект и глобальные)
- **Скрипты**: при отмене скрипты корректно завершаются, поддерживаются параллельные скрипты-отчёты
- **Клавиатура**: восстановлены клавиши, потерянные в 0.18.2 (PageUp/PageDown/Enter в панелях структуры, диагностики и Git)
- **Клавиатура**: исправлены конфликты привязок F2/F4 в редакторе с глобальными горячими клавишами
- **Файловые операции**: при копировании сохраняются права доступа, перемещение в пределах одной файловой системы выполняется через `fs::rename`
- **i18n**: удалены дублирующиеся ключи, исправлены нелокализованные строки панели справки
