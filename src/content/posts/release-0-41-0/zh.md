## 不兼容变更
- **链接在 termide 内部打开；`[viewer] open_links` 和 `open_images` 已移除。** 点击的链接中，网址在查看器中打开，文件在 打开… 会打开它的地方打开，图片在图片预览中打开，网页书签总是在查看器中打开。若要在外部打开，在 HTML 和 Markdown 查看器中使用 `O`、`Alt+Enter` 或 `Alt+Click`（`[viewer.keybindings]` 下的 `open_external`，可重新绑定，并列在设置和帮助中），在终端和代理面板中使用 `Ctrl+Alt+Click`，在那里 `Ctrl+Click` 仍在内部打开链接。`config.toml` 中的旧键会被忽略。

## 新增
- **用 `Alt+F9` 解压压缩包。** 选中的压缩包或光标下的压缩包会通过操作面板解压，带有进度、暂停和取消。提示框会提供以压缩包命名的目录，位置可选另一个文件管理器的目录、其他面板的目录或压缩包本身所在的目录；多个压缩包各自解压到一个目录。加密的 zip 会先询问密码，输错时再次询问；解压会覆盖已有文件时会先询问。解压和打包失败的提示以你的语言表述。
- **按掩码选择。** 在文件管理器中，`+` 和 `-` 选择和取消选择匹配掩码的项——glob 模式，不区分大小写，末尾的 `/` 表示目录（`*.rs *.md`、`target/`）——`*` 反转选择。`Alt+Click` 与 `Ctrl+Click` 一样切换某一行的选择状态，因为 macOS 终端会把后者变成右键单击。
- **目录切换器中的挂载点。** 在 Linux 和 macOS 上，它会列出根目录、已挂载的磁盘、可移动介质和网络共享，系统挂载点除外。
- **文件管理器中的 Far / Total Commander 别名快捷键**，与现有快捷键并存：`Alt+F1` 目录切换器，`Shift+F4` 新建文件，`Alt+F5` 打包，`Alt+F7` 搜索，`Alt+F9` 解压。全部可重新绑定。
- **代理提示框中的图片。** `Ctrl+V` 会附加剪贴板上的图片（截图、在浏览器中复制的图片）或在文件管理器中复制的图片文件；粘贴或拖入 PNG、JPEG、GIF 或 WebP 的路径也有同样效果。每张图片在提示框中以 `[#1 pasted image 1280×720]` 占位，只要占位符还在，它就会随消息一起发送；超过 1568 px 的图片会被缩小。外部代理在声明支持图片时会收到它们。在 macOS 上请使用 `Ctrl+V`：`Cmd+V` 是终端自身的文本粘贴。
- **面板关闭时未完成的工作可以继续。** 在运行、`/goal` 或 `/loop` 期间关闭面板或 termide 现在会先询问。重新打开的会话如果有被中断或暂停的运行，或有仍在进行的目标或循环，会说明进展到了哪里，并提供 **继续**、**放弃** 或 **稍后决定**；不会自动运行任何内容。被中断的运行留下的无结果调用不会被盲目重复：模型会被告知它们可能已部分执行。
- **运行中的子代理始终可见。** 输入框上方的状态条为每个正在运行的 `task` 调用保留一行：`& 委派给 agent · task`，附带它最后做的事、加载动画和用时，这样即使其块已滚出视野，也能看出它仍在工作；单击该行会把块滚动到视野中。
- **`/goal` 可以判定目标无法达成。** 评审除了 `DONE` 和 `CONTINUE` 之外还可以回答 `IMPOSSIBLE`，这会结束该目标。
- **在目录选择器中新建、重命名和删除目录。** 新建项目、更改根路径以及其他目录选择器支持文件管理器的 `create_dir`（`F7`/`D`，或 **新建文件夹** 按钮）、`rename`（`F2`/`R`）和 `delete`（`F8`/`Delete`）。名称在光标所在条目旁边的树行中输入——与其同级，而不是在其内部——`Esc` 会撤掉该行；新目录会留在光标下，可直接选取。在这里只能删除空目录。
- **打包的压缩级别。** 打包提示框（`P`）有一个 **压缩** 行——不压缩、快速、标准（默认）或最佳——用于设置 zip、gzip、bzip2 和 xz 的级别；zstd 只区分不压缩和其他级别。
- **限制 CLI 代理的上下文窗口。** Claude Code 或 Codex 连接可设置比模型更小的 **上下文窗口上限**（`context_window_limit`）：Claude Code 以 `CLAUDE_CODE_AUTO_COMPACT_WINDOW` 的形式获得（至少 100000），Codex 通过 `CODEX_CONFIG` 以 `model_context_window` 的形式获得。代理会在达到该上限时压缩上下文，面板的 `Context:` 显示的数值不会超过它。
- **设置中显示 CLI 代理的模型。** 打开 Claude Code、Codex 或 Gemini CLI 连接时，模型下拉列表会列出其登录账号可用的模型；只要有任何连接的模型正在加载，该字段就会显示加载动画。
- **能识别推理陷入循环的模型。** 内置代理会在推理和回答流式输出时进行监视；一旦最近的大多数句子都在重复已经说过多次的内容，它就会中断调用，保留循环开始之前的推理，告诉模型它在哪些点之间反复摇摆，并在不推理的情况下再调用一次。第二次循环会停止运行（连同正在进行的 `/goal`），并显示这些要点供你决定。此前，这样的回复会一直持续到输出上限——有一次达到 140 KB、耗时 18 分钟——而运行结束时什么也没显示。改写 `system/loop.md` 可以更改告诉模型的内容。

## 变更
- **各处统一的计时器。** 代理的运行计时、子代理、暂停、`/loop` 倒计时、文件操作面板以及远程连接的状态，都在相同的时长旁显示相同的 `✻` 加载动画：以整秒计，显示最大的两个单位（`45s`、`1m13s`、`2h5m`、`3d4h`），较小单位为零时省略（`5m`、`1h`）。操作面板和 `/loop` 间隔以前使用其他格式（`1h 10m 5s`、未翻译的 `60m`）。
- **停止显示为一行，然后是一个状态。** 运行停止期间，运行计时会变为 `正在停止… ✻ 2s`；被停止的回答随后以已翻译的 `✗ 已取消` 结尾，并附上用时和状态。`正在停止…` 通知和提供方原始的 `aborted` 不再同时留在对话记录中，从日志重新打开的会话也显示 `已取消`。
- **进行中的 `/goal` 和 `/loop` 始终可见。** 输入框上方的状态条在它们进行期间各固定一行，与运行中的子代理并列：`◎ 正在朝目标前进 …` 附带已运行时长（评审检查进行时也会显示），`↺ 每 5m 重复一次 …` 附带运行次数和距下次运行的倒计时。单击该行的 `✕` 会停止它；单击该行其他位置会把其最近一次运行滚动到视野中。
- **设置在更改时即保存。** 设置模态窗口不再有「应用」：开关和下拉列表在设置时保存，文本和数字字段在按 `Enter` 时保存。底部一行是 **存储：全局 / 项目**、**重置** 和 **关闭**。切换到项目会创建 `.termide/config.toml`；切换回来时会询问是丢弃项目设置还是将其移到全局文件。重置会先询问，并将项目重置为全局设置，或将全局设置重置为默认值。在那里修改的快捷键会立即生效。
- **`--config` 指定的全局文件既用于加载也用于保存**，项目文件叠加在其上；文件缺失或无法读取现在会报错。`--no-lsp`、`--log-level` 和 Linux 控制台主题不再写入配置文件，分离实例会保留这三个参数。
- **`/goal` 没有轮次上限。** 以前它在 50 轮时停止；现在当评审判定目标已达成或无法达成时结束。如果目标的代理只说不做——连续三个工作轮次没有工具调用——目标会暂停但仍保持设定，等待 `/continue` 或 `/goal stop`。
- **`/goal` 可以在代理工作时启动，并会被立即采纳。** 以前它会被拒绝，之后又作为引导消息排队，停止时会被遗留下来；现在不再排队，运行结束后，它的第一个轮次（以输入时的 `/goal` 开头）会代替评审进行。启动目标不再把它打印两次。停止或 `/loop stop` 也会撤回仍在队列中等待的循环轮次。
- **CLI 代理从 npm 缓存启动。** Claude Code、Codex 和 Gemini CLI 不再在每次启动时查询 npm 注册表——这会让每个面板、审查模型和子代理多花几秒，离线时则超过一分钟；每次运行会在后台检查一次是否有新版本，并从下次启动开始使用。
- **AI 菜单以与面板相同的方式标注会话日期**（`YYYY-MM-DD HH:MM`，暗色），而不是「2 小时前」。
- **代理的状态栏只显示连接名称**；协议保留在欢迎横幅中，仅在连接没有名称时代为显示。
- **菜单栏中提醒铃铛位于文本之前**（`🔔 name`），与其他各处的图标一致。

## 修复
- **自行继续工作的外部代理会显示它在工作。** Claude Code 会把正在运行的命令移到后台以接收期间输入的消息，并在命令完成后继续——此时它的回合已经结束。这部分工作现在作为一次独立的运行：计时器会走动，会话在其进行期间不能被切换或删除，`Esc` 会停止它，期间输入的消息作为下一个请求发送。当代理没有未完成的调用并保持安静时（回答后 5 秒，否则 30 秒），运行结束。新会话（`F7`）不再继承遗留下来的走动计时器。
- **快速停止后立即发送的 Claude Code 请求不再卡住。** 在尚未作答时被停止，Claude Code 的 ACP 适配器可能会在看不见的地方继续处理已取消的提示词，让下一个请求在其后等待。现在在首次回复前被停止的外部代理会在同一会话上重新启动，这也结束了隐藏的工作，对话记录中会注明这一点。
- **`/goal` 检查会显示它正在进行。** 评审做决定期间，对话记录显示与模型消息相同的实时行：走动的计时器，以及内置代理的读取进度（`⏫`）和回答的 token 数。本地模型上耗时较长的检查不再看起来像卡住了。
- **进行中的 `/goal` 或 `/loop` 只在结束时响铃。** 之后紧接着目标评审或循环下一次运行的运行，无论耗时多长都不响铃；目标达成、放弃、暂停或失败，以及循环达到上限而结束时，才会响铃。
- **单独的 `/goal` 或 `/loop` 不再停止正在进行的那个。** 它会报告当前状态——目标及其轮次，或循环、其运行次数和距下次运行的等待时间——没有进行中的目标或循环时则显示用法。只有 `stop`（或 `off`）才会结束它们。
- **`/goal` 评审的结论能越过标记和开场白被读取。** 评审如果给这个词加了标记（`**DONE**`）或在它前面写了一行，会被读作 `CONTINUE`，而由此发出的工作轮次只告诉代理 `Still missing: CONTINUE`。
- **被关闭的问题不再阻止代理再次提问。** 它的结果告诉模型永远不要再问，这在长时间的 `/goal` 中让它无法就后续本应由用户决定的事项提问。
- **`/goal` 检查失败不再丢弃目标。** 出错的评审调用会在 10 秒和 20 秒后重试；如果这些也失败，目标会暂停，`/continue` 会再次检查，`/goal stop` 则结束它。
- **`bash` 调用不再因脱离进程组的进程而卡住。** 保持输出打开的守护进程或 ssh `ControlPersist` 主进程会让调用永远挂起，即使超过超时或停止也是如此；现在输出会一直读取到安静为止，结果会说明是否有东西仍在运行。
- **Claude Code 的工具调用显示完整参数。** 它的参数分段到达，而以前只保留了第一段，因此子代理调用显示为没有任务的 `default:`，在面板和会话日志中都是如此。
- **关闭代理面板不再使界面冻结**——以前在关闭远程 MCP 服务器的 HTTP 会话时，每个服务器最多冻结 2 秒。
- **鼠标滚轮可以滚动设置**，包括快捷键选项卡；以前下一帧会把它弹回原位。
- **粘贴占位符读起来像一个短语**，数量有正确的词形变化（`[#1 вставлено 6 строк]`），英文也不再显示「1 chars」。
- **进入另一个已打开的项目会应用它自己的设置**，全局基线会随每次全局保存更新，在编辑器中保存 `config.toml` 会保留项目叠加设置和命令行参数。配置文件通过临时文件写入。
- **`install.sh` 使用正确的 Homebrew tap**，即 `termide/termide`；它原先指定的 `termide/tap` 并不存在。
