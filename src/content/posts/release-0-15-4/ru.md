## Добавлено
- **Git статус**: обновление по Ctrl+R запускает фоновый `git fetch`
- **Приложение**: звуковой сигнал (bell) по завершении git push/pull и выходе из терминала
- **Буфер обмена**: запасной буфер обмена через OSC 52 для сессий по SSH и без графической среды

## Исправлено
- **Терминал**: устранён panic при поиске в UTF-8 (кириллица, эмодзи) — сдвиг на длину совпадения, а не на 1 байт
- **Файловый менеджер**: при входе во вложенный каталог в дереве используется полный путь

## Изменено
- **Производительность**: пропуск лишней обработки в обработчике мыши и упрощённая логика OSC 52
- **Производительность**: при наведении мыши не сбрасывается таймер простоя и не выполняется принудительная перерисовка
- **Производительность**: отступы через `.repeat()` заменены статическим срезом `PAD` при отрисовке файлового менеджера
- **Производительность**: раскладка меню кэшируется в структуре `MenuLayout`, чтобы избежать повторных аллокаций
- **Рефакторинг**: улучшено логирование ошибок VFS в обработчике пакетных операций
- **Рефакторинг**: удалён мёртвый метод `find_visible_by_path`
