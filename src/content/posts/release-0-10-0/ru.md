## Добавлено
- **Режим Vim**: полная поддержка клавиш vim в панели редактора, включая кириллическую раскладку
- **Переключатель каталогов**: окно быстрого перехода по каталогам по Ctrl+P с недавними каталогами и нечётким поиском
- **Окно добавления закладки**: умный ввод группы с выпадающими подсказками для упорядочивания закладок
- **Вставка в модальных окнах**: текст можно вставлять прямо в поля ввода модальных окон, управляющие символы отфильтровываются

## Исправлено
- **Визуальные артефакты терминала**: исправлено состояние гонки при инвалидации кэша в sync_output
- **Пакетная отрисовка терминала**: принудительная инвалидация кэша по командам ED (очистка экрана)
- **Инвариант буфера**: добавлен ensure_buffer_size() для предотвращения пограничных случаев IL/DL
