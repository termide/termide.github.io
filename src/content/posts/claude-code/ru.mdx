Вы уже платите за Claude, и Claude Code на вашей машине выполнил вход. Можно запустить `claude` в одной из терминальных панелей termide, и это будет работать, но жить он будет рядом с termide, а не внутри: его правки попадают на диск в обход открытого редактора, запросы разрешений у него свои, и сессии тоже не termide.

Агентная панель termide умеет работать на Claude Code. Модель и подписка остаются за Claude, а инструменты, карточки разрешений, список сессий и редактор, который следит за каждой правкой, — за termide. Этот гайд показывает, как это настроить и что меняется по сравнению с Claude Code в терминале.

## Что понадобится

- **Node.js** и `npx` в `PATH`. termide управляет Claude Code через его адаптер для [Agent Client Protocol](https://agentclientprotocol.com), `@agentclientprotocol/claude-agent-acp`, и запускает последний выпуск через `npx`. Копия из кэша npm стартует, не обращаясь к реестру; новый выпуск termide ищет в фоне раз за запуск, и он начинает работать со следующей панели.
- **Вход в Claude Code.** Сам termide вход не выполняет. Если вы уже пользуетесь Claude Code, всё готово; иначе один раз запустите `claude` в терминале и войдите командой `/login`.

API-ключ не нужен: подключение работает по входу, который уже есть у Claude Code, — по вашей подписке или вашему ключу.

## Добавьте подключение

Откройте настройки клавишами <Keys k="Alt+P" /> и перейдите на вкладку **AI**. Первым идёт раздел **Подключения**. Выберите **+ Добавить подключение** и на странице нового подключения поставьте **Провайдер**: **Claude Code**. Страница уберёт поля, которые Claude Code не нужны, — базовый URL, API-ключ, запасное контекстное окно, — а подключение будет называться `claude-code`, пока вы не дадите ему имя.

<Shot src={models} alt="Настройки, AI › claude-code: Провайдер — Claude Code, открыт список моделей: Авто — на выбор провайдера, Default (recommended), Opus 5.5 (1M context), Sonnet 5, Haiku 4.5 и ввод id вручную" caption="В списке моделей — модели вашего входа, под именами, которые им даёт Claude Code." />

Остальное на странице:

- **Модель**: termide ненадолго запускает Claude Code и показывает модели вашего входа; пока список грузится, в поле крутится индикатор. **Авто — на выбор провайдера** оставляет выбор за Claude Code. Выбранная здесь модель — только та, что выбрана заранее: в панели её можно сменить в любой момент.
- **Ограничение контекстного окна**: оставьте пустым, чтобы работать с окном модели, или сделайте меньше, но не меньше 100000. Claude Code получает его как `CLAUDE_CODE_AUTO_COMPACT_WINDOW` и сжимает разговор на этой границе, а `Context:` в панели не показывает больше неё.
- **Использовать по умолчанию**: отметьте, и новые агентные панели будут открываться на Claude Code.

То же самое в `config.toml`:

```toml
[ai]
connection = "claude"        # подключение для новых сессий

[ai.connections.claude]
provider = "claude_code"     # больше ничего не требуется
# model = ""                 # пусто: модель по умолчанию у Claude Code
# context_window_limit = 400000
```

## Первый запрос

Откройте агентную панель клавишами <Keys k="Alt+A" />. Баннер показывает подключение и модель; чип **Модель** в строке статуса крутится, пока Claude Code стартует в фоне, а запрос, отправленный в это время, ждёт его. Дальше панель работает как с любым другим подключением: ответы, рассуждения и вызовы инструментов появляются блоками, редактор с открытым файлом следит за каждой правкой, а часы прогона идут, пока Claude Code не закончит.

<Video src="/assets/blog/claude-code/claude-code.mp4" poster="/assets/blog/claude-code/claude-code.png" label="Панель агента на подключении Claude Code под report.py: запрос, чтение, правка, которую редактор показывает в строках 14 и 15, карточка разрешения для python3 -m unittest -q с ответом 1, затем ответ" caption="Запрос на Claude Code: редактор отмечает изменённые строки, а запуск тестов ждёт вашего ответа." />

Чипы переключают то, что предлагает Claude Code, в любой момент, и во время прогона тоже:

- **Модель**: модели вашего входа под теми именами, которые им даёт Claude Code.
- **Рассуждения**: уровень рассуждений.
- **Опции**: остальные его настройки, например быстрый режим.

Собственные `/`-команды Claude Code попадают в список `/` панели и уходят к нему как набраны; его `/compact` заменяет команду termide. Сообщение, набранное во время работы, присоединяется к текущему ходу, как и в самом Claude Code.

## Инструменты termide, а не Claude Code

Главное, что нужно знать: в панели Claude Code работает на **системном промпте и инструментах termide**, которые termide отдаёт ему через локальный MCP-сервер вместо его собственных. Встроенные инструменты Claude Code и его собственные настройки не используются: его правила, хуки, MCP-серверы и `CLAUDE.md`, который он загрузил бы сам. Что это даёт:

- **Одни разрешения на всё.** Каждый вызов проходит те же проверки, что и у собственного агента termide: режим разрешений, ваши правила, ответы, данные в этой сессии, режим плана и точки отката `/undo`.
- **Список инструментов.** Чип **Инструменты** перечисляет инструменты termide, ваши навыки и инструменты MCP-серверов termide; снятый с отметки инструмент отклоняется с первого же запроса.
- **Инструкции проекта по-прежнему действуют.** termide читает `AGENTS.md`, а где его нет — `CLAUDE.md`, из каждой папки между корнем и рабочей папкой панели и добавляет их в свой промпт.
- **MCP-серверы, навыки и хуки настраиваются в termide.** Настройте их один раз там, и они будут работать одинаково, на каком бы подключении ни шла сессия.

Цикл разговора остаётся за Claude Code: контекст он сжимает сам (сжатие видно в панели вместе с его сводкой), и поставить прогон на паузу между шагами нельзя.

## Разрешения и режим auto

Чип **Разрешения** (или <Keys k="Shift+Tab" />) задаёт режим: `ask`, `plan`, `edit`, `configured`, `auto`, `all`. Всё, что не решают режим и правила, появляется карточкой над полем ввода: разрешить один раз, на сессию, всегда в этом проекте или везде, запретить, запретить и объяснить агенту почему, или остановить прогон.

<Shot src={permission} alt="Карточка над полем ввода: агент хочет запустить python3 -m unittest -q; варианты: разрешить один раз, на сессию, запретить, запретить на сессию, запретить и объяснить, остановить прогон" caption="Claude Code спрашивает через карточку termide, как и собственный агент termide." />

`auto` — для прогона, направлению которого вы доверяете, но отвечать на карточку за карточкой не хотите. То, что вызвало бы карточку, уходит ревьюеру — отдельному обращению к модели, которое решает, служит ли шаг тому, о чём вы просили. На подключении Claude Code ревьюер работает **через вашу подписку, на Haiku** — самой дешёвой модели вашего входа — без API-ключа: termide держит адаптер запущенным и задаёт каждый вопрос в короткой отдельной сессии, без инструментов и без разговора агента, так что агент никогда не судит сам себя. Проверка занимает секунду или больше и расходует лимиты подписки. Другого ревьюера можно указать в поле **Ревьюер режима auto** на странице подключения или в `[ai.auto_reviewer]`:

```toml
[ai.auto_reviewer]
connection = "claude"   # пусто: подключение сессии
model = "haiku"         # его модель: по id, имени или части любого из них
```

Собственный режим auto у Claude Code не используется: каждый вызов оценивает ревьюер termide.

## Когда кончился лимит

Исчерпанное окно подписки завершает прогон карточкой, которая знает, когда лимит сбросится, — это сообщает адаптер Claude Code:

- **Подождать до 15:00 и повторить**,
- **Повторить сейчас**,
- **Остановиться** (<Keys k="Esc" />).

<Shot src={limit} alt="Ошибка лимита сессии и карточка Usage limit reached: сброс в 15:00 (через 4 ч 17 мин), варианты: подождать до 15:00 и повторить, повторить сейчас, остановиться" caption="Лимит исчерпан: карточка отсчитывает время до сброса." />

Для `/goal` или `/loop` без присмотра поставьте **При лимите или сбое сети** (`on_limit` в `[ai]`) в `wait`: прогон дождётся сброса и продолжит сам; `ask_else_wait` показывает карточку и ждёт, если никто не ответил. Если закрыть termide в это время, ничего не потеряется: открытая заново сессия вернёт карточку.

Если ждать не хочется, держите второе подключение. Чип **Подключение** в строке статуса остаётся доступен, пока висит карточка: переведите сессию на другое подключение и ответьте **Повторить сейчас**. Разговор переносится, так что другая модель продолжит с того места, где остановился Claude:

```toml
[ai.connections.claude]
provider = "claude_code"

[ai.connections.api]
provider = "anthropic_compatible"
model = "claude-sonnet-5"
api_key_env = "ANTHROPIC_API_KEY"   # или сохраните ключ в хранилище паролей termide из настроек
```

Подойдёт и локальная модель через llama.cpp или Ollama: `provider = "openai_compatible"` и её `base_url`.

## Поручённые задачи

Когда агент поручает задачу инструментом `task`, она выполняется копией Claude Code: в отдельной сессии, с промптом поручения и инструментами termide, а её запросы разрешений приходят к вам в поручившую панель. Чтобы тратить подписку только на основной разговор, укажите другое подключение в поле **Подагенты** на странице подключения Claude Code:

```toml
[ai.connections.claude]
provider = "claude_code"
subagents = "local"     # поручённые задачи выполняет локальная модель
```

Работает и в обратную сторону: сессия на локальной модели может поручать задачи Claude Code.

## Сессии и расходы

Журнал сессии хранит собственную сессию Claude Code, поэтому открытая заново панель продолжает её, и Claude Code знает весь разговор вместе с вызовами инструментов. Сессия, перешедшая на Claude Code с другого подключения, начинается с записи разговора до этого момента.

**Сведения о сессии** (<Keys k="F3" /> или `/usage`) раскладывают токены по тому, кто их потратил, — разговор, поручения, ревьюер `auto` и то, что Claude Code тратит внутри себя, — и по моделям.

## Полезно знать

- **Песочницы нет.** Разрешения termide — это контроль, а не изоляция: разрешённые команды выполняются с вашими правами.
- **Codex и Gemini CLI подключаются так же**: `provider = "codex"` или `"gemini_cli"`. У них остаются свои системные промпты и инструменты, а termide переводит свой режим разрешений в их режимы. Им посвящены гайды [Codex в агентной панели](/ru/blog/codex/) и [Gemini CLI в агентной панели](/ru/blog/gemini-cli/).
- **Вторым подключением, на которое можно перевести сессию, когда кончился лимит, может быть любой OpenAI- или Anthropic-совместимый API**: hosted, как у OpenAI, [OpenRouter](/ru/blog/openrouter/) или Anthropic, или ваш собственный сервер, — с собственным агентом termide. [llama.cpp](/ru/blog/llama-cpp/) и [omlx](/ru/blog/omlx/) — два примера последнего.
- **Подробности** — в [руководстве по агенту](https://github.com/termide/termide/blob/main/doc/ru/agent.md#настройка-модели).
