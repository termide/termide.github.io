## Добавлено
- **Поддержка Linux TTY**: родные цвета терминала для консоли и фреймбуфера Linux (TERM=linux)
- **Отображение удалённых веток**: панель статуса Git показывает удалённые ветки, которых нет локально
- **Области прокрутки DECSTBM**: корректная поддержка областей прокрутки CSI для терминальных приложений

## Изменено
- **Рефакторинг терминала**: выделены служебные модули (clipboard, disk_space, link_detection, shell_utils)
- **Рефакторинг редактора**: core.rs разбит на узконаправленные модули (LSP, перемещение, поиск, текст)
- **Рефакторинг Git**: монолитный lib.rs разделён на модули command, commits, files и operations
- **Производительность**: кэширование регулярных выражений для распознавания ссылок, меньше дублирования кода панелей
- **DRY-улучшения**: выделены вспомогательные функции для открытия файлов и терминалов из разных панелей

## Исправлено
- **Синхронизированный вывод**: исправлена инвалидация кэша при выходе из режима sync_output (CSI ? 2026 l)
- **Заметки к релизу в CI**: исправлено извлечение заметок к релизу из CHANGELOG.md

## Производительность
- **Терминал**: снижена задержка ввода по SSH и накладные расходы на отрисовку htop
