## Добавлено
- **Скрипт установки**: способ установки через Nix командой `nix profile install` для пользователей NixOS
- **Скрипт установки**: в системах NixOS вариант Nix помечен как «(recommended for NixOS)»

## Исправлено
- **Скрипт установки**: правильно работает при запуске через конвейер `curl | sh` (читает из /dev/tty)
- **Скрипт установки**: исправлены ссылки на скачивание (убран лишний префикс `v` перед версией)
- **Скрипт установки**: escape-коды ANSI больше не выводятся буквально в сообщении об успехе
- **Скрипт установки**: добавлен флаг `--refresh`, чтобы через Nix устанавливалась последняя версия

## Изменено
- **Сборка**: для релизных сборок включены LTO и strip (размер исполняемого файла меньше на 14%: 29→25 МиБ)
- **Упаковка**: удалены устаревшие шаги установки help/themes (файлы встроены в исполняемый файл)
- **Nix**: Cargo.lock добавлен под контроль версий для воспроизводимых сборок flake
