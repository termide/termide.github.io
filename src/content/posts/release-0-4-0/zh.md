## 新增
- 编辑器中双击选择单词
  - 双击选择最近分隔符之间的单词
  - 正确处理字母数字单词边界
- 带单词边界检测的智能自动换行
  - 尽可能在单词边界处换行
  - 单词宽于视口时回退为强制断行
- 自动换行文本的视觉行导航
  - 光标上/下按视觉行移动，而不是按缓冲区行
  - 在视觉行间移动时保持首选列
- CJK 和组合字符的正确 Unicode 渲染
  - 中文/日文/韩文字符以正确的 2 列宽度显示
  - 印地语及其他带组合字符的文字正确渲染
  - 使用字素簇进行正确的文本切分
- 新增 7 种语言的本地化
  - 德语 (de)、西班牙语 (es)、法语 (fr)、印地语 (hi)
  - 日语 (ja)、韩语 (ko)、葡萄牙语 (pt)、泰语 (th)、中文 (zh)
- 面板重新排序快捷键
  - Alt+[ 和 Alt+] 在当前分组内重新排序面板
  - Alt+PageUp/PageDown 根据上下文（重新排序或切换）
- 支持 Kitty 键盘协议，以正确处理 Alt+西里尔字母

## 变更
- 编辑器架构大规模拆分
  - 将光标移动提取到专门模块（physical、visual）
  - 将渲染拆分为专注的模块（line、wrap、cursor、highlights）
  - 创建 RenderContext 用于共享渲染状态
  - 键盘处理采用命令模式
- 翻译从 Rust 代码迁移到 TOML 文件
  - 更容易添加/更新翻译
  - 关注点分离更清晰
- 终端 VT100 解析器提取到专门模块
- 大量代码清理和 DRY 重构
  - 为模态窗口输入提取 TextInputHandler
  - 创建 path_utils 模块用于路径解析
  - 添加面板向下转型辅助方法（PanelExt trait）

## 修复
- 自动换行时的光标上/下导航
- 子目录中的 Git 状态跟踪
- 自动换行时的编辑器导航和视口问题
- 以正确的终端尺寸初始化应用

## 性能
- 关键热路径优化（快 100–270 倍）
  - 已知大小时预分配 Vec
  - 消除不必要的字符串分配
  - 用 copy_within 优化终端字符移位
