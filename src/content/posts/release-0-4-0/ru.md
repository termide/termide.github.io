## Добавлено
- Выделение слова двойным щелчком в редакторе
  - Двойной щелчок выделяет слово между ближайшими разделителями
  - Правильная обработка границ буквенно-цифровых слов
- Умный перенос строк с определением границ слов
  - Строки разрываются по границам слов, когда это возможно
  - Для слов шире области просмотра используется жёсткий разрыв
- Навигация по визуальным строкам в тексте с переносом
  - Курсор вверх/вниз движется по визуальным строкам, а не по строкам буфера
  - Предпочтительная колонка сохраняется при движении по визуальным строкам
- Правильная отрисовка Unicode для CJK и комбинируемых символов
  - Китайские, японские и корейские символы отображаются с правильной шириной в 2 колонки
  - Хинди и другие письменности с комбинируемыми символами отображаются правильно
  - Для правильной сегментации текста используются кластеры графем
- Локализация на 7 новых языков
  - Немецкий (de), испанский (es), французский (fr), хинди (hi)
  - Японский (ja), корейский (ko), португальский (pt), тайский (th), китайский (zh)
- Горячие клавиши для перестановки панелей
  - Alt+[ и Alt+] переставляют панели внутри текущей группы
  - Alt+PageUp/PageDown учитывают контекст (переставляют или переключают)
- Поддержка протокола клавиатуры Kitty для правильной обработки Alt с кириллицей

## Изменено
- Крупная декомпозиция архитектуры редактора
  - Перемещение курсора вынесено в отдельные модули (физическое, визуальное)
  - Отрисовка разделена на узкие модули (строка, перенос, курсор, подсветка)
  - Создан RenderContext для общего состояния отрисовки
  - Обработка клавиатуры по паттерну «Команда»
- Переводы перенесены из кода на Rust в файлы TOML
  - Переводы проще добавлять и обновлять
  - Более чистое разделение ответственности
- Парсер VT100 терминала вынесен в отдельный модуль
- Обширная чистка кода и рефакторинг по принципу DRY
  - Выделен TextInputHandler для полей ввода в модальных окнах
  - Создан модуль path_utils для разрешения путей
  - Добавлены помощники приведения типа панелей (трейт PanelExt)

## Исправлено
- Навигация курсора вверх/вниз при переносе строк
- Отслеживание статуса git в подкаталогах
- Проблемы навигации и области просмотра редактора при переносе строк
- Инициализация приложения с правильным размером терминала

## Производительность
- Оптимизация критических горячих путей (в 100–270 раз быстрее)
  - Предварительное выделение Vec, когда размер известен
  - Устранены лишние выделения памяти под строки
  - Сдвиг символов терминала оптимизирован с помощью copy_within
