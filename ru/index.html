Одно терминальное рабочее место — на ноутбуке и на серверах.

Редактор, файловый менеджер, терминал, git, базы данных и агент для кода. Один статический бинарник, без настройки.

Код с LSP

Автодополнение, переход к определению, ссылки, переименование и диагностика для 22 языков — без настройки плагинов.

Агент на вашей модели

Подключите llama.cpp, Ollama или vLLM на своей машине — и код никуда не уходит. Или используйте облачный endpoint.

Git как на ладони

Статус, цветной граф коммитов, diff, stash и ветки вместе с их ворктри.

Документы рядом с кодом

Отрендеренный Markdown, диаграммы Mermaid, HTML и изображения в панелях рядом с редактором.

Команды проекта

Сборка, тесты и деплой в commands.toml, для каждого проекта свои, на горячих клавишах.

root@srv:~# На серверах

Скопировал файл — и работает

Статический musl-бинарник без OpenSSL и без привязки к libc: Alpine, ARM-платы, контейнеры, Termux.

Локальная и удалённая панели

SFTP, FTP и FTPS в файловом менеджере; копирование между хостами идёт в фоне.

Переживает обрыв SSH

termide --detached сохраняет редакторы, шеллы и задачи; --attach возвращает их в терминале любого размера.

Что нагружает сервер

CPU, память, сеть и диск в строке меню, топ процессов и слушающие порты в один клик.

Заглянуть в базу

Таблицы SQLite, PostgreSQL и MySQL с сортировкой, фильтрами, правкой ячеек и экспортом.

Ваш $EDITOR

EDITOR=termide для crontab -e, visudo и сообщений коммитов.

// Агент для кода, который сначала спрашивает

Опишите задачу — модель читает, правит и запускает команды в вашем проекте, а каждое изменение ждёт вашего разрешения.

Локальная модель? Код не покидает вашу машину.
Не доверяете агентам? Он спрашивает перед каждым изменением, а /undo его откатывает.
Уже пользуетесь Claude Code или Codex? Запускайте их в той же панели.

Своя модель

Любой OpenAI- или Anthropic-совместимый endpoint: llama.cpp, Ollama, vLLM, omlx или облачный провайдер. Размер контекста берётся с сервера, если он его сообщает.

Без вас ничего не меняется

Разрешить один раз, на сессию или навсегда по шаблону; отказать с причиной, которую прочтёт модель; режим плана запрещает любую запись; /undo и контрольные точки откатывают правки.

Только нужные инструменты

Чтение, правка, запись и шелл, плюс веб-поиск и загрузка страниц через собственный профиль браузера — без ваших логинов.

Другие агенты в той же панели

Claude Code, Codex и Gemini CLI по Agent Client Protocol, ваши собственные агенты и субагенты для отдельных задач.

Расширяется файлами

Skills, шаблоны промптов, командные скрипты, MCP-серверы, хуки и инструкции проекта — всё обычные файлы.

Видно, во что обходится

Фаза и скорость в реальном времени, прогресс чтения промпта, заполнение контекста и счётчики токенов; каждый ответ заканчивается временем и токенами. Уровень рассуждений выбирается для каждой модели; сессии можно продолжить позже.

Без интерфейса — для скриптов и CI

Тот же агент, инструменты и правила разрешений без UI:

termide --prompt "run the tests and report failures" --output json

Сделайте по-своему

Тема — это TOML-файл с десятью цветами. Без сборки и плагинов.

  • Именованные цвета или RGB, десять ключей в одном файле.
  • Файл с именем встроенной темы заменяет эту тему.
  • "Reset" оставляет видимым собственный фон терминала.
  • Своя тема для проекта или хоста: красная на проде сразу подскажет, где вы.
> Формат тем 
# ~/.config/termide/themes/prod-red.toml
name = "prod-red"

[colors]
bg          = { rgb = [40, 8, 8] }
fg          = { rgb = [240, 220, 220] }
accented_bg = { rgb = [110, 20, 20] }
accented_fg = "White"
selected_bg = { rgb = [200, 40, 40] }
selected_fg = "White"
disabled    = "DarkGray"
success     = "LightGreen"
warning     = "LightYellow"
error       = "LightRed"

// Всё остальное

Остальное, что входит в бинарник.

Код

  • {}Редактор с LSP Автодополнение, hover, переход к определению, ссылки, переименование и быстрые исправления; панель диагностики; подсветка tree-sitter для 22 языков.
  • §Структура кода Навигация по структуре через запросы tree-sitter, синхронизированная с курсором.
  • ¶Документы и диаграммы Отрендеренные Markdown и HTML, текстовый браузер, сохраняющий страницы в Markdown, и диаграммы Mermaid, нарисованные текстом, — включая диаграммы классов из ваших исходников.
  • 0xHex-редактор Hex/ASCII-просмотр с курсором по байтам, выделением и поиском; правка поверх с резервной копией .bak.

Файлы и данные

  • []Файловый менеджер Дерево с вложенным git-статусом, поиск по glob и regex, пакетные операции, закладки и переключатель каталогов. Архивы zip, tar и ISO открываются как папки, в том числе на сервере; P упаковывает выделенное.
  • ↔Удалённые файловые системы SFTP, FTP и FTPS на чистом Rust; SMB и NFS через монтирование ОС.
  • ⇅Фоновые операции Копирование, перемещение, загрузка и выгрузка с прогрессом, паузой, продолжением и отменой.
  • ▦Просмотр баз данных SQLite, PostgreSQL и MySQL: серверная сортировка, фильтры по столбцам, правка ячеек, строки в TSV, JSON или INSERT.

Серверы и эксплуатация

  • &Отсоединяемые экземпляры Закройте терминал или потеряйте соединение — и подключитесь снова позже из любого терминала (Unix).
  • >_Встроенный терминал Полноценный PTY с прокруткой, поиском, мышью и распознаванием URL; заголовок следует за cd.
  • %%Монитор ресурсов CPU, RAM, сеть и диск; топ процессов по CPU, памяти или соединениям, со слушающими портами.
  • ◆Один статический бинарник Linux x86_64 и ARM64 (glibc или musl), macOS, нативный Windows и Android Termux.

Рабочее пространство

  • +-Git Статус, лог с цветным графом коммитов, diff, индекс, stash, blame, ветки и их ворктри.
  • ::Проекты Раскладка панелей восстанавливается для каждого каталога, со своими настройками и командами проекта.
  • $/Свои команды Глобальные и проектные команды с горячими клавишами, формами параметров и режимами терминала, фона или отчёта.
  • ⌘Палитра и «Открыть» Нечёткая палитра команд по Ctrl+P; Ctrl+G открывает файл, папку или URL с подсказками путей.

Внешний вид и управление

  • #*38 тем Тёмные, светлые, ретро и кинематографические; свои темы пишутся в TOML.
  • @!15 языков интерфейса Русский, английский, китайский, японский, корейский, немецкий, французский, испанский и другие.
  • F1Клавиатура и мышь Любое сочетание меняется в настройках; полная поддержка мыши; горячие клавиши работают в кириллической раскладке и с Alt на macOS.
  • ✎Vim-режим Необязательное редактирование в стиле Vim — для тех, чьи пальцы к нему привыкли.

// Вопросы и ответы

Обязательно ли пользоваться ИИ-агентом?

Нет. По умолчанию не задан ни провайдер, ни модель, поэтому агент ничего не делает и никуда ничего не отправляет, пока вы его не настроите. Всё остальное работает без него.

TermIDE что-то отправляет в сеть?

Ни телеметрии, ни аккаунтов, ни проверки обновлений. В сеть он выходит только по вашей команде: удалённое расположение, веб-страница, git push или pull, модель для агента.

Он заменяет tmux?

Для частого случая — не потерять работу при обрыве SSH — да: termide --detached сохраняет всё рабочее место, а --attach возвращает его. Произвольными сессиями и окнами, как tmux, он не управляет и спокойно работает внутри tmux.

Как пользоваться им на сервере?

Скопируйте статический musl-бинарник и запустите — больше ничего ставить не нужно. Можно и остаться локально, открыв сервер по SFTP или FTP из файлового менеджера.

Какой нужен терминал?

Любой современный с поддержкой true colour. Изображения рисуются нативно в Kitty, WezTerm, iTerm2, Ghostty и foot; сочетания с Alt на macOS работают в терминалах с протоколом клавиатуры Kitty.

Работает ли на Windows?

Да, нативно через ConPTY в Windows Terminal или в WSL. Отсоединяемые экземпляры есть только в Unix.

Придётся учить новые клавиши?

В меню видно каждое сочетание, мышь работает везде, а двухпанельная раскладка знакома по mc и FAR. Любое сочетание меняется в настройках, есть необязательный Vim-режим.

// Установка

Выберите платформу. Ни рантайма, ни зависимостей.

Linux и macOS; сам определяет систему.

curl -fsSL https://raw.githubusercontent.com/termide/termide/main/install.sh | sh

Статический musl-бинарник для любого Linux, включая Alpine и контейнеры.

curl -LO https://github.com/termide/termide/releases/latest/download/termide-0.37.0-x86_64-unknown-linux-musl.tar.gz
tar xzf termide-0.37.0-x86_64-unknown-linux-musl.tar.gz && ./termide

macOS и Linux.

brew tap termide/termide
brew install termide

Из AUR; пакет termide собирается из исходников.

yay -S termide-bin

Запуск без установки или nix profile install.

nix run github:termide/termide

Debian и Ubuntu, x86_64.

curl -LO https://github.com/termide/termide/releases/latest/download/termide_0.37.0-1_amd64.deb
sudo dpkg -i termide_0.37.0-1_amd64.deb

Fedora, RHEL и CentOS, x86_64.

sudo rpm -i https://github.com/termide/termide/releases/latest/download/termide-0.37.0-1.x86_64.rpm

Android; статическая ARM64-сборка работает на Bionic.

pkg install git openssh
curl -LO https://github.com/termide/termide/releases/latest/download/termide-0.37.0-aarch64-unknown-linux-musl.tar.gz
tar xzf termide-0.37.0-aarch64-unknown-linux-musl.tar.gz && ./termide

Скачайте, распакуйте и запустите termide.exe в Windows Terminal.

https://github.com/termide/termide/releases/latest/download/termide-0.37.0-x86_64-pc-windows-msvc.zip
