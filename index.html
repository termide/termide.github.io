// A coding agent that asks first

Describe a task; the model reads, edits and runs commands in your project, and every change waits for your approval.

Local model? Code never leaves your machine.
Wary of agents? It asks before every change, and /undo takes it back.
Already on Claude Code or Codex? Run them in the same panel.

Bring your own model

Any OpenAI- or Anthropic-compatible endpoint: llama.cpp, Ollama, vLLM, omlx or a hosted provider. The context window comes from the server when it reports one.

Nothing changes without you

Allow once, for the session or always for a pattern; deny with a reason the model reads; plan mode refuses every write; /undo and checkpoints take edits back.

Tools it needs, nothing more

Read, edit, write and shell, plus web search and fetch through a browser profile of its own, never your logins.

Other agents in the same panel

Claude Code, Codex and Gemini CLI over the Agent Client Protocol, your own agents, and subagents for focused jobs.

Extend it in files

Skills, prompt templates, command scripts, MCP servers, hooks and project instructions, all plain files.

See what it costs

Live phase and speed, prefill progress, a context bar and token totals; each answer ends with its time and tokens. Pick the reasoning level per model; sessions resume later.

Headless, for scripts and CI

The same agent, tools and permission rules without the UI:

termide --prompt "run the tests and report failures" --output json

Make it yours

A theme is a TOML file with ten colours. No build step, no plugin.

  • Named colours or RGB, ten keys in one file.
  • A file with a built-in theme's name replaces that theme.
  • "Reset" lets your terminal's own background show through.
  • Set it per project or per host: a red theme on production tells you where you are.
> Theme format 
# ~/.config/termide/themes/prod-red.toml
name = "prod-red"

[colors]
bg          = { rgb = [40, 8, 8] }
fg          = { rgb = [240, 220, 220] }
accented_bg = { rgb = [110, 20, 20] }
accented_fg = "White"
selected_bg = { rgb = [200, 40, 40] }
selected_fg = "White"
disabled    = "DarkGray"
success     = "LightGreen"
warning     = "LightYellow"
error       = "LightRed"

// Everything else

The rest of what ships in the binary.

Code

  • {}Editor with LSP Completion, hover, go to definition, references, rename and quick fixes; a diagnostics panel; tree-sitter highlighting for 22 languages.
  • §Code outline Structural navigation through tree-sitter queries, synced with the cursor.
  • ¶Docs and diagrams Rendered Markdown and HTML, a text-mode browser that saves pages as Markdown, and Mermaid diagrams drawn as text, including class diagrams from your source.
  • 0xHex editor Hex/ASCII view with a byte cursor, selection and search; overwrite editing with a .bak backup.

Files and data

  • []File manager Tree with nested git status, glob and regex search, batch operations, bookmarks and a directory switcher. Zip, tar and ISO archives open like folders, also on a server; P packs the selection.
  • ↔Remote filesystems SFTP, FTP and FTPS in pure Rust; SMB and NFS through the OS mount.
  • ⇅Background operations Copy, move, upload and download with progress, pause, resume and cancel.
  • ▦Database viewer SQLite, PostgreSQL and MySQL: server-side sort, per-column filters, cell editing, rows as TSV, JSON or INSERT.

Servers and ops

  • &Detached instances Close the terminal or lose the connection; attach again later from any terminal (Unix).
  • >_Integrated terminal Full PTY with scrollback, search, mouse and URL detection; the title follows your cd.
  • %%Resource monitor CPU, RAM, network and disk; top processes by CPU, memory or connections, with listening ports.
  • ◆One static binary Linux x86_64 and ARM64 (glibc or musl), macOS, native Windows and Android Termux.

Workspace

  • +-Git Status, log with a coloured commit graph, diff, staging, stash, blame, branches and their worktrees.
  • ::Projects Panel layouts restored per directory, with per-project settings and commands.
  • $/Custom commands Global or per-project commands with hotkeys, parameter forms and terminal, background or report modes.
  • ⌘Palette and Open Ctrl+P fuzzy command palette; Ctrl+G opens a file, a folder or a URL with path suggestions.

Look and feel

  • #*38 themes Dark, light, retro and cinematic; write your own in TOML.
  • @!15 UI languages English, Chinese, Russian, Japanese, Korean, German, French, Spanish and more.
  • F1Keyboard and mouse Every binding is editable in Settings; full mouse support; hotkeys work on a Cyrillic layout and with Alt on macOS.
  • ✎Vim mode Optional Vim-style editing for those whose fingers expect it.

// FAQ

Do I have to use the AI agent?

No. No provider or model is set by default, so the agent does nothing and sends nothing until you configure one. Everything else works without it.

Does TermIDE phone home?

No telemetry, no account and no update checks. It goes online only when you ask: a remote location, a web page, git push or pull, or a model for the agent.

Does it replace tmux?

For the common case of keeping work alive over SSH, yes: termide --detached keeps the whole workspace running and --attach brings it back. It does not manage arbitrary sessions and windows the way tmux does, and runs fine inside tmux.

How do I use it on a server?

Copy the static musl binary and run it; nothing else needs installing. You can also stay local and open the server over SFTP or FTP from the file manager.

Which terminals does it need?

Any modern terminal with true colour. Images are drawn natively in Kitty, WezTerm, iTerm2, Ghostty and foot; Alt hotkeys on macOS work in terminals with the Kitty keyboard protocol.

Does it run on Windows?

Yes, natively through ConPTY in Windows Terminal, or in WSL. Detached instances are Unix-only.

Do I have to learn new keys?

Menus list every shortcut, the mouse works everywhere, and the dual-pane layout will feel familiar from mc or FAR. Every binding can be changed in Settings, and there is an optional Vim mode.

// Install

Pick your platform. No runtime, no dependencies.

Linux and macOS; detects your system.

curl -fsSL https://raw.githubusercontent.com/termide/termide/main/install.sh | sh

Static musl binary for any Linux, including Alpine and containers.

curl -LO https://github.com/termide/termide/releases/latest/download/termide-0.37.0-x86_64-unknown-linux-musl.tar.gz
tar xzf termide-0.37.0-x86_64-unknown-linux-musl.tar.gz && ./termide

macOS and Linux.

brew tap termide/termide
brew install termide

From the AUR; termide builds from source.

yay -S termide-bin

Run without installing, or nix profile install.

nix run github:termide/termide

Debian and Ubuntu, x86_64.

curl -LO https://github.com/termide/termide/releases/latest/download/termide_0.37.0-1_amd64.deb
sudo dpkg -i termide_0.37.0-1_amd64.deb

Fedora, RHEL and CentOS, x86_64.

sudo rpm -i https://github.com/termide/termide/releases/latest/download/termide-0.37.0-1.x86_64.rpm

Android; the static ARM64 build runs on Bionic.

pkg install git openssh
curl -LO https://github.com/termide/termide/releases/latest/download/termide-0.37.0-aarch64-unknown-linux-musl.tar.gz
tar xzf termide-0.37.0-aarch64-unknown-linux-musl.tar.gz && ./termide

Download, extract and run termide.exe in Windows Terminal.

https://github.com/termide/termide/releases/latest/download/termide-0.37.0-x86_64-pc-windows-msvc.zip
